# 4.6 Generalization in Classification

> **핵심 키워드:** Generalization · Training Set · Test Set · Test Set Reuse · Statistical Learning Theory

---

## 등장 배경

앞 절에서는 Softmax Regression을 구현하고 Classification 모델을 학습하는 방법을 학습하였다.

하지만 높은 Training Accuracy를 얻었다고 해서 반드시 좋은 모델이라고 할 수는 없다. 머신러닝 모델의 진정한 목적은 **학습 데이터뿐만 아니라 처음 보는 새로운 데이터에서도 좋은 성능을 유지하는 것**이다.

따라서 이번 절에서는 **Generalization(일반화)** 의 개념을 Classification 문제에 적용하고, Test Set의 역할과 올바른 사용 방법을 학습한다.

---

## 핵심 아이디어

> **좋은 분류 모델은 Training Data를 외우는 것이 아니라, 새로운 데이터에서도 높은 Accuracy를 유지하는 모델이다.**

모델의 성능은 크게 두 가지 데이터에서 평가된다.

```
Training Dataset
        │
        ▼
Model Training
        │
        ▼
Test Dataset
        │
        ▼
Generalization Performance
```

Training Accuracy와 Test Accuracy가 모두 높을수록 일반화 성능이 좋은 모델이라고 할 수 있다.

---

## 주요 개념

### 1. Test Set

Test Set은 학습 과정에서 사용하지 않은 데이터로, 모델의 일반화 성능을 평가하기 위해 사용된다.

Training이 모두 끝난 후 한 번만 사용하여 모델의 최종 성능을 측정한다.

#### 왜 사용하는가?

- 새로운 데이터에서의 성능을 평가하기 위해
- 모델의 일반화 능력을 확인하기 위해
- 실제 환경에서의 성능을 예측하기 위해

---

### 2. Training Accuracy vs Test Accuracy

Training Accuracy는 학습 데이터에서의 정확도를 의미하고,

Test Accuracy는 학습에 사용하지 않은 데이터에서의 정확도를 의미한다.

이 두 값의 차이가 크다면 Overfitting이 발생했을 가능성이 높다.

#### 특징

- 두 Accuracy가 모두 높으면 좋은 모델
- Training Accuracy만 높으면 Overfitting 가능성
- 두 Accuracy가 모두 낮으면 Underfitting 가능성

---

### 3. Test Set Reuse

Test Set은 모델의 최종 성능을 평가하기 위한 데이터이다.

하지만 Test Set을 반복해서 사용하면 모델이 Test Set에 맞춰 최적화되어 더 이상 새로운 데이터를 평가하는 기준이 될 수 없다.

#### 왜 문제가 되는가?

- Test Set 정보가 모델 개발에 반영된다.
- Test Accuracy가 실제보다 높게 측정될 수 있다.
- 일반화 성능을 객관적으로 평가할 수 없게 된다.

따라서 Test Set은 **최종 평가를 위해 아껴두는 것**이 원칙이다.

---

### 4. Statistical Learning Theory

Statistical Learning Theory는 모델이 새로운 데이터에서도 좋은 성능을 낼 수 있는 이유를 설명하는 이론이다.

이 이론에서는

- 데이터의 양
- 모델의 복잡도
- 일반화 오차

사이의 관계를 연구한다.

#### 왜 중요한가?

- 좋은 모델의 조건을 이론적으로 설명할 수 있다.
- 모델의 복잡도와 일반화 성능의 관계를 이해할 수 있다.
- 머신러닝 알고리즘의 성능을 분석하는 기반이 된다.

---

## 장점

- 모델의 실제 성능을 객관적으로 평가할 수 있다.
- Overfitting을 쉽게 확인할 수 있다.
- 새로운 데이터에서의 성능을 예측할 수 있다.
- 모델 선택(Model Selection)의 기준을 제공한다.

---

## 한계

- Test Set이 충분히 크지 않으면 평가 결과의 신뢰성이 낮아질 수 있다.
- 데이터 분포가 실제 환경과 다르면 Test Accuracy도 실제 성능을 보장하지 못한다.
- Statistical Learning Theory는 실제 딥러닝 모델의 모든 특성을 완벽하게 설명하지는 못한다.
