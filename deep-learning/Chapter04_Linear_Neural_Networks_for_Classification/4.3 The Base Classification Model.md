# 4.3 The Base Classification Model

> **핵심 키워드:** Classifier · Accuracy · Prediction · Evaluation · Base Model

---

## 등장 배경

앞 절에서는 Fashion-MNIST 데이터를 불러오고 DataLoader를 이용하여 모델이 학습할 수 있는 형태로 데이터를 준비하였다.

이제 데이터를 이용하여 실제 분류 모델을 학습할 차례이다. 하지만 앞으로 CNN, ResNet, Transformer 등 다양한 분류 모델을 구현하게 되므로, 모델마다 동일한 학습 및 평가 코드를 반복해서 작성하는 것은 비효율적이다.

따라서 D2L에서는 **분류 모델의 공통 기능을 담당하는 Base Classification Model(Classifier)** 을 정의한다.

또한 Regression에서는 MSE를 이용하여 성능을 평가했지만, Classification에서는 **Accuracy**를 이용하여 모델의 성능을 평가한다.

---

## 핵심 아이디어

> **분류 모델의 공통 기능을 하나의 Class로 관리하고, Accuracy를 이용하여 모델의 성능을 평가한다.**

전체 흐름은 다음과 같다.

```
Input Image
      │
      ▼
Classifier
      │
      ▼
Prediction
      │
      ▼
Accuracy
```

즉,

모델은 Prediction을 수행하고,

Accuracy는 Prediction이 실제 Label과 얼마나 일치하는지를 계산한다.

---

## 주요 개념

### 1. Classifier

Classifier는 모든 분류 모델이 공통적으로 사용하는 기본 클래스이다.

Softmax Regression뿐 아니라 이후 학습할 MLP, CNN, ResNet 등도 동일한 구조를 사용할 수 있도록 설계되어 있다.

Classifier는

- Forward
- Loss 계산
- Prediction
- Accuracy 계산

등 분류 모델에서 공통적으로 필요한 기능을 제공한다.

#### 왜 사용하는가?

- 코드의 재사용성을 높일 수 있다.
- 새로운 분류 모델을 쉽게 구현할 수 있다.
- 모델마다 반복되는 코드를 줄일 수 있다.

---

### 2. Prediction

Prediction은 모델이 입력 데이터를 어느 클래스로 분류하는지를 결정하는 과정이다.

Softmax의 출력은 각 클래스의 확률이므로,

가장 높은 확률을 가진 클래스를 최종 예측으로 선택한다.

예를 들어

| Class | Probability |
|--------|------------:|
| Cat | 0.12 |
| Dog | 0.80 |
| Car | 0.08 |

이라면

최종 Prediction은 **Dog**가 된다.

#### 왜 사용하는가?

- 모델의 최종 분류 결과를 얻기 위해
- Accuracy 계산의 기준이 되기 위해

---

### 3. Accuracy

Accuracy는 전체 데이터 중 모델이 정확하게 예측한 비율을 의미한다.

공식은 다음과 같다.

$$
Accuracy=\frac{\text{Correct Predictions}}{\text{Total Predictions}}
$$

예를 들어

100개의 이미지 중

90개를 맞추었다면

Accuracy는 90%가 된다.

#### 왜 사용하는가?

- Classification에서 가장 기본적인 평가 지표이다.
- 모델 성능을 직관적으로 이해할 수 있다.
- 서로 다른 모델을 쉽게 비교할 수 있다.

---

### 4. Base Classification Model

Base Model은 앞으로 구현할 다양한 분류 모델의 기반이 된다.

즉,

```
Classifier
     │
     ├── Softmax Regression
     ├── MLP
     ├── LeNet
     ├── AlexNet
     ├── ResNet
     └── Vision Transformer
```

처럼 동일한 구조를 공유한다.

#### 왜 사용하는가?

- 모델 구조를 통일할 수 있다.
- 확장성이 뛰어나다.
- 실제 딥러닝 프레임워크의 설계 방식과 유사하다.

---

## 장점

- 분류 모델의 공통 기능을 하나의 클래스로 관리할 수 있다.
- 코드의 재사용성과 유지보수성이 향상된다.
- Accuracy를 통해 모델 성능을 쉽게 평가할 수 있다.
- 이후 다양한 분류 모델에도 동일한 구조를 사용할 수 있다.

---

## 한계

- Accuracy는 클래스 불균형(Class Imbalance)에 취약하다.
- 예측 확률의 신뢰도를 평가하지는 못한다.
- Precision, Recall, F1-score 등이 필요한 문제도 존재한다.
- 매우 복잡한 분류 문제에서는 Accuracy만으로 성능을 판단하기 어렵다.
