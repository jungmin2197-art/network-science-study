# 4.1 Softmax Regression

> **핵심 키워드:** Classification · Softmax · Probability · Cross Entropy · Information Theory

---

## 등장 배경

Chapter 3에서는 Linear Regression을 이용하여 연속적인 값(Regression)을 예측하는 방법을 학습하였다. 하지만 실제 머신러닝 문제의 상당수는 숫자가 아니라 **범주(Class)** 를 예측하는 문제이다.

예를 들어

- 이메일이 스팸인지 아닌지
- 손글씨 숫자가 무엇인지
- 이미지가 고양이인지 강아지인지

와 같은 문제는 모두 Classification 문제이다.

하지만 Linear Regression은 출력값이 연속적인 실수이므로 이러한 문제를 해결하기에 적합하지 않다.

따라서 여러 클래스 중 하나를 선택할 수 있도록 Linear Regression을 확장한 모델인 **Softmax Regression**이 등장하였다.

---

## 핵심 아이디어

> **Softmax Regression은 각 클래스에 속할 확률을 예측하고, 가장 높은 확률을 가진 클래스를 최종 결과로 선택하는 선형 분류 모델이다.**

학습 과정은 Chapter 3과 거의 동일하다.
