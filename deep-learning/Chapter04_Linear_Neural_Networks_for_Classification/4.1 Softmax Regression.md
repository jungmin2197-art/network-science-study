# 4.1 Softmax Regression

> **핵심 키워드:** Classification · Softmax · Probability · Cross Entropy · Information Theory

---

## 등장 배경

Chapter 3에서는 **Linear Regression**을 이용하여 연속적인 값(Regression)을 예측하는 방법을 학습하였다.

Linear Regression은 입력과 출력 사이의 선형 관계를 학습하여 숫자를 예측하는 모델이므로, 집값 예측이나 주가 예측처럼 **연속적인 값(Continuous Value)** 을 예측하는 문제에 적합하다.

하지만 현실에서 해결해야 하는 많은 문제는 숫자가 아니라 **범주(Class)** 를 예측하는 문제이다.

예를 들어

- 이메일이 스팸인지 아닌지
- 손글씨 숫자가 무엇인지
- 사진 속 동물이 고양이인지 강아지인지
- 질병이 정상인지 이상인지

와 같은 문제는 모두 **Classification** 문제이다.

이러한 문제에서는 출력값 자체보다 **각 클래스에 속할 확률**을 예측하는 것이 중요하다.

하지만 Linear Regression은 출력값이 제한되지 않는 실수이므로

```
Cat = 3.4

Dog = -2.1

Car = 5.8
```

과 같은 값을 출력할 수 있으며,

이를 확률이라고 해석할 수 없다.

따라서 Classification에서는 출력값을 확률로 변환할 수 있는 새로운 모델이 필요하며,

이를 위해 **Softmax Regression**이 등장하였다.

---

## 핵심 아이디어

> **Softmax Regression은 각 클래스에 속할 확률을 예측하고, 가장 높은 확률을 가진 클래스를 최종 결과로 선택하는 선형 분류 모델이다.**

전체 학습 과정은 다음과 같다.

```
Input
   │
Linear Transformation
   │
Logits
   │
Softmax
   │
Probability
   │
Cross Entropy Loss
   │
Gradient Descent
```

Regression에서는

```
Input

↓

Linear Regression

↓

Prediction

↓

MSE Loss
```

를 사용하였다.

반면 Classification에서는

```
Input

↓

Linear Transformation

↓

Softmax

↓

Probability

↓

Cross Entropy Loss
```

를 사용한다.

즉,

Regression은 **실수를 예측**하고,

Classification은 **확률을 예측**한다는 점이 가장 큰 차이이다.

---

## 주요 개념

### 1. Classification

Classification은 입력 데이터를 여러 개의 클래스 중 하나로 분류하는 문제이다.

Regression이 "얼마인가?"를 예측하는 문제라면,

Classification은 "무엇인가?"를 예측하는 문제이다.

예를 들어

```
Input Image

↓

Cat

Dog

Car
```

중 하나를 선택하는 것이 Classification이다.

#### 왜 사용하는가?

- 대부분의 컴퓨터 비전 문제를 해결하기 위해
- 자연어 처리의 문장 분류 문제를 해결하기 위해
- 의료 AI의 질병 분류 문제를 해결하기 위해

---

### 2. Softmax Regression

Softmax Regression은 Linear Regression을 다중 클래스 분류 문제로 확장한 모델이다.

먼저 입력 데이터를 선형 변환하여 **Logits**를 계산한다.

```
z = Wx + b
```

하지만 Logits는 확률이 아니다.

따라서 Softmax 함수를 이용하여

```
0.2

1.3

-0.7
```

과 같은 값을

```
0.18

0.72

0.10
```

처럼 확률로 변환한다.

Softmax의 가장 중요한 특징은

- 모든 확률이 0~1 사이
- 모든 확률의 합이 1

이라는 것이다.

#### 왜 사용하는가?

- 여러 클래스를 동시에 분류할 수 있다.
- 출력을 확률로 해석할 수 있다.
- 가장 높은 확률을 선택하여 최종 클래스를 결정할 수 있다.

---

### 3. Loss Function (Cross Entropy)

Regression에서는 MSE Loss를 사용하였다.

하지만 Classification에서는

예측값과 정답 사이의 거리가 아니라

**정답 클래스의 확률이 얼마나 높은가**가 중요하다.

이를 위해 사용하는 Loss가

**Cross Entropy Loss**이다.

Cross Entropy는

정답 클래스의 확률이

- 높으면 작은 Loss
- 낮으면 큰 Loss

를 가지도록 설계되어 있다.

예를 들어

```
Prediction

Cat = 0.95

Dog = 0.03

Car = 0.02
```

라면 Loss는 매우 작다.

반대로

```
Prediction

Cat = 0.02

Dog = 0.90

Car = 0.08
```

이라면 Loss는 매우 커진다.

#### 왜 사용하는가?

- Classification 문제에 가장 적합한 Loss이다.
- Softmax와 함께 사용할 때 Gradient 계산이 안정적이다.
- 정답 클래스의 확률을 효과적으로 최대화할 수 있다.

---

### 4. Information Theory

Cross Entropy는 Information Theory에서 유래한 개념이다.

Information Theory에서는

**발생 확률이 낮은 사건일수록 더 많은 정보를 가진다.**

예를 들어

```
해가 동쪽에서 뜬다.

↓

정보량 작음
```

반면

```
오늘 눈이 한여름에 내렸다.

↓

정보량 큼
```

이다.

Cross Entropy는 이러한 개념을 이용하여

모델이 정답을 얼마나 놀랍게(Surprised) 생각하는지를 계산한다.

즉,

정답 확률이 높으면

```
Surprise ↓

Loss ↓
```

정답 확률이 낮으면

```
Surprise ↑

Loss ↑
```

가 된다.

#### 왜 중요한가?

- Cross Entropy의 원리를 이해할 수 있다.
- Classification Loss가 Information Theory와 연결된다는 점을 이해할 수 있다.

---

## 장점

- 여러 클래스를 동시에 분류할 수 있다.
- 출력을 확률로 표현할 수 있다.
- Cross Entropy와 함께 사용하면 안정적인 학습이 가능하다.
- 대부분의 분류 모델(CNN, Transformer 등)의 기본 구조가 된다.

---

## 한계

- 입력과 출력 사이의 관계는 여전히 선형이다.
- 복잡한 비선형 문제는 해결하기 어렵다.
- 표현력이 제한적이므로 Hidden Layer가 필요하다.

---

## Linear Regression vs Softmax Regression

| Linear Regression | Softmax Regression |
|-------------------|--------------------|
| Regression | Classification |
| 연속적인 값 예측 | 클래스 예측 |
| 출력은 실수 | 출력은 확률 |
| MSE Loss | Cross Entropy Loss |
| 하나의 출력값 | 여러 클래스 출력 |
