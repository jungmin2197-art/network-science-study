# 4.4 Softmax Regression Implementation from Scratch

> **핵심 키워드:** Softmax · Cross Entropy · Logits · Gradient Descent · From Scratch

---

## 등장 배경

앞 절에서는 분류 모델의 기본 구조(Classifier)와 Accuracy를 이용한 성능 평가 방법을 학습하였다.

하지만 아직 PyTorch가 Softmax와 Cross Entropy를 내부적으로 어떻게 계산하는지는 알지 못한다.

따라서 이번 절에서는 **Softmax Regression을 처음부터 직접 구현(From Scratch)** 하여, 분류 모델이 어떻게 확률을 계산하고 학습하는지 이해하는 것이 목표이다.

이를 통해 Classification 모델의 전체 학습 과정을 직접 구현하고, 이후 PyTorch의 고수준 API를 사용할 때 내부 동작 원리를 쉽게 이해할 수 있다.

---

## 핵심 아이디어

> **Linear Regression을 Classification 문제에 적용하기 위해 Softmax와 Cross Entropy Loss를 직접 구현한다.**

전체 학습 과정은 다음과 같다.

```
Input Image
      │
      ▼
Linear Layer
      │
      ▼
Logits
      │
      ▼
Softmax
      │
      ▼
Probability
      │
      ▼
Cross Entropy Loss
      │
      ▼
Gradient Descent
      │
      ▼
Parameter Update
```

Linear Regression과 전체 구조는 동일하지만,

- MSE → Cross Entropy
- 출력값 → 확률(Probability)

로 변경된 것이 가장 큰 차이점이다.

---

## 주요 개념

### 1. Softmax

Softmax는 모델의 출력(Logits)을 각 클래스의 **확률(Probability)** 로 변환하는 함수이다.

각 클래스의 출력값을 모두 더했을 때 합이 항상 **1**이 되도록 정규화한다.

$$
P(y=i)=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

#### 왜 사용하는가?

- 출력을 확률로 해석할 수 있다.
- 여러 클래스 중 가장 가능성이 높은 클래스를 선택할 수 있다.
- Cross Entropy Loss와 함께 사용하기 적합하다.

---

### 2. The Model

Softmax Regression은

$$
z=XW+b
$$

를 먼저 계산하여 **Logits**를 생성한 뒤,

Softmax를 적용하여 최종 확률을 계산한다.

즉,

```
Linear
      ↓
Logits
      ↓
Softmax
      ↓
Probability
```

순서로 동작한다.

#### 왜 Logits를 사용하는가?

- Linear Layer의 출력을 그대로 유지할 수 있다.
- Softmax를 적용하기 전의 정보를 보존한다.
- 대부분의 딥러닝 프레임워크가 동일한 방식을 사용한다.

---

### 3. Cross Entropy Loss

Classification에서는 MSE 대신 **Cross Entropy Loss**를 사용한다.

Cross Entropy는 정답 클래스의 확률이 높을수록 Loss가 작아지고,

낮을수록 Loss가 크게 증가한다.

즉,

모델이 정답을 틀릴수록 더 큰 패널티를 받는다.

#### 왜 사용하는가?

- Classification 문제에 적합하다.
- Gradient 계산이 안정적이다.
- Softmax와 함께 사용할 때 가장 효과적이다.

---

### 4. Training

Training 과정은 Chapter 3과 동일하다.

```
Forward
     │
Loss
     │
Backward
     │
SGD
     │
Repeat
```

Forward에서는

- Linear 계산
- Softmax
- Cross Entropy

를 수행한다.

Backward에서는

Gradient를 계산하여 Weight와 Bias를 업데이트한다.

#### 왜 중요한가?

- 모든 분류 모델이 동일한 학습 구조를 사용한다.
- CNN, ResNet, Transformer도 같은 Training Pipeline을 따른다.

---

### 5. Prediction

Prediction은 Softmax의 출력 중

가장 높은 확률을 가진 클래스를 선택하는 과정이다.

예를 들어

| Class | Probability |
|--------|------------:|
| T-shirt | 0.08 |
| Dress | 0.11 |
| Sneaker | 0.76 |
| Bag | 0.05 |

이라면

최종 Prediction은 **Sneaker**가 된다.

## Linear Regression vs Softmax Regression

| Linear Regression | Softmax Regression |
|-------------------|--------------------|
| Regression | Classification |
| 출력은 실수 | 출력은 확률 |
| MSE Loss | Cross Entropy Loss |
| 하나의 출력값 | 여러 클래스의 확률 |
| 연속적인 값 예측 | 클래스 예측 |
