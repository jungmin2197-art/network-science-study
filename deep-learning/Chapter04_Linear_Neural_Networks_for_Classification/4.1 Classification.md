# 4.1 Classification

> **핵심 키워드:** Classification · Class · Label · Hard Assignment · Soft Assignment · Multi-class Classification

---

## 등장 배경

앞 장에서는 **Linear Regression**을 이용하여 연속적인 값(Continuous Value)을 예측하는 방법을 학습하였다. 하지만 현실의 많은 문제는 숫자를 예측하는 것이 아니라 **어떤 범주(Category)에 속하는지 판단하는 문제**이다.

예를 들어

- 이메일이 **스팸**인지 아닌지
- 이미지가 **고양이**, **강아지**, **자동차** 중 무엇인지
- 고객이 서비스를 **구매할 가능성이 있는지** 없는지

와 같은 문제는 모두 **Classification(분류)** 문제에 해당한다.

즉, Regression이 **"얼마나(How much?)"** 를 예측하는 문제라면, Classification은 **"무엇인가(Which class?)"** 를 예측하는 문제이다.

---

## 핵심 아이디어

> **입력 데이터를 미리 정의된 여러 클래스(Class) 중 하나로 분류하는 것이 Classification의 목표이다.**

Classification에서는 출력이 하나의 연속적인 숫자가 아니라 여러 클래스 중 하나가 된다.

예를 들어 숫자 손글씨를 분류한다면

```
입력 이미지
      │
      ▼
Neural Network
      │
      ▼
[0] [1] [2] ... [9]
```

모델은 각 클래스에 대한 가능성을 계산한 뒤 가장 높은 값을 가진 클래스를 최종 예측으로 선택한다.

---

## 주요 개념

### 1. Classification

Classification은 입력 데이터를 하나 이상의 **Class(범주)** 로 분류하는 머신러닝 문제이다.

Regression과 달리 출력값은 연속적인 숫자가 아니라 **이산적인 클래스(Label)** 이다.

#### 왜 사용하는가?

- 범주를 예측하는 문제를 해결하기 위해
- 실제 AI 서비스의 대부분이 분류 문제이기 때문
- 이미지, 음성, 자연어 처리 등 다양한 분야에서 사용된다.

---

### 2. Class와 Label

- **Class** : 모델이 예측해야 하는 범주
- **Label** : 각 데이터가 실제로 속하는 정답 클래스

예를 들어

| 이미지 | Label |
|---------|-------|
| 🐱 | Cat |
| 🐶 | Dog |
| 🚗 | Car |

모델은 입력 이미지의 Label을 예측하도록 학습된다.

---

### 3. Hard Assignment

Hard Assignment는 하나의 데이터가 **오직 하나의 클래스에만 속한다고 판단하는 방식**이다.

예를 들어

```
Cat : 0
Dog : 1
Car : 0
```

이라면 최종 결과는 **Dog**이다.

#### 특징

- 가장 높은 확률을 가진 클래스 하나만 선택한다.
- 일반적인 이미지 분류에서 가장 많이 사용된다.

---

### 4. Soft Assignment

Soft Assignment는 각 클래스에 속할 **확률(Probability)** 을 함께 예측하는 방식이다.

예를 들어

| Class | Probability |
|--------|-------------|
| Cat | 0.15 |
| Dog | 0.80 |
| Car | 0.05 |

최종 예측은 Dog이지만, 다른 클래스일 가능성도 함께 표현한다.

#### 왜 사용하는가?

- 모델의 신뢰도를 확인할 수 있다.
- 이후 Softmax와 Cross Entropy Loss의 기반이 된다.

---

### 5. Multi-class Classification

클래스가 두 개 이상인 분류 문제를 의미한다.

예를 들어

- 숫자 인식 (0~9)
- 동물 분류
- 음식 분류

등이 대표적인 예이다.

Classification에서는 모든 클래스 중 가장 적합한 클래스를 선택하는 것이 목표이다.

---

## 장점

- 범주형 데이터를 효과적으로 분류할 수 있다.
- 이미지, 음성, 자연어 처리 등 다양한 AI 분야에 적용된다.
- 확률 기반 예측을 통해 모델의 신뢰도를 함께 확인할 수 있다.
- 대부분의 실제 딥러닝 응용 분야의 기본 문제이다.

---

## 한계

- Regression처럼 연속적인 값을 예측할 수 없다.
- 클래스 수가 많아질수록 모델의 복잡도가 증가한다.
- 클래스 간 데이터 불균형(Class Imbalance)이 발생하면 성능이 저하될 수 있다.
- 서로 비슷한 클래스는 구분하기 어려울 수 있다.

---

## Regression vs Classification

| Regression | Classification |
|------------|----------------|
| 연속적인 값 예측 | 범주(Class) 예측 |
| 출력은 실수값 | 출력은 클래스 |
| MSE Loss 사용 | Cross Entropy Loss 사용 |
| House Price Prediction | Cat vs Dog Classification |
