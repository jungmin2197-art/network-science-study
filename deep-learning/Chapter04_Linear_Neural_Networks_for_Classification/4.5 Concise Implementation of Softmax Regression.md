# 4.5 Concise Implementation of Softmax Regression

> **핵심 키워드:** PyTorch · nn.Linear · CrossEntropyLoss · Softmax Revisited · High-level API

---

## 등장 배경

앞 절에서는 Softmax Regression을 처음부터 직접 구현(From Scratch)하면서 Softmax 함수와 Cross Entropy Loss의 동작 원리를 이해하였다.

하지만 실제 딥러닝 프로젝트에서는 모든 연산을 직접 구현하지 않는다. PyTorch는 모델 정의, Loss 계산, Optimizer 등 대부분의 기능을 이미 구현하여 제공하므로, 개발자는 모델 설계에 더욱 집중할 수 있다.

이번 절에서는 **PyTorch의 High-level API를 이용하여 Softmax Regression을 간결하게 구현하는 방법**을 학습하고, 직접 구현과의 차이를 이해하는 것이 목표이다.

---

## 핵심 아이디어

> **직접 구현을 통해 원리를 이해하고, PyTorch를 이용하여 효율적으로 모델을 구현한다.**

Softmax Regression을 구성하는 대부분의 기능은 PyTorch에서 이미 제공한다.

| From Scratch | PyTorch |
|:-------------|:---------|
| Weight 직접 생성 | `nn.Linear` |
| Softmax 구현 | `CrossEntropyLoss` 내부 처리 |
| Cross Entropy 구현 | `nn.CrossEntropyLoss()` |
| SGD 구현 | `torch.optim.SGD()` |

즉, 모델의 학습 원리는 동일하지만 구현 과정이 훨씬 단순해진다.

---

## 주요 개념

### 1. Defining the Model

PyTorch에서는 `nn.Linear`를 이용하여 Softmax Regression을 구현한다.

Linear Layer는 입력 데이터를 각 클래스의 **Logits**로 변환하는 역할을 한다.

#### 왜 사용하는가?

- Weight와 Bias를 자동으로 생성한다.
- Forward 연산을 직접 구현할 필요가 없다.
- 다양한 분류 모델에서도 동일하게 사용할 수 있다.

---

### 2. Softmax Revisited

PyTorch에서는 **Softmax를 직접 호출하지 않는다.**

`nn.CrossEntropyLoss()`는 내부적으로

- Softmax
- Log 연산
- Cross Entropy 계산

을 모두 수행한다.

즉,

```
Logits
    │
CrossEntropyLoss
```

만으로 학습이 가능하다.

#### 왜 Softmax를 직접 사용하지 않는가?

- 계산 과정이 더욱 안정적이다.
- 수치적인 오차(Numerical Instability)를 줄일 수 있다.
- 불필요한 연산을 방지할 수 있다.

> **실무에서는 `CrossEntropyLoss`를 사용할 경우 Softmax를 별도로 적용하지 않는 것이 원칙이다.**

---

### 3. Training

Training 과정은 이전 장과 동일하다.

```
Input
   │
Forward
   │
Loss
   │
Backward
   │
Optimizer Step
   │
Repeat
```

PyTorch는 자동 미분(Autograd)을 제공하므로 Gradient를 직접 계산할 필요가 없다.

#### 왜 사용하는가?

- 코드가 매우 간결해진다.
- 구현 오류를 줄일 수 있다.
- 다양한 Optimizer를 쉽게 적용할 수 있다.

---

## From Scratch vs PyTorch

| From Scratch | PyTorch |
|:-------------|:---------|
| Softmax 직접 구현 | 내부적으로 자동 처리 |
| Cross Entropy 직접 구현 | `CrossEntropyLoss` 사용 |
| Weight 직접 생성 | `nn.Linear` 사용 |
| 교육 목적에 적합 | 실제 프로젝트에 적합 |

---

## 장점

- 코드가 매우 간결하다.
- 구현 오류를 줄일 수 있다.
- 자동 미분(Autograd)을 활용할 수 있다.
- 다양한 모델과 Optimizer를 쉽게 적용할 수 있다.
- 실제 연구 및 산업 환경에서 사용하는 방식과 동일하다.

## 한계

- 내부 동작을 이해하지 않으면 단순히 API만 사용하는 수준에 머무를 수 있다.
- 디버깅이 필요한 경우 내부 구조를 이해해야 한다.
- 추상화 수준이 높아 처음에는 동작 원리를 파악하기 어렵다.
