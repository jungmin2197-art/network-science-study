# 4.2 The Image Classification Dataset

> **핵심 키워드:** Fashion-MNIST · Dataset · DataLoader · Mini-batch · Visualization

---

## 등장 배경

앞 절에서는 Softmax Regression을 이용하여 Classification 문제를 해결하는 방법을 학습하였다.

하지만 아무리 좋은 모델이라도 학습에 사용할 데이터가 없다면 의미가 없다. 따라서 이번 절에서는 **이미지 분류(Image Classification)** 를 위한 대표적인 데이터셋인 **Fashion-MNIST**를 이용하여 데이터를 불러오고, 모델이 학습할 수 있는 형태로 구성하는 방법을 학습한다.

또한 데이터를 효율적으로 관리하기 위해 **DataLoader**, **Mini-batch**, **Visualization**의 개념도 함께 이해한다.

---

## 핵심 아이디어

> **이미지 데이터를 모델이 바로 사용할 수 있는 Tensor 형태로 변환하고, Mini-batch 단위로 효율적으로 전달한다.**

전체 과정은 다음과 같다.

```
Fashion-MNIST Dataset
        │
        ▼
Load Dataset
        │
        ▼
Transform (Resize, Tensor)
        │
        ▼
DataLoader
        │
        ▼
Mini-batch
        │
        ▼
Model Training
```

즉, 모델을 설계하기 전에 데이터를 올바르게 준비하는 과정이 먼저 이루어진다.

---

## 주요 개념

### 1. Fashion-MNIST Dataset

Fashion-MNIST는 의류 이미지를 이용한 이미지 분류 데이터셋이다.

총 10개의 의류 클래스로 구성되어 있으며,

- Training Dataset : 60,000장
- Test Dataset : 10,000장

의 Grayscale 이미지를 제공한다.

대표 클래스는 다음과 같다.

- T-shirt
- Trouser
- Pullover
- Dress
- Coat
- Sandal
- Shirt
- Sneaker
- Bag
- Ankle Boot

#### 왜 사용하는가?

- MNIST보다 조금 더 현실적인 이미지 분류 문제를 제공한다.
- 데이터 크기가 적당하여 학습 속도가 빠르다.
- CNN 등 다양한 모델의 성능을 비교하는 기준(Benchmark)으로 많이 사용된다.

---

### 2. Data Loading

PyTorch에서는 `torchvision.datasets.FashionMNIST`를 이용하여 데이터를 쉽게 불러올 수 있다.

데이터를 불러오는 과정에서

- Resize
- Tensor 변환
- Train/Test 분리

가 함께 수행된다.

#### 왜 사용하는가?

- 데이터를 자동으로 다운로드하고 관리할 수 있다.
- 동일한 방식으로 다양한 데이터셋을 사용할 수 있다.
- 반복적인 전처리 코드를 줄일 수 있다.

---

### 3. DataLoader

DataLoader는 Dataset을 Mini-batch 단위로 모델에 전달하는 역할을 한다.

또한 학습 데이터는 Shuffle하여 모델이 특정 데이터 순서에 의존하지 않도록 한다.

#### 왜 사용하는가?

- 메모리 사용량을 줄일 수 있다.
- Mini-batch Learning을 수행할 수 있다.
- 데이터를 자동으로 반복하여 읽을 수 있다.
- 대용량 데이터도 효율적으로 처리할 수 있다.

---

### 4. Mini-batch

Mini-batch는 전체 데이터 중 일정 개수만 선택하여 한 번의 학습을 수행하는 방식이다.

예를 들어 Batch Size가 64라면

```
64 Images
      │
      ▼
Forward
      ▼
Loss
      ▼
Backward
      ▼
Weight Update
```

를 반복하게 된다.

#### 왜 사용하는가?

- Full Batch보다 계산 속도가 빠르다.
- SGD보다 Gradient가 안정적이다.
- GPU 병렬 연산을 효율적으로 활용할 수 있다.

---

### 5. Visualization

모델을 학습하기 전에 데이터를 직접 확인하는 과정이다.

이미지와 Label을 함께 출력하여

- 데이터가 정상적으로 불러와졌는지
- Label이 올바른지
- 전처리가 제대로 수행되었는지

확인할 수 있다.

#### 왜 사용하는가?

- 데이터 오류를 미리 발견할 수 있다.
- 잘못된 Label이나 전처리 문제를 쉽게 확인할 수 있다.
- 학습 전에 데이터의 특징을 이해할 수 있다.

---

## 장점

- Fashion-MNIST는 가볍고 사용하기 쉬운 Benchmark Dataset이다.
- DataLoader를 이용하면 데이터 관리를 자동화할 수 있다.
- Mini-batch를 통해 효율적인 학습이 가능하다.
- Visualization을 통해 데이터 품질을 쉽게 확인할 수 있다.
- 이후 CNN, ResNet, Vision Transformer 등에서도 동일한 데이터 처리 방식을 사용할 수 있다.

---

## 한계

- Fashion-MNIST는 단순한 흑백 이미지이므로 실제 이미지보다 난이도가 낮다.
- 클래스 수가 10개로 제한되어 있다.
- 실제 이미지 데이터(ImageNet, COCO 등)에 비해 규모가 매우 작다.
- 실제 환경의 복잡한 배경이나 다양한 객체를 포함하지 않는다.
