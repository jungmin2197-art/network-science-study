# 8.3 Network in Network (NiN)

## 논문

**Network In Network**

- Min Lin
- Qiang Chen
- Shuicheng Yan

ICLR 2014

---

# 왜 등장했는가?

AlexNet과 VGG는 뛰어난 성능을 보였지만 몇 가지 한계가 존재하였다.

- Fully Connected Layer의 Parameter가 매우 많음
- Overfitting 발생
- Feature 표현력이 제한적
- Convolution Layer가 단순한 선형 필터 역할만 수행

NiN(Network in Network)은 이러한 문제를 해결하기 위해 **Convolution Layer 자체의 표현력을 높이고, Fully Connected Layer를 제거하는 새로운 CNN 구조**를 제안하였다.

---

# 기존 CNN의 한계

기존 CNN에서는 하나의 Convolution Filter가 단순히 선형 연산을 수행하였다.

즉,

```
Input

↓

Convolution

↓

ReLU
```

구조만 반복하였다.

하지만 이는 Feature를 충분히 복잡하게 표현하는 데 한계가 있었다.

또한 마지막의 Fully Connected Layer는 대부분의 Parameter를 차지하여 Overfitting의 주요 원인이 되었다.

---

# 핵심 아이디어

NiN의 핵심 아이디어는 크게 두 가지이다.

- MLPConv (Multi-Layer Perceptron Convolution)
- Global Average Pooling(GAP)

즉,

> **Convolution 자체를 더 강력하게 만들고, Fully Connected Layer를 제거하자.**

---

# NiN Block

기존 CNN Block은

```text
Conv

↓

ReLU
```

였다.

NiN은 이를

```text
Conv

↓

ReLU

↓

1×1 Conv

↓

ReLU

↓

1×1 Conv

↓

ReLU
```

로 변경하였다.

즉 하나의 Convolution 뒤에 여러 개의 **1×1 Convolution(MLP)** 을 추가하여 Feature를 더욱 복잡하게 학습한다.

---

# MLPConv

NiN의 가장 중요한 아이디어는 **MLPConv**이다.

기존 CNN에서는 하나의 Filter가 선형 변환만 수행하였다.

NiN에서는

```text
Conv

↓

1×1 Conv

↓

1×1 Conv
```

처럼 작은 다층 퍼셉트론(MLP)을 삽입하였다.

이를 통해 Feature의 비선형 표현 능력이 크게 향상되었다.

---

# 1×1 Convolution

처음 보면

> "1×1인데 무슨 의미가 있지?"

라는 생각이 들 수 있다.

하지만 1×1 Convolution은

- Channel 간 정보를 학습
- Feature를 조합
- Parameter 감소
- 계산량 감소

라는 매우 중요한 역할을 수행한다.

예를 들어

```
32 × 32 × 256
```

Feature Map이 있다면

1×1 Conv를 사용하여

```
32 × 32 × 128
```

처럼 Channel 수를 줄일 수 있다.

즉,

공간 크기는 유지하면서 Feature를 새롭게 조합하는 역할을 한다.

---

# Global Average Pooling (GAP)

NiN은 Fully Connected Layer 대신

**Global Average Pooling**을 사용하였다.

기존 CNN은

```text
Feature Map

↓

Flatten

↓

Fully Connected

↓

Softmax
```

를 사용하였다.

NiN은

```text
Feature Map

↓

Global Average Pooling

↓

Softmax
```

를 사용한다.

즉 Feature Map 전체의 평균값을 계산하여 하나의 값을 생성한다.

---

# 왜 GAP를 사용할까?

Global Average Pooling은

- Fully Connected Layer 제거
- Parameter 감소
- Overfitting 감소
- 구조 단순화

라는 장점을 가진다.

현재 대부분의 CNN에서도 마지막 Layer에 GAP가 사용된다.

---

# NiN 구조

대표적인 NiN 구조는 다음과 같다.

```text
Input

↓

NiN Block

↓

Max Pooling

↓

NiN Block

↓

Max Pooling

↓

NiN Block

↓

Global Average Pooling

↓

Softmax
```

---

# 장점

- Convolution의 표현력 증가
- Fully Connected Layer 제거
- Parameter 감소
- Overfitting 감소
- 1×1 Convolution 활용

---

# 한계

- 매우 깊은 Network 학습은 여전히 어려움
- Residual Connection이 없어 Gradient Vanishing 문제가 존재
- 이후 ResNet보다 성능이 낮음

---

# 후속 연구에 미친 영향

NiN은 현대 CNN에 매우 큰 영향을 미쳤다.

특히

- GoogLeNet의 1×1 Convolution
- ResNet의 Bottleneck Block
- DenseNet
- MobileNet

등 대부분의 CNN에서 **1×1 Convolution**이 핵심 요소로 사용된다.

또한 **Global Average Pooling** 역시 현대 CNN의 표준 구조가 되었다.

---

# 내가 이해한 내용

NiN은 단순히 새로운 CNN 모델이 아니라 **Convolution Layer의 표현력을 높이는 방법**을 제안한 모델이라고 이해할 수 있다.

특히 **1×1 Convolution**을 이용하여 Channel 간 정보를 학습하고, **Global Average Pooling**을 통해 Fully Connected Layer를 제거함으로써 Parameter를 줄이고 Overfitting을 완화하였다.

현재 대부분의 CNN 구조에서 사용되는 **1×1 Convolution**과 **Global Average Pooling**은 모두 NiN에서 시작된 중요한 아이디어이다.
