# 왜 등장했는가?

CNN은 AlexNet, VGG를 거치면서 점점 깊어졌지만, Layer를 계속 추가한다고 해서 성능이 항상 좋아지는 것은 아니었다.

오히려 일정 깊이를 넘어서면 학습이 어려워지고 정확도가 감소하는 **Degradation Problem**이 발생하였다.

ResNet은 이러한 문제를 해결하기 위해 **Residual Learning**이라는 새로운 학습 방식을 제안하였다.

---

# 기존 Deep CNN의 한계

Layer를 계속 추가하면 다음과 같은 문제가 발생하였다.

- Gradient Vanishing
- 학습 속도 저하
- Degradation Problem
- 매우 깊은 Network 학습 어려움

특히 Degradation Problem은 Overfitting 때문이 아니라 **깊은 Network 자체를 최적화하기 어려운 문제**이다.

---

# Degradation Problem

일반적으로

```
20 Layer
```

보다

```
56 Layer
```

가 더 좋은 성능을 낼 것이라고 생각한다.

하지만 실제로는

```
20 Layer

↓

Training Error 낮음

56 Layer

↓

Training Error 증가
```

하는 현상이 발생한다.

즉,

Layer를 더 많이 추가했는데도 학습 자체가 잘 되지 않는다.

---

# 핵심 아이디어

ResNet의 핵심은 매우 단순하다.

> **원래 입력을 그대로 다음 Layer로 전달하자.**

이를 **Skip Connection** 또는 **Shortcut Connection**이라고 한다.

---

# Residual Learning

기존 CNN은

```
Input

↓

F(x)

↓

Output
```

을 학습한다.

ResNet은

```
Input
   │
   │──────────────┐
   ▼              │
 F(x)             │
   │              │
   └───────＋─────┘
          ▼
       Output
```

즉,

최종 출력은

$$
H(x)=F(x)+x
$$

가 된다.

여기서

- x : 입력
- F(x) : Residual Function

이다.

---

# 왜 Residual을 학습할까?

기존에는

```
Output = H(x)
```

전체를 학습하였다.

ResNet은

```
Output = x + F(x)
```

만 학습한다.

즉,

원래 입력은 그대로 전달하고

**변화해야 하는 부분만 학습**한다.

그래서 Optimization이 훨씬 쉬워진다.

---

# Residual Block

ResNet의 기본 Block은 다음과 같다.

```
Input
   │
Conv
   │
BatchNorm
   │
ReLU
   │
Conv
   │
BatchNorm
   │
＋ Shortcut
   │
ReLU
```

이 구조를 반복하여 매우 깊은 Network를 구성한다.

---

# Skip Connection

Skip Connection은

입력을 여러 Layer를 건너뛰어(Output에) 더하는 구조이다.

```
Input
 │
 ├───────────────┐
 │               │
Conv → Conv      │
 │               │
 └──────＋────────┘
```

이를 통해

- Gradient 전달
- 정보 손실 감소
- 깊은 Network 학습

이 가능해진다.

---

# Bottleneck Block

깊은 ResNet(50, 101, 152 Layer)은

다음 구조를 사용한다.

```
1×1 Conv

↓

3×3 Conv

↓

1×1 Conv
```

첫 번째 1×1 Conv는

Channel 수를 줄이고,

마지막 1×1 Conv는

Channel 수를 다시 늘린다.

이를 통해

Parameter와 계산량을 크게 줄일 수 있다.

---

# ResNeXt

ResNeXt는 ResNet을 더욱 발전시킨 모델이다.

기존 ResNet은 하나의 경로에서 Feature를 학습하였다.

ResNeXt는

```
Input

↓

여러 개의 Residual Branch

↓

Aggregation

↓

Output
```

처럼 여러 Branch를 동시에 학습한다.

이를 **Cardinality**라고 한다.

---

# Cardinality

ResNeXt는

Depth나 Width를 증가시키는 대신

**Branch의 개수(Cardinality)** 를 증가시켰다.

즉

```
Branch 1

Branch 2

Branch 3

...

Branch N
```

을 동시에 학습한 후

결과를 합친다.

논문에서는

Cardinality 증가가 성능 향상에 매우 효과적임을 보여주었다.

---

# 장점

- 매우 깊은 Network 학습 가능
- Gradient Vanishing 완화
- Optimization 개선
- 뛰어난 ImageNet 성능
- 다양한 Vision 모델의 Backbone으로 사용

---

# 한계

- 구조가 VGG보다 복잡하다.
- Layer 수가 많아 학습 시간이 길다.
- 메모리 사용량 증가

---

# 후속 연구에 미친 영향

ResNet은 현대 Computer Vision의 가장 중요한 Backbone 중 하나이다.

현재

- Faster R-CNN
- Mask R-CNN
- YOLO
- PSPNet
- DeepLab
- DETR

등 대부분의 Vision 모델에서 ResNet Backbone이 사용되었다.

또한

- DenseNet
- ResNeXt
- EfficientNet

등 다양한 CNN 구조의 기반이 되었다.

---

# 내가 이해한 내용

ResNet은 단순히 Layer를 많이 쌓은 모델이 아니라 **Residual Learning을 통해 매우 깊은 Network도 안정적으로 학습할 수 있도록 만든 모델**이다.

가장 중요한 아이디어는 Skip Connection을 이용하여 입력을 그대로 다음 Layer에 전달하고, 새로운 Feature(F(x))만 학습하는 것이다.

또한 ResNeXt는 이러한 Residual Block을 여러 Branch로 확장하여 Cardinality라는 새로운 개념을 도입하였으며, 더 높은 성능을 달성하였다.
