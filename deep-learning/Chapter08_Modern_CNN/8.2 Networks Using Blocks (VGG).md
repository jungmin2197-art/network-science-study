# 8.2 Networks Using Blocks (VGG)

## 논문

**Very Deep Convolutional Networks for Large-Scale Image Recognition (VGG)**

- Karen Simonyan
- Andrew Zisserman

ICLR 2015

---

# 왜 등장했는가?

AlexNet은 Deep CNN의 가능성을 입증하였지만 여전히 몇 가지 한계가 존재하였다.

- 큰 Convolution Kernel(11×11, 5×5) 사용
- 네트워크가 충분히 깊지 않음
- 모델 설계가 다소 복잡함

VGG는 **작은 Convolution Kernel을 반복적으로 사용하여 더 깊은 CNN을 만드는 것이 성능 향상에 효과적**이라는 아이디어를 제안하였다.

---

# AlexNet의 한계

AlexNet은 당시 뛰어난 성능을 보였지만 다음과 같은 문제가 있었다.

- 큰 Kernel 사용으로 Parameter 수 증가
- Feature를 세밀하게 추출하기 어려움
- Layer 수가 충분히 깊지 않음
- 네트워크 구조가 일정하지 않음

VGG는 이러한 문제를 해결하기 위해 매우 단순하면서도 깊은 CNN 구조를 설계하였다.

---

# 핵심 아이디어

VGG의 핵심은 매우 단순하다.

> **큰 Convolution 대신 여러 개의 작은 3×3 Convolution을 연속적으로 사용하자.**

이를 통해

- 더 깊은 네트워크 구성
- 더 많은 Non-linearity(ReLU)
- 더 작은 Parameter
- 더 높은 표현력

을 얻을 수 있었다.

---

# VGG Block

VGG는 동일한 구조를 반복하는 **VGG Block**으로 구성된다.

대표적인 Block은 다음과 같다.

```text
Conv 3×3

↓

ReLU

↓

Conv 3×3

↓

ReLU

↓

Max Pooling
```

또는

```text
Conv

↓

ReLU

↓

Conv

↓

ReLU

↓

Conv

↓

ReLU

↓

Max Pooling
```

이 Block을 반복해서 깊은 네트워크를 구성한다.

---

# VGG 구조

대표적인 VGG-16 구조는 다음과 같다.

```text
Input

↓

Conv Block

↓

Conv Block

↓

Conv Block

↓

Conv Block

↓

Conv Block

↓

FC

↓

FC

↓

Softmax
```

VGG-16은

- 13개의 Convolution Layer
- 3개의 Fully Connected Layer

로 구성되어 총 **16개의 학습 가능한 Layer**를 가진다.

---

# 왜 3×3 Kernel을 사용할까?

큰 Kernel 하나를 사용하는 것보다 작은 Kernel 여러 개를 사용하는 것이 더 효율적이다.

예를 들어

```text
7×7 Conv
```

대신

```text
3×3

↓

3×3

↓

3×3
```

를 사용하면

동일한 Receptive Field를 가지면서

- Parameter 감소
- ReLU 증가
- 표현력 증가

라는 장점을 얻을 수 있다.

예를 들어

7×7 Kernel

```
Parameter

49
```

3×3 Kernel 3개

```
Parameter

9 + 9 + 9 = 27
```

즉 더 적은 Parameter로 비슷한 효과를 얻을 수 있다.

---

# Representation Learning

VGG 역시 Layer가 깊어질수록 더 추상적인 특징을 학습한다.

```text
Input

↓

Edge

↓

Texture

↓

Shape

↓

Object Parts

↓

Object
```

하지만 AlexNet보다 Layer가 훨씬 깊기 때문에 더욱 복잡한 특징을 학습할 수 있다.

---

# 장점

- 매우 단순한 구조
- 구현이 쉽다.
- 깊은 Network 구성 가능
- 작은 Kernel을 사용하여 Parameter를 줄임
- 뛰어난 ImageNet 성능

---

# 한계

VGG는 성능은 뛰어나지만 계산량이 매우 크다.

대표적인 문제는 다음과 같다.

- Parameter가 매우 많음
- Fully Connected Layer가 큼
- 메모리 사용량 증가
- 학습 시간이 오래 걸림

특히 VGG-16은 약 **1억 3천만 개 이상의 Parameter**를 가진다.

이러한 문제를 해결하기 위해 이후 GoogLeNet과 ResNet이 등장하였다.

---

# AlexNet과의 차이

| AlexNet | VGG |
|----------|-----|
| 큰 Kernel 사용 | 작은 3×3 Kernel 반복 |
| 8 Layer | 16~19 Layer |
| 구조가 복잡함 | 매우 규칙적인 구조 |
| 상대적으로 얕음 | 매우 깊음 |
| 성능 향상 시작 | 깊은 CNN의 표준 제시 |

---

# 후속 연구에 미친 영향

VGG는 CNN 설계에서 **Block 구조**라는 개념을 널리 사용하게 만든 모델이다.

이후

- ResNet
- DenseNet
- U-Net
- Faster R-CNN

등 수많은 Computer Vision 모델이 VGG의 Block 구조를 기반으로 발전하였다.

---

# 내가 이해한 내용

VGG는 AlexNet보다 훨씬 단순한 구조를 사용하면서도 더 깊은 네트워크를 구성하였다. 가장 중요한 아이디어는 **큰 Convolution을 사용하는 것보다 작은 3×3 Convolution을 여러 번 쌓는 것이 더 효율적**이라는 점이다.

또한 이후 등장한 대부분의 CNN이 Block 단위로 네트워크를 설계하게 된 계기를 마련한 모델이라고 이해할 수 있다.
