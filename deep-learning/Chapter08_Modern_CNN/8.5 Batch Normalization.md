# 8.5 Batch Normalization

## 논문

**Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift**

- Sergey Ioffe
- Christian Szegedy

ICML 2015

---

# 왜 등장했는가?

CNN이 점점 깊어질수록 학습이 어려워지는 문제가 발생하였다.

대표적인 문제는 다음과 같다.

- Gradient Vanishing
- Gradient Exploding
- 느린 학습 속도
- Weight Initialization에 민감
- Learning Rate를 크게 설정하기 어려움

Batch Normalization(BN)은 이러한 문제를 해결하여 **깊은 신경망을 더 빠르고 안정적으로 학습하기 위해** 제안되었다.

---

# 기존 Deep Network의 문제

Deep Network에서는 Layer가 업데이트될 때마다 다음 Layer의 입력 분포도 함께 변한다.

즉,

```
Input

↓

Layer 1 (변경)

↓

Layer 2의 입력도 계속 변함

↓

Layer 3의 입력도 계속 변함
```

이러한 현상을 논문에서는 **Internal Covariate Shift**라고 설명하였다.

입력 분포가 계속 변하면 각 Layer는 매번 새로운 분포에 적응해야 하므로 학습 속도가 느려지고 불안정해진다.

---

# 핵심 아이디어

Batch Normalization의 핵심은 매우 단순하다.

> **각 Mini-batch의 Feature를 평균 0, 분산 1로 정규화하여 입력 분포를 안정화하자.**

즉,

```
Feature

↓

Normalize

↓

Scale

↓

Shift

↓

다음 Layer
```

과정을 거친다.

---

# Batch Normalization 과정

Batch의 입력을

```
x
```

라고 하면

먼저 Batch 평균을 계산한다.

$$
\mu_B=\frac{1}{m}\sum_{i=1}^{m}x_i
$$

---

Batch 분산을 계산한다.

$$
\sigma_B^2=\frac{1}{m}\sum_{i=1}^{m}(x_i-\mu_B)^2
$$

---

평균이 0, 분산이 1이 되도록 정규화한다.

$$
\hat{x_i}=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}
$$

---

마지막으로 학습 가능한 Parameter를 이용하여 다시 변환한다.

$$
y_i=\gamma\hat{x_i}+\beta
$$

여기서

- γ(Gamma) : Scale
- β(Beta) : Shift

를 의미한다.

즉 BN은 단순히 정규화만 하는 것이 아니라 필요한 값으로 다시 학습할 수 있다.

---

# Batch Normalization은 어디에 넣을까?

일반적으로

```
Convolution

↓

BatchNorm

↓

ReLU
```

순서로 사용한다.

또는

```
Linear

↓

BatchNorm

↓

Activation
```

순서로 사용된다.

---

# BatchNorm의 장점

## 1. 학습 속도 향상

입력 분포가 안정되어 더 빠르게 수렴한다.

---

## 2. Gradient Vanishing 완화

깊은 Network에서도 Gradient가 안정적으로 전달된다.

---

## 3. 큰 Learning Rate 사용 가능

학습이 안정적이므로 더 큰 Learning Rate를 사용할 수 있다.

---

## 4. Weight Initialization 영향 감소

초기 Weight에 덜 민감해진다.

---

## 5. Regularization 효과

Mini-batch마다 평균과 분산이 조금씩 달라지므로 약간의 Regularization 효과도 얻을 수 있다.

Dropout 없이도 좋은 성능을 보이는 경우가 많다.

---

# BatchNorm의 한계

- Mini-batch 크기에 영향을 받는다.
- Batch Size가 매우 작으면 성능이 떨어질 수 있다.
- RNN에는 적용하기 어렵다.

이러한 문제를 해결하기 위해

- Layer Normalization
- Instance Normalization
- Group Normalization

등이 제안되었다.

---

# BatchNorm과 Dropout

| Batch Normalization | Dropout |
|--------------------|----------|
| 입력 분포 안정화 | Overfitting 감소 |
| 학습 속도 향상 | 일반화 성능 향상 |
| Gradient 안정화 | 뉴런 일부 제거 |
| 대부분 CNN에서 사용 | 최근 CNN에서는 사용 빈도 감소 |

---

# 후속 연구에 미친 영향

Batch Normalization은 현대 Deep Learning에서 가장 널리 사용되는 기술 중 하나이다.

현재 대부분의 모델에서 기본적으로 사용된다.

- ResNet
- DenseNet
- EfficientNet
- MobileNet
- YOLO

등 거의 모든 CNN 구조에서 Batch Normalization을 사용한다.

---

# 내가 이해한 내용

Batch Normalization은 단순히 데이터를 정규화하는 기법이 아니라 **각 Layer의 입력 분포를 안정적으로 유지하여 깊은 신경망이 빠르고 안정적으로 학습될 수 있도록 만드는 기술**이다.

또한 BatchNorm 덕분에 더 깊은 CNN을 효과적으로 학습할 수 있게 되었으며, 이후 등장한 대부분의 현대 CNN 구조에서 기본 구성 요소로 사용되고 있다.
