# 8.7 Densely Connected Networks (DenseNet)

## 논문

**Densely Connected Convolutional Networks**

- Gao Huang
- Zhuang Liu
- Laurens van der Maaten
- Kilian Q. Weinberger

CVPR 2017

---

# 왜 등장했는가?

ResNet은 Skip Connection을 이용하여 매우 깊은 CNN을 효과적으로 학습할 수 있게 하였지만, Feature를 충분히 재사용하지 못하는 한계가 있었다.

DenseNet은 이러한 문제를 해결하기 위해 **모든 이전 Layer의 Feature를 이후 Layer에서 직접 사용할 수 있도록 하는 Dense Connection**을 제안하였다.

---

# ResNet의 한계

ResNet은 이전 Layer의 출력을 Skip Connection으로 더해준다.

```
Input

↓

Conv

↓

+

↓

Output
```

하지만 이전 Layer의 Feature가 계속 더해지는 과정에서 일부 정보가 희석될 수 있으며, 모든 Layer의 Feature를 직접 활용하지는 못한다.

---

# 핵심 아이디어

DenseNet의 핵심은 매우 단순하다.

> **모든 이전 Layer의 Feature를 이후 Layer의 입력으로 사용하자.**

즉,

각 Layer는 바로 이전 Layer뿐 아니라 모든 이전 Layer의 Feature Map을 입력으로 받는다.

---

# Dense Connection

ResNet은

```
x

↓

F(x)

↓

x + F(x)
```

를 사용하였다.

DenseNet은

```
Layer1

↓

Layer2

↓

Layer3

↓

Layer4
```

가 아니라

```
Layer1 ───────────────┐
   │                  │
   ▼                  │
Layer2 ───────────┐   │
   │              │   │
   ▼              ▼   ▼
Layer3 ───────────────┐
   │                  │
   ▼                  ▼
Layer4
```

처럼 모든 Layer가 서로 연결된다.

---

# Dense Block

DenseNet의 기본 구조는 Dense Block이다.

```
Input

↓

Conv

↓

Concatenate

↓

Conv

↓

Concatenate

↓

Conv

↓

Concatenate
```

각 Layer의 출력은 다음 Layer에서 모두 사용된다.

즉,

Addition이 아니라 **Concatenation**을 사용한다.

---

# Concatenation

ResNet은

```
Output

=

x + F(x)
```

처럼 더하기(Addition)를 수행한다.

DenseNet은

```
Output

=

[x0, x1, x2, ..., xn]
```

처럼 Channel 방향으로 Feature를 이어 붙인다(Concatenate).

즉,

이전 Feature를 그대로 보존하면서 새로운 Feature를 추가한다.

---

# Feature Reuse

DenseNet의 가장 중요한 개념은 Feature Reuse이다.

예를 들어

초기 Layer에서 학습한 Edge 정보가 있다면,

기존 CNN에서는 여러 Layer를 거치면서 점차 희미해질 수 있다.

DenseNet에서는

모든 Layer가 초기 Layer의 Feature를 직접 사용할 수 있다.

따라서

- Edge
- Texture
- Shape

등의 정보를 계속 활용할 수 있다.

---

# Growth Rate

DenseNet에서는

각 Layer가 추가하는 새로운 Feature Map의 개수를 **Growth Rate(k)** 라고 한다.

예를 들어

```
Growth Rate = 32
```

라면

각 Layer는 새로운 Feature Map 32개만 생성하고,

기존 Feature는 그대로 재사용한다.

이를 통해 Parameter를 효율적으로 사용할 수 있다.

---

# Transition Layer

Dense Connection을 계속 사용하면 Feature Map 수가 매우 커진다.

이를 해결하기 위해 DenseNet은 **Transition Layer**를 사용한다.

Transition Layer는

```
1×1 Convolution

↓

Average Pooling
```

으로 구성되며,

- Channel 수 감소
- Feature Map 크기 감소

역할을 수행한다.

---

# DenseNet 구조

대표적인 DenseNet은 다음과 같이 구성된다.

```
Input

↓

Conv

↓

Dense Block

↓

Transition Layer

↓

Dense Block

↓

Transition Layer

↓

Dense Block

↓

Global Average Pooling

↓

Softmax
```

---

# 장점

- Feature Reuse 가능
- Gradient 전달이 매우 원활함
- Parameter 효율이 높음
- 깊은 Network 학습 가능
- 높은 성능

---

# 한계

- Dense Connection으로 메모리 사용량 증가
- Feature Map 저장 비용 증가
- 구현이 복잡함

---

# ResNet과 비교

| ResNet | DenseNet |
|---------|-----------|
| Addition 사용 | Concatenation 사용 |
| 이전 Layer만 연결 | 모든 이전 Layer 연결 |
| Skip Connection | Dense Connection |
| Residual Learning | Feature Reuse |

---

# 후속 연구에 미친 영향

DenseNet은 Feature Reuse라는 새로운 개념을 제안하였다.

이후

- EfficientNet
- Dense Prediction Network
- Medical Image Segmentation
- Semantic Segmentation

등 다양한 Vision 모델에 Dense Connection이 활용되었다.

또한 Feature 재사용이라는 아이디어는 현대 CNN 설계에도 큰 영향을 미쳤다.

---

# 내가 이해한 내용

DenseNet은 ResNet처럼 Gradient 문제를 해결하는 것에서 한 걸음 더 나아가 **모든 Layer가 이전 Layer들의 Feature를 직접 사용할 수 있도록 만든 모델**이다.

ResNet은 입력과 출력을 더하는(Addition) 방식이지만, DenseNet은 모든 이전 Feature를 이어 붙이는(Concatenation) 방식을 사용한다.

이를 통해 Feature를 재사용하고 Gradient 전달을 더욱 원활하게 만들어 적은 Parameter로도 높은 성능을 달성하였다.
