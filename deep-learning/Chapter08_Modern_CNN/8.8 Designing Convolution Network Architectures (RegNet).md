# 왜 등장했는가?

AlexNet, VGG, GoogLeNet, ResNet, DenseNet 등 다양한 CNN 모델이 등장하면서 성능은 크게 향상되었다.

하지만 대부분의 모델은 연구자의 경험과 직관에 의해 설계되었으며,

- Layer 수
- Channel 수
- Kernel 크기
- Block 구조

등을 시행착오를 통해 결정하였다.

RegNet은 이러한 문제를 해결하기 위해 **좋은 CNN 구조를 체계적으로 설계하는 방법**을 제안하였다.

---

# 기존 CNN 설계의 한계

기존 CNN들은

- 사람이 직접 구조를 설계
- 많은 시행착오 필요
- 설계 원칙이 명확하지 않음
- Architecture Search 비용이 큼

이라는 한계가 있었다.

즉,

좋은 모델은 만들 수 있었지만

**왜 그 구조가 좋은지는 설명하기 어려웠다.**

---

# 핵심 아이디어

RegNet의 핵심은 매우 단순하다.

> **좋은 CNN은 일정한 규칙을 가지는 구조를 가진다.**

즉,

무작정 Layer를 늘리는 것이 아니라

Channel 수가 일정한 규칙에 따라 증가하는 Network가 가장 효율적이라는 것이다.

---

# Network Design Space

논문에서는 먼저

**Design Space**

라는 개념을 제안한다.

Design Space란

> 가능한 CNN 구조들의 집합

을 의미한다.

예를 들어

```
Layer 수

Channel 수

Kernel 크기

Block 개수

Stride
```

등의 조합이 모두 Design Space에 포함된다.

---

# AnyNet

논문에서는 가장 단순한 CNN 구조인

**AnyNet**

부터 시작한다.

AnyNet은

```
Input

↓

Stage1

↓

Stage2

↓

Stage3

↓

Stage4

↓

Classifier
```

형태를 가진 일반적인 CNN이다.

즉,

특정 모델이 아니라

가장 기본적인 CNN 구조이다.

---

# Design Space Exploration

논문에서는

수많은 CNN 구조를 실험하면서

좋은 구조들의 공통점을 분석하였다.

그 결과

Channel 수가 일정한 규칙으로 증가하는 구조가

가장 효율적이라는 사실을 발견하였다.

---

# RegNet

RegNet은

Design Space 분석을 통해 얻은 규칙을 기반으로 설계된 CNN이다.

대표적인 특징은

- 단순한 구조
- 규칙적인 Channel 증가
- 높은 계산 효율
- 뛰어난 정확도

이다.

---

# Stage 구조

RegNet은

ResNet처럼 여러 개의 Stage로 구성된다.

```
Input

↓

Stage 1

↓

Stage 2

↓

Stage 3

↓

Stage 4

↓

Global Average Pooling

↓

Classifier
```

각 Stage에서는

동일한 Block이 반복된다.

---

# RegNet의 특징

## 1. 규칙적인 Channel 증가

기존 CNN은

```
64

↓

128

↓

256

↓

512
```

처럼 경험적으로 결정하였다.

RegNet은

수학적인 규칙을 이용하여

Channel 수를 결정한다.

---

## 2. 단순한 구조

복잡한 Branch나 Dense Connection 없이

단순한 Block 반복만으로도

높은 성능을 얻을 수 있다.

---

## 3. 높은 효율성

Parameter 수와 FLOPs를 줄이면서도

높은 정확도를 달성하였다.

---

# Design Space의 장점

RegNet은

특정 모델 하나를 만드는 것이 아니라

좋은 CNN을 만드는 방법을 제안하였다.

즉,

```
Design Rule

↓

CNN 생성

↓

성능 평가

↓

최적 구조 선택
```

이라는 새로운 접근을 제시하였다.

---

# 장점

- CNN 설계를 체계화
- 높은 계산 효율
- 규칙적인 구조
- 구현이 단순
- 다양한 환경에 적용 가능

---

# 한계

- CNN 기반 설계에 초점
- Vision Transformer에는 직접 적용하기 어려움
- 구조 탐색 과정이 필요

---

# 이전 모델과 비교

| Model | 핵심 아이디어 |
|--------|--------------|
| AlexNet | Deep CNN |
| VGG | 작은 3×3 Kernel |
| NiN | 1×1 Convolution |
| GoogLeNet | Inception Module |
| ResNet | Residual Learning |
| DenseNet | Dense Connection |
| RegNet | CNN Design Methodology |

---

# 후속 연구에 미친 영향

RegNet은 CNN 자체보다

**Architecture Design**이라는 새로운 연구 방향을 제시하였다.

이후

- EfficientNet
- ConvNeXt
- Neural Architecture Search(NAS)

등 다양한 모델 설계 연구에 영향을 주었다.

또한

CNN 구조를 경험이 아닌

설계 원칙에 따라 생성하는 접근의 기반이 되었다.

---

# 내가 이해한 내용

RegNet은 새로운 Convolution 연산이나 Block을 제안한 모델이 아니라, **좋은 CNN 구조를 어떻게 설계해야 하는지를 연구한 모델**이다.

가장 중요한 아이디어는 CNN의 성능이 복잡한 구조보다도 **규칙적인 Network Design**에서 나온다는 점이며, 이를 통해 CNN 설계를 경험과 시행착오가 아닌 체계적인 방법으로 접근할 수 있음을 보여주었다.
