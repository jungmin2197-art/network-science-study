# 8.1 Deep Convolutional Neural Networks (AlexNet)

## 논문

**ImageNet Classification with Deep Convolutional Neural Networks**

- Alex Krizhevsky
- Ilya Sutskever
- Geoffrey Hinton

NeurIPS 2012

---

# 왜 등장했는가?

LeNet은 CNN의 가능성을 보여준 최초의 성공적인 모델이었지만, 작은 데이터셋(MNIST)을 대상으로 설계되어 복잡한 이미지를 학습하기에는 한계가 있었다. 이후 ImageNet과 같은 대규모 데이터셋이 등장하면서 더 깊고 강력한 CNN이 필요하게 되었지만, 당시에는 깊은 네트워크를 안정적으로 학습하기 어려웠다.

AlexNet은 이러한 문제를 해결하기 위해 다양한 학습 기법을 적용한 모델로, **Deep Learning이 대규모 이미지 분류에서도 뛰어난 성능을 낼 수 있음을 처음으로 증명한 CNN**이다.

---

# 기존 CNN의 한계

AlexNet 이전의 CNN은 다음과 같은 문제를 가지고 있었다.

- Sigmoid, Tanh 활성화 함수로 인한 Gradient Vanishing
- 대규모 모델의 Overfitting
- GPU 성능을 충분히 활용하지 못함
- 학습 시간이 매우 오래 걸림
- ImageNet과 같은 대규모 데이터셋에서 성능이 낮음

---

# 핵심 아이디어

AlexNet은 단순히 CNN을 깊게 만든 것이 아니라 여러 가지 핵심 기술을 함께 적용하여 성능을 크게 향상시켰다.

- ReLU 활성화 함수
- Dropout
- Data Augmentation
- GPU 병렬 학습
- Local Response Normalization(LRN)

이 기술들의 조합을 통해 ImageNet 2012 대회에서 기존 방법보다 압도적으로 높은 성능을 기록하였다.

---

# AlexNet 구조

AlexNet은 **5개의 Convolution Layer와 3개의 Fully Connected Layer**로 구성된 총 8개의 학습 가능한 Layer를 가진다.

```text
Input
    │
    ▼
Conv1
    │
ReLU
    │
LRN
    │
Max Pooling
    │
    ▼
Conv2
    │
ReLU
    │
LRN
    │
Max Pooling
    │
    ▼
Conv3
    │
ReLU
    │
    ▼
Conv4
    │
ReLU
    │
    ▼
Conv5
    │
ReLU
    │
Max Pooling
    │
    ▼
FC
    │
Dropout
    │
FC
    │
Dropout
    │
FC
    │
Softmax
```

---

# 주요 기술

## 1. ReLU

AlexNet 이전에는 Sigmoid와 Tanh를 주로 사용하였다. 하지만 깊은 네트워크에서는 Gradient Vanishing 문제가 발생하여 학습이 매우 느렸다.

ReLU는

$$
f(x)=\max(0,x)
$$

로 정의되며 다음과 같은 장점을 가진다.

- 계산이 단순하다.
- Gradient Vanishing을 완화한다.
- 학습 속도가 매우 빠르다.

현재 대부분의 CNN에서 기본 활성화 함수로 사용된다.

---

## 2. Dropout

Fully Connected Layer는 Parameter 수가 매우 많기 때문에 Overfitting이 쉽게 발생한다.

Dropout은 학습 과정에서 일부 뉴런을 랜덤하게 제거하여 특정 뉴런에 대한 의존성을 줄인다.

이를 통해 일반화 성능을 향상시킬 수 있다.

---

## 3. Data Augmentation

AlexNet은 학습 데이터를 인위적으로 증가시켜 Overfitting을 줄였다.

대표적인 방법은 다음과 같다.

- Random Crop
- Horizontal Flip
- RGB Color Jitter

동일한 이미지에서도 다양한 학습 데이터를 생성할 수 있어 모델의 일반화 성능이 향상된다.

---

## 4. GPU 병렬 학습

당시 GPU 메모리의 한계 때문에 하나의 GPU에서 AlexNet 전체를 학습하기 어려웠다.

AlexNet은 **두 개의 GPU를 이용한 병렬 학습**을 수행하여 학습 속도를 크게 향상시켰다.

이는 당시 Deep Learning 모델에서는 매우 혁신적인 시도였다.

---

## 5. Local Response Normalization (LRN)

AlexNet은 ReLU의 출력을 정규화하기 위해 LRN(Local Response Normalization)을 사용하였다.

이는 큰 Activation을 강조하고 작은 Activation을 억제하여 일반화 성능 향상에 도움을 주었다.

하지만 이후 Batch Normalization이 등장하면서 현재는 거의 사용되지 않는다.

---

# Representation Learning

AlexNet은 Layer가 깊어질수록 점점 추상적인 특징을 학습한다.

```text
Input Image
      │
      ▼
Edges
      │
      ▼
Texture
      │
      ▼
Object Parts
      │
      ▼
High-level Object
```

초기 Layer에서는 Edge와 Texture를 학습하고, 깊은 Layer에서는 사람, 자동차와 같은 고수준의 특징을 학습한다.

---

# 장점

- Deep CNN의 가능성을 입증하였다.
- ImageNet 성능을 크게 향상시켰다.
- ReLU의 효과를 증명하였다.
- Dropout과 Data Augmentation의 효과를 입증하였다.
- GPU 기반 Deep Learning 시대를 열었다.

---

# 한계

- Fully Connected Layer의 Parameter가 매우 많다.
- 모델 크기가 크다.
- 계산량이 많다.
- LRN은 현재 거의 사용되지 않는다.

이러한 한계를 해결하기 위해 이후 VGG, GoogLeNet, ResNet 등이 등장하였다.

---

# 후속 연구에 미친 영향

AlexNet은 현대 CNN의 출발점이 된 모델이다.

이후 등장한

- VGG
- GoogLeNet
- ResNet
- DenseNet

등 대부분의 CNN 구조는 AlexNet의 영향을 받아 발전하였다.

---

# 내가 이해한 내용

AlexNet은 단순히 CNN을 깊게 만든 모델이 아니라 **깊은 CNN을 실제로 학습 가능하게 만든 모델**이라고 이해할 수 있다. ReLU를 통해 Gradient Vanishing 문제를 완화하고, Dropout과 Data Augmentation으로 Overfitting을 줄였으며, GPU 병렬 학습을 통해 대규모 ImageNet 데이터셋에서도 효율적으로 학습할 수 있음을 보여주었다.

AlexNet의 가장 큰 의미는 **현대 Deep Learning 기반 Computer Vision 시대를 시작한 모델**이라는 점이다.
