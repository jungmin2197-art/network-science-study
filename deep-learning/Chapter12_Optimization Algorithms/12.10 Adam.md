# 12.10 Adam

---

# 왜 Adam이 등장했는가?

Momentum은 이전 Gradient의 방향을 기억하여 학습 속도를 높였지만, 모든 Parameter에 동일한 Learning Rate를 사용하였다.

반면 RMSProp은 Parameter마다 Adaptive Learning Rate를 적용했지만, 이전 Gradient의 방향은 고려하지 않았다.

Adam(Adaptive Moment Estimation)은 **Momentum의 1차 모멘트와 RMSProp의 2차 모멘트를 함께 이용하여 빠르고 안정적인 학습을 수행하는 Optimizer**이다.

---

# 기존 Optimizer의 한계

### Momentum

```
이전 Gradient 기억

↓

빠른 이동
```

하지만

Learning Rate는

모든 Parameter가 동일하다.

---

### RMSProp

```
Adaptive Learning Rate

↓

Parameter마다 다름
```

하지만

Gradient의 방향은

기억하지 않는다.

---

# 핵심 아이디어

Adam의 핵심은

> **Momentum과 RMSProp을 동시에 사용하자.**

즉,

```
Gradient

↓

Momentum

+

RMSProp

↓

Parameter Update
```

를 수행한다.

---

# 1차 모멘트 (First Moment)

Adam은

Gradient의 평균을 계산한다.

$$
m_t
=
\beta_1m_{t-1}
+
(1-\beta_1)g_t
$$

여기서

- \(m_t\) : Gradient의 이동평균
- \(\beta_1\) : 보통 0.9

이다.

Momentum과 거의 같은 개념이다.

---

# 2차 모멘트 (Second Moment)

Gradient 제곱의 이동평균도 계산한다.

$$
v_t
=
\beta_2v_{t-1}
+
(1-\beta_2)g_t^2
$$

여기서

- \(v_t\) : Gradient²의 이동평균
- \(\beta_2\) : 보통 0.999

이다.

RMSProp과 같은 개념이다.

---

# Bias Correction

초기에는

\(m_t\)와

\(v_t\)가

0으로 시작한다.

따라서

초기 몇 번의 Update에서는

값이 실제보다 작게 계산된다.

이를 보정하기 위해

Bias Correction을 수행한다.

$$
\hat{m}_t
=
\frac{m_t}{1-\beta_1^t}
$$

$$
\hat{v}_t
=
\frac{v_t}{1-\beta_2^t}
$$

---

# Parameter Update

최종적으로

Parameter는

$$
\theta_{t+1}
=
\theta_t
-
\eta
\frac{\hat{m}_t}
{\sqrt{\hat{v}_t}+\epsilon}
$$

로 업데이트된다.

---

# Adam 과정

```text
Gradient

↓

Momentum 계산

↓

RMSProp 계산

↓

Bias Correction

↓

Parameter Update
```

---

# Adam의 특징

Momentum은

```
이전 방향 기억
```

RMSProp은

```
Learning Rate 자동 조절
```

Adam은

```
둘 다 사용
```

한다.

---

# Adam의 기본 하이퍼파라미터

일반적으로

```
Learning Rate = 0.001

β1 = 0.9

β2 = 0.999

ε = 10^-8
```

을 사용한다.

대부분의 문제에서

이 기본값만으로도 좋은 성능을 보인다.

---

# Adam과 기존 Optimizer 비교

| Optimizer | 특징 |
|-----------|------|
| SGD | 단순 Gradient |
| Momentum | 이전 Gradient 기억 |
| AdaGrad | Adaptive Learning Rate |
| RMSProp | EMA 기반 Adaptive LR |
| Adam | Momentum + RMSProp |

---

# Yogi

Yogi는

Adam의 변형 Optimizer이다.

Adam은

Gradient 분산이 매우 큰 경우

Learning Rate가

불안정해질 수 있다.

Yogi는

2차 모멘트 업데이트 방식을 수정하여

Learning Rate가

너무 커지거나

너무 작아지는 문제를 줄였다.

특히

- 대규모 데이터
- 희소 데이터
- 비정상적인 Gradient

환경에서

더 안정적인 학습이 가능하다.

---

# 장점

- 빠른 수렴 속도
- Adaptive Learning Rate
- Momentum 효과
- 대부분의 문제에서 좋은 성능
- 하이퍼파라미터 튜닝이 비교적 쉽다.

---

# 한계

- 메모리 사용량이 SGD보다 크다.
- 일반화 성능은 SGD가 더 좋은 경우도 있다.
- 매우 큰 모델에서는 AdamW 같은 개선 버전을 사용하는 경우가 많다.

---

# 후속 연구에 미친 영향

Adam은 현재 가장 널리 사용되는 Optimizer 중 하나이다.

이후

- AdamW
- Nadam
- RAdam
- Yogi
- AdaBelief

등 다양한 Adam 기반 Optimizer가 제안되었다.

특히 Transformer와 대규모 언어 모델은 대부분 Adam 계열 Optimizer를 사용한다.

---

# 내가 이해한 내용

Adam은 **Momentum과 RMSProp을 결합한 Adaptive Optimizer**이다.

Momentum을 이용하여 이전 Gradient의 방향을 기억하고, RMSProp을 이용하여 Parameter마다 서로 다른 Learning Rate를 적용한다.

또한 Bias Correction을 통해 초기 학습의 편향을 보정하여 더욱 안정적으로 Parameter를 업데이트한다.

즉, **Adam은 빠른 수렴과 안정적인 학습을 동시에 제공하는 현대 딥러닝의 대표적인 Optimizer**라고 이해할 수 있다.
