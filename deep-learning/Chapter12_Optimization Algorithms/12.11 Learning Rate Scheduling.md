# 12.11 Learning Rate Scheduling

---

# 왜 Learning Rate Scheduling이 필요한가?

Learning Rate는 Parameter를 얼마나 크게 업데이트할지를 결정하는 중요한 하이퍼파라미터이다.

하지만 학습 전 과정에서 동일한 Learning Rate를 사용하는 것은 항상 최선이 아니다.

초기에는 큰 Learning Rate로 빠르게 학습하고, 후반에는 작은 Learning Rate로 미세하게 조정하는 것이 일반적으로 더 좋은 성능을 보인다.

Learning Rate Scheduling은 **학습 과정에 따라 Learning Rate를 자동으로 조절하는 방법**이다.

---

# 고정 Learning Rate의 문제

예를 들어

```
Learning Rate = 0.1
```

을 끝까지 사용하면

초기에는

빠르게 학습할 수 있다.

하지만

후반에도

```
0.1
```

을 사용하면

최적점을 계속 지나쳐

Loss가 흔들릴 수 있다.

---

# 핵심 아이디어

Learning Rate Scheduling의 핵심은

> **초기에는 크게, 후반에는 작게 학습하자.**

이다.

즉,

```
Learning Rate

0.1

↓

0.01

↓

0.001

↓

0.0001
```

처럼

학습이 진행될수록

Learning Rate를 감소시킨다.

---

# Learning Rate Scheduling 과정

```text
초기 Learning Rate

↓

Training

↓

Learning Rate 감소

↓

Training

↓

Learning Rate 감소

↓

Training
```

---

# Toy Problem

간단한 Optimization 문제를 생각해보면

큰 Learning Rate는

최적점 근처에서

계속 진동한다.

```text
★

↙

↗

↙

↗
```

반면

Learning Rate를 줄이면

```
★

↓

↓

↓

```

처럼

안정적으로 수렴한다.

---

# 대표적인 Scheduler

## 1. Step Decay

일정 Epoch마다

Learning Rate를 감소시킨다.

예를 들어

```
Epoch

0 ~ 30

↓

0.1

30 ~ 60

↓

0.01

60 ~

↓

0.001
```

처럼 사용한다.

---

## 2. Exponential Decay

매 Epoch마다

일정 비율로 감소시킨다.

$$
\eta_t
=
\eta_0e^{-kt}
$$

Learning Rate가

부드럽게 감소한다.

---

## 3. Cosine Annealing

Learning Rate를

Cosine 함수 형태로 감소시킨다.

초기에는 크게 감소하고

후반에는 천천히 감소한다.

현재

Vision Transformer,

ResNet,

YOLO

등에서 매우 많이 사용된다.

---

## 4. Polynomial Decay

Learning Rate를

다항식 형태로 감소시킨다.

Semantic Segmentation 등에서

많이 사용된다.

---

# Warmup

초기부터

큰 Learning Rate를 사용하면

학습이 불안정할 수 있다.

Warmup은

```
0

↓

작은 Learning Rate

↓

점점 증가

↓

기본 Learning Rate
```

로

천천히 시작한다.

특히

Transformer에서는

거의 필수적으로 사용된다.

---

# Learning Rate Policy

Learning Rate Policy는

Learning Rate를

언제,

얼마나,

어떻게

변경할지를 결정하는 전략이다.

대표적으로

- Step Policy
- Cosine Policy
- Linear Decay
- Warmup + Cosine

등이 있다.

---

# 고정 Learning Rate와 비교

| Fixed LR | Learning Rate Scheduling |
|-----------|--------------------------|
| 항상 동일 | 학습 중 변경 |
| 최적점에서 진동 가능 | 안정적으로 수렴 |
| 성능 제한 | 일반적으로 더 높은 성능 |

---

# 장점

- 빠른 초기 학습
- 안정적인 후반 학습
- 더 좋은 일반화 성능
- 다양한 Optimizer와 함께 사용 가능

---

# 한계

- Scheduler 선택이 필요하다.
- 하이퍼파라미터가 증가한다.
- 잘못 설정하면 오히려 성능이 저하될 수 있다.

---

# 후속 연구에 미친 영향

Learning Rate Scheduling은 현대 딥러닝의 표준 기법이 되었다.

현재 대부분의 모델은

- SGD + Cosine Annealing
- AdamW + Cosine Annealing
- Warmup + Cosine

등의 조합을 사용한다.

특히 Transformer와 Vision Transformer에서는 Warmup과 Cosine Annealing이 거의 기본 설정으로 사용된다.

---

# 내가 이해한 내용

Learning Rate Scheduling은 **학습 과정에 따라 Learning Rate를 자동으로 조절하는 기법**이다.

초기에는 큰 Learning Rate를 사용하여 빠르게 학습하고, 후반에는 작은 Learning Rate를 사용하여 최적점 근처를 안정적으로 탐색한다.

대표적인 방법으로 Step Decay, Exponential Decay, Cosine Annealing, Warmup 등이 있으며, 현재 대부분의 딥러닝 모델은 Optimizer와 함께 Learning Rate Scheduler를 사용하여 더 빠르고 안정적인 학습을 수행한다.
