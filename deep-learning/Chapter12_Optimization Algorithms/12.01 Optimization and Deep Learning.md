# 12.1 Optimization and Deep Learning

---

# 왜 Optimization이 중요한가?

딥러닝 모델의 목표는 **손실 함수(Loss Function)를 최소화하는 최적의 파라미터(Parameter)를 찾는 것**이다.

신경망은 입력 데이터를 이용하여 예측을 수행하고, 예측 결과와 실제 정답의 차이를 Loss Function으로 계산한다.

Optimization은 이 Loss를 가장 작게 만드는 방향으로 모델의 가중치(Weight)와 편향(Bias)을 반복적으로 업데이트하는 과정이다.

---

# Optimization이란?

Optimization은

> **목적 함수(Objective Function)를 최적화하는 과정**이다.

딥러닝에서는

```
입력 데이터

↓

Neural Network

↓

Prediction

↓

Loss Function

↓

Optimization

↓

Parameter Update
```

순으로 학습이 진행된다.

즉,

Loss가 가장 작은 Parameter를 찾는 것이 목표이다.

---

# Objective Function

Objective Function은

모델이 최소화하거나 최대화하려는 함수이다.

딥러닝에서는 대부분

```
Objective Function

=

Loss Function
```

으로 생각하면 된다.

예를 들어

- Mean Squared Error (MSE)
- Cross Entropy Loss

등이 대표적인 Loss Function이다.

---

# Optimization의 목표

Optimization의 목적은

Loss Function의 최솟값을 찾는 것이다.

```text
Loss

▲
│          ●
│       ●
│    ●
│  ●
│●________________▶ Parameter
```

즉,

Loss가 가장 낮은 지점을 찾도록 Parameter를 계속 업데이트한다.

---

# Training과 Optimization

Training은

모델 전체를 학습하는 과정이다.

Optimization은

그 과정에서 Parameter를 업데이트하는 방법이다.

즉,

```
Training

↓

Optimization

↓

Parameter Update
```

라는 관계이다.

---

# Deep Learning에서 Optimization이 어려운 이유

딥러닝에서는 Parameter 수가 매우 많다.

예를 들어

Transformer는

수억~수천억 개의 Parameter를 가진다.

따라서

Loss Function도 매우 복잡한 형태를 가진다.

이 때문에

최적의 해(Global Minimum)를 찾는 것이 어렵다.

---

# Optimization의 어려움

대표적인 문제는 다음과 같다.

### 1. Local Minimum

최소값처럼 보이지만

전체에서 가장 작은 값은 아니다.

```text
Loss
▲
│      ●
│   ●     ●
│ ●         ●
└────────────────▶
```

학습이 Local Minimum에서 멈출 수 있다.

---

### 2. Saddle Point

Gradient는 거의 0이지만

최소값도 최대값도 아닌 지점이다.

```text
      ／＼
    ／    ＼
──●──────────
    ＼    ／
      ＼／
```

고차원 딥러닝에서는

Local Minimum보다 Saddle Point가 더 많이 존재한다고 알려져 있다.

---

### 3. Plateau

Gradient가 매우 작은 평평한 영역이다.

```text
──────────────
```

Gradient가 거의 0이기 때문에

학습 속도가 매우 느려진다.

---

### 4. Ill-conditioning

어떤 방향은 매우 가파르고

어떤 방향은 매우 완만한 경우이다.

```text
╱
│
│
╲____________
```

Gradient Descent가

지그재그(Zig-zag)로 이동하면서

수렴 속도가 느려진다.

---

# Generalization과 Optimization

Optimization의 목표는

단순히 Training Loss를 줄이는 것이 아니다.

궁극적으로는

**보지 않은 데이터(Test Data)에서도 좋은 성능을 내는 것**이 중요하다.

즉,

Training Loss가 매우 작더라도

Test 성능이 나쁘면

좋은 모델이라고 할 수 없다.

---

# Optimization 과정

```text
Initialize Parameters

↓

Forward Propagation

↓

Loss Calculation

↓

Backward Propagation

↓

Gradient

↓

Optimizer

↓

Parameter Update

↓

반복
```

Optimizer는

Gradient를 이용하여

Parameter를 업데이트한다.

---

# 장점

- 모델의 성능을 향상시킨다.
- Loss를 최소화할 수 있다.
- 다양한 Optimizer를 적용할 수 있다.
- 딥러닝 학습의 핵심 과정이다.

---

# 한계

- Global Minimum을 보장하지 않는다.
- Saddle Point에 빠질 수 있다.
- 학습 속도가 느릴 수 있다.
- Learning Rate 설정에 민감하다.

이러한 문제를 해결하기 위해

Gradient Descent, SGD, Momentum, Adam 등 다양한 Optimization 알고리즘이 제안되었다.

---

# 후속 연구에 미친 영향

Optimization은 현대 딥러닝의 핵심 요소이다.

Gradient Descent를 시작으로

- SGD
- Momentum
- AdaGrad
- RMSProp
- Adam

등 다양한 Optimizer가 개발되었으며,

현재 대부분의 딥러닝 모델은 Adam 또는 SGD 계열 Optimizer를 사용한다.

---

# 내가 이해한 내용

Optimization은 **딥러닝 모델의 Loss Function을 최소화하도록 파라미터를 반복적으로 업데이트하는 과정**이다.

하지만 딥러닝 모델은 수많은 Parameter를 가지기 때문에 Loss Surface가 매우 복잡하며, Local Minimum, Saddle Point, Plateau와 같은 문제로 인해 최적의 해를 찾기가 쉽지 않다.

따라서 다양한 Optimization 알고리즘은 이러한 문제를 해결하면서 빠르고 안정적으로 학습하기 위해 제안되었다.
