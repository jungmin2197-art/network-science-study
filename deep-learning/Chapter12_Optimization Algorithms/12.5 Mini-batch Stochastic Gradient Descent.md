# 12.5 Mini-batch Stochastic Gradient Descent

---

# 왜 Mini-batch SGD가 등장했는가?

Gradient Descent는 전체 데이터를 사용하여 Gradient를 계산하므로 계산량이 매우 크다.

반면 SGD는 하나의 샘플만 사용하기 때문에 계산은 빠르지만 Gradient의 분산이 커져 학습이 불안정하다.

Mini-batch SGD는 **적은 수의 데이터를 하나의 Batch로 묶어 Gradient를 계산함으로써 Gradient Descent와 SGD의 장점을 모두 활용하는 방법**이다.

---

# 기존 방법의 한계

### Gradient Descent

```
전체 데이터

↓

Gradient 계산

↓

Update
```

- 계산량이 큼
- 안정적

---

### SGD

```
Data 1

↓

Update

↓

Data 2

↓

Update
```

- 계산이 빠름
- Gradient가 매우 불안정

---

# 핵심 아이디어

Mini-batch SGD의 핵심은

> **전체 데이터도 아니고, 하나의 데이터도 아닌, 적당한 크기의 Batch를 사용하자.**

이다.

예를 들어

```
Batch Size = 32
```

이면

```
32개 데이터

↓

Gradient 계산

↓

Update
```

를 반복한다.

---

# Mini-batch란?

예를 들어

```
Training Data

=

10,000개
```

이고

```
Batch Size

=

100
```

이라면

```
100

100

100

...

100
```

총

```
100개의 Mini-batch
```

로 나누어 학습한다.

---

# Parameter Update

Mini-batch SGD는

Mini-batch의 평균 Gradient를 이용하여

Parameter를 업데이트한다.

$$
\theta_{t+1}
=
\theta_t
-
\eta
\frac{1}{B}
\sum_{i=1}^{B}
\nabla J_i(\theta_t)
$$

여기서

- \(B\) : Batch Size

이다.

---

# 학습 과정

```text
Training Dataset

↓

Mini-batch 생성

↓

Forward

↓

Loss

↓

Backward

↓

Gradient 계산

↓

Parameter Update

↓

다음 Mini-batch
```

# Epoch와 Batch

예를 들어

```
데이터

=

1000개
```

Batch Size가

```
100
```

이라면

```
1000

↓

100

100

100

...

100
```

총

```
10개의 Batch
```

가 만들어진다.

모든 Batch를

한 번 학습하면

```
1 Epoch
```

가 된다.

---

# Batch Size의 영향

### 작은 Batch

예를 들어

```
Batch Size = 8
```

- Update가 자주 발생
- Gradient Noise 증가
- 일반화 성능이 좋은 경우가 많음

---

### 큰 Batch

예를 들어

```
Batch Size = 1024
```

- Gradient가 안정적
- GPU 활용도가 높음
- 메모리 사용량 증가

---

# Vectorization

Mini-batch의 가장 큰 장점은

**벡터 연산(Vectorization)** 이 가능하다는 것이다.

예를 들어

SGD는

```python
for sample in dataset:
    update()
```

처럼

하나씩 계산한다.

Mini-batch는

```python
batch = dataset[0:32]
update(batch)
```

처럼

한 번에 계산한다.

GPU는

이러한 병렬 연산에 매우 강하다.

---

# Cache 활용

Mini-batch는

CPU와 GPU의 Cache를

효율적으로 사용할 수 있다.

큰 행렬 연산을

한 번에 수행하기 때문에

메모리 접근 횟수가 줄어든다.

따라서

연산 속도가 크게 향상된다.

---

# Gradient Descent, SGD, Mini-batch 비교

| 방법 | 사용 데이터 | Update 횟수 | 속도 | 안정성 |
|------|------------|------------|------|--------|
| Gradient Descent | 전체 | 적음 | 느림 | 매우 높음 |
| SGD | 1개 | 매우 많음 | 빠름 | 낮음 |
| Mini-batch SGD | Batch | 적당 | 빠름 | 높음 |

---

# 장점

- 계산 속도가 빠르다.
- GPU 병렬 연산이 가능하다.
- Gradient Noise가 적당하다.
- 메모리 사용이 효율적이다.
- 현재 딥러닝의 표준 학습 방식이다.

---

# 한계

- Batch Size를 적절히 선택해야 한다.
- 너무 큰 Batch는 일반화 성능이 저하될 수 있다.
- GPU 메모리 크기에 영향을 받는다.

---

# 후속 연구에 미친 영향

Mini-batch SGD는 현대 딥러닝에서 가장 널리 사용되는 학습 방식이다.

Momentum, AdaGrad, RMSProp, Adam 등 대부분의 Optimizer는 Mini-batch SGD 환경에서 동작하도록 설계되었다.

또한 Data Parallel Training, Distributed Learning, Large-scale Deep Learning에서도 Mini-batch 학습이 기본으로 사용된다.

---

# 내가 이해한 내용

Mini-batch SGD는 **전체 데이터를 사용하는 Gradient Descent와 하나의 샘플만 사용하는 SGD의 중간 방식**이다.

일정 개수의 데이터를 하나의 Batch로 묶어 Gradient를 계산하기 때문에 계산 효율과 학습 안정성을 모두 확보할 수 있다.

또한 GPU의 병렬 연산과 벡터화를 효율적으로 활용할 수 있어 현재 대부분의 딥러닝 모델은 Mini-batch SGD 기반으로 학습된다.

즉, **Mini-batch SGD는 실제 딥러닝에서 가장 많이 사용되는 표준 학습 방식**이라고 이해할 수 있다.
