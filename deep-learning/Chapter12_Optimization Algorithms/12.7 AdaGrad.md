# 12.7 AdaGrad

---

# 왜 AdaGrad가 등장했는가?

Gradient Descent와 Momentum은 모든 Parameter에 동일한 Learning Rate를 사용한다.

하지만 실제 딥러닝에서는 모든 Parameter가 동일한 속도로 학습될 필요는 없다.

예를 들어 어떤 Parameter는 자주 업데이트되고, 어떤 Parameter는 거의 업데이트되지 않을 수 있다.

AdaGrad는 **Parameter마다 서로 다른 Learning Rate를 자동으로 적용하는 Adaptive Learning Rate Optimizer**이다.

---

# 기존 Optimizer의 한계

Gradient Descent와 Momentum은

```
θ1

↓

같은 η

↓

Update

θ2

↓

같은 η

↓

Update
```

처럼

모든 Parameter에

동일한 Learning Rate를 사용한다.

하지만

각 Parameter의 Gradient 크기는

서로 다르다.

---

# 핵심 아이디어

AdaGrad의 핵심은

> **자주 업데이트되는 Parameter는 Learning Rate를 줄이고, 드물게 업데이트되는 Parameter는 크게 유지하자.**

이다.

즉,

```
큰 Gradient

↓

Learning Rate 감소

----------------

작은 Gradient

↓

Learning Rate 유지
```

가 된다.

---

# Gradient Accumulation

AdaGrad는

과거 Gradient의 제곱을

계속 누적한다.

$$
G_t
=
G_{t-1}
+
g_t^2
$$

여기서

- \(g_t\) : 현재 Gradient
- \(G_t\) : 누적된 Gradient

이다.

---

# Parameter Update

AdaGrad의 업데이트 식은

$$
\theta_{t+1}
=
\theta_t
-
\frac{\eta}{\sqrt{G_t+\epsilon}}
g_t
$$

이다.

여기서

- \(\eta\) : 초기 Learning Rate
- \(G_t\) : 누적 Gradient
- \(\epsilon\) : 0으로 나누는 것을 방지하는 작은 값

이다.

---

# 왜 Gradient를 제곱할까?

Gradient는

양수와 음수가 존재한다.

예를 들어

```
+3

-3
```

을 그대로 더하면

```
0
```

이 되어버린다.

따라서

Gradient의 크기만 반영하기 위해

제곱을 사용한다.

```
(+3)^2 = 9

(-3)^2 = 9
```

---

# AdaGrad의 동작

초기에는

Learning Rate가 크다.

```
η
```

↓

Gradient가 계속 누적된다.

```
η

↓

η/2

↓

η/5

↓

η/10
```

즉,

학습이 진행될수록

Learning Rate가 자동으로 감소한다.

---

# Sparse Feature에 강한 이유

AdaGrad는

자주 등장하는 Feature보다

드물게 등장하는 Feature를

더 크게 업데이트한다.

예를 들어

NLP에서

```
the

is

a
```

같은 단어는

매우 자주 등장한다.

반면

```
Transformer

GraphSAGE
```

같은 단어는

드물게 등장한다.

AdaGrad는

드물게 등장하는 Feature에

더 큰 Learning Rate를 유지하기 때문에

희소 데이터(Sparse Data)에 강하다.

---

# Preconditioning

AdaGrad는

Gradient를 그대로 사용하는 것이 아니라

누적 Gradient로

Scaling한 뒤 사용한다.

즉,

```
Gradient

↓

누적 Gradient 계산

↓

Scaling

↓

Update
```

를 수행한다.

이러한 과정을

**Preconditioning**이라고 한다.

---

# Gradient Descent와 AdaGrad 비교

| Gradient Descent | AdaGrad |
|------------------|----------|
| 같은 Learning Rate | Parameter마다 다른 Learning Rate |
| Learning Rate 고정 | Learning Rate 자동 조절 |
| Sparse Feature에 약함 | Sparse Feature에 강함 |

---

# 장점

- Adaptive Learning Rate를 사용한다.
- Learning Rate를 직접 많이 조정할 필요가 없다.
- Sparse Feature에서 뛰어난 성능을 보인다.
- Parameter마다 최적의 Learning Rate를 적용한다.

---

# 한계

Gradient가 계속 누적되기 때문에

Learning Rate가

계속 감소한다.

결국

```
η

↓

0.1η

↓

0.01η

↓

0.001η
```

처럼

거의 0에 가까워질 수 있다.

그러면

학습이 너무 일찍 멈추는 문제가 발생한다.

---

# 후속 연구에 미친 영향

AdaGrad는 최초의 Adaptive Learning Rate Optimizer이다.

하지만 Learning Rate가 계속 감소하는 문제가 있었기 때문에

이후

- RMSProp
- Adadelta
- Adam

등이 이를 개선하기 위해 제안되었다.

특히 RMSProp은 AdaGrad의 누적 Gradient를 모두 저장하지 않고 **최근 Gradient만 반영**하여 Learning Rate가 지나치게 감소하는 문제를 해결하였다.

---

# 내가 이해한 내용

AdaGrad는 **Parameter마다 서로 다른 Learning Rate를 자동으로 적용하는 Adaptive Learning Rate Optimizer**이다.

Gradient의 제곱을 계속 누적하여 자주 업데이트되는 Parameter는 Learning Rate를 줄이고, 드물게 업데이트되는 Parameter는 상대적으로 큰 Learning Rate를 유지한다.

따라서 희소한 특징(Sparse Feature)을 가지는 문제에서는 효과적이지만, Gradient가 계속 누적되면서 Learning Rate가 지나치게 작아지는 문제가 있어 장기 학습에는 적합하지 않다.
