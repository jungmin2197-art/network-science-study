# 12.8 RMSProp

---

# 왜 RMSProp이 등장했는가?

AdaGrad는 Parameter마다 서로 다른 Learning Rate를 적용하여 학습 성능을 향상시켰다.

하지만 Gradient의 제곱을 계속 누적하기 때문에 학습이 진행될수록 Learning Rate가 지속적으로 감소하는 문제가 있었다.

RMSProp은 **과거 모든 Gradient를 저장하는 대신 최근 Gradient를 지수이동평균(Exponential Moving Average)으로 계산하여 Adaptive Learning Rate를 유지하는 Optimizer**이다.

---

# AdaGrad의 한계

AdaGrad는

```
Gradient²

↓

계속 누적

↓

Learning Rate 감소

↓

거의 0
```

가 된다.

즉,

학습 후반에는

Parameter가 거의 업데이트되지 않는다.

---

# 핵심 아이디어

RMSProp의 핵심은

> **과거 Gradient를 모두 기억하지 말고 최근 Gradient만 중요하게 생각하자.**

이다.

즉,

```
Old Gradient

↓

점점 잊어버림

↓

Recent Gradient

↓

더 크게 반영
```

한다.

---

# Exponential Moving Average

RMSProp은

Gradient의 제곱을

지수이동평균(EMA)으로 계산한다.

$$
s_t
=
\beta s_{t-1}
+
(1-\beta)g_t^2
$$

여기서

- \(g_t\) : 현재 Gradient
- \(s_t\) : Gradient 제곱의 이동평균
- \(\beta\) : 감쇠 계수(보통 0.9)

이다.

---

# Parameter Update

RMSProp의 업데이트 식은

$$
\theta_{t+1}
=
\theta_t
-
\frac{\eta}{\sqrt{s_t+\epsilon}}
g_t
$$

이다.

여기서

- \(\eta\) : Learning Rate
- \(s_t\) : 이동평균
- \(\epsilon\) : 작은 상수

이다.

---

# 왜 RMSProp이 좋은가?

AdaGrad는

```
1

2

3

4

5

6

...
```

처럼

모든 Gradient를

계속 저장한다.

반면

RMSProp은

```
최근 Gradient

★★★★★

이전 Gradient

★★★

오래된 Gradient

★
```

처럼

최근 Gradient를

더 크게 반영한다.

---

# RMSProp의 동작

초기에는

Gradient가 크게 반영된다.

```
Gradient

↓

EMA 계산

↓

Learning Rate 자동 조절

↓

Update
```

Learning Rate가

너무 작아지지 않으므로

학습이 끝까지 계속된다.

---

# AdaGrad와 RMSProp 비교

| AdaGrad | RMSProp |
|----------|----------|
| Gradient를 계속 누적 | 최근 Gradient만 반영 |
| Learning Rate 계속 감소 | Learning Rate 유지 |
| 장기 학습 어려움 | 장기 학습 가능 |

---

# Gradient Descent와 비교

| Gradient Descent | RMSProp |
|------------------|----------|
| Learning Rate 고정 | Adaptive Learning Rate |
| Parameter마다 동일 | Parameter마다 다름 |
| 수동 조절 | 자동 조절 |

---

# 장점

- Adaptive Learning Rate 사용
- AdaGrad보다 안정적인 학습
- Learning Rate가 지나치게 감소하지 않음
- 비정상적(Non-stationary) 문제에도 효과적

---

# 한계

- Momentum을 사용하지 않는다.
- β 값을 적절히 선택해야 한다.
- Adam보다 성능이 낮은 경우가 많다.

---

# 후속 연구에 미친 영향

RMSProp은 AdaGrad의 단점을 해결한 대표적인 Adaptive Optimizer이다.

이후

- Adam
- Nadam
- AdamW

등은 RMSProp의 Adaptive Learning Rate와 Momentum을 결합하여 더욱 뛰어난 성능을 보였다.

현재 Adam은 RMSProp의 아이디어를 그대로 포함하고 있다.

---

# 내가 이해한 내용

RMSProp은 **Gradient 제곱의 이동평균(EMA)을 이용하여 Parameter마다 Learning Rate를 자동으로 조절하는 Adaptive Optimizer**이다.

AdaGrad처럼 Adaptive Learning Rate를 사용하지만, 과거 모든 Gradient를 누적하지 않고 최근 Gradient를 중심으로 계산하기 때문에 Learning Rate가 지나치게 감소하지 않는다.

즉, **AdaGrad의 Learning Rate 감소 문제를 해결하여 더 안정적이고 지속적인 학습이 가능하도록 만든 Optimizer**라고 이해할 수 있다.
