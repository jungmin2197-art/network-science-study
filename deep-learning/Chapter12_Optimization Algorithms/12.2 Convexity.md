# 12.2 Convexity

---

# 왜 Convexity를 배우는가?

Optimization 알고리즘의 성능은 목적 함수(Objective Function)의 형태에 크게 영향을 받는다.

특히 함수가 **Convex(볼록)** 이라면 Local Minimum이 Global Minimum과 같기 때문에 최적해를 찾기가 쉽다.

반면 딥러닝의 Loss Function은 대부분 **Non-Convex** 형태이므로 최적화가 훨씬 어렵다.

따라서 Optimization을 이해하기 위해서는 먼저 Convexity의 개념을 이해해야 한다.

---

# Convex Set

Convex Set(볼록 집합)이란

> **집합 안의 두 점을 직선으로 연결했을 때 그 직선 전체가 집합 안에 존재하는 집합**이다.

예를 들어

원을 생각하면

```
●────────●
```

를 연결한 선분이

항상 원 안에 존재한다.

따라서 원은 Convex Set이다.

반대로

도넛 모양은

가운데가 비어 있으므로

직선을 그리면 밖으로 나가게 된다.

따라서 Convex Set이 아니다.

---

# Convex Function

Convex Function은

> **두 점을 연결한 직선이 항상 함수 위에 있는 함수**이다.

수학적으로는

$$
f(\lambda x+(1-\lambda)y)
\le
\lambda f(x)+(1-\lambda)f(y)
$$

를 만족한다.

여기서

- \(0 \le \lambda \le 1\)

이다.

쉽게 말하면

함수가 아래로 볼록한 그릇 모양이면

Convex Function이다.

---

# Convex Function의 예

대표적인 Convex Function은

$$
f(x)=x^2
$$

이다.

```text
      ●
    ●   ●
  ●       ●
●___________●
```

어느 두 점을 연결해도

직선은 항상 함수 위에 있다.

---

# Non-Convex Function

딥러닝에서 많이 등장하는 함수는

Non-Convex이다.

```text
      ●
   ●     ●
 ●         ●
   ●     ●
      ●
```

처럼

봉우리와 골짜기가 여러 개 존재한다.

---

# 왜 Convex가 중요한가?

Convex Function에서는

Local Minimum과

Global Minimum이 항상 같다.

```text
      ●
    ●   ●
  ●       ●
●___________●
      ↓
Global Minimum
```

따라서

Gradient Descent를 사용하면

최적해를 쉽게 찾을 수 있다.

---

# Local Minimum

Local Minimum은

주변에서만 가장 작은 값이다.

```text
Loss
▲
│      ●
│   ●     ●
│ ●         ●
└────────────────▶
```

전체에서는

더 작은 값이 존재할 수도 있다.

---

# Global Minimum

Global Minimum은

함수 전체에서

가장 작은 값이다.

```text
Loss
▲
│
│
│
└──────●────────▶
```

Optimization의 목표는

Global Minimum을 찾는 것이다.

---

# Convex Optimization

Convex Optimization은

Convex Function을 최적화하는 문제이다.

특징은

- Local Minimum = Global Minimum
- 안정적인 수렴
- 이론적 보장 가능

이다.

---

# Non-Convex Optimization

딥러닝은 대부분

Non-Convex Optimization 문제이다.

예를 들어

수백만 개의 Parameter를 가진

Neural Network의 Loss Surface는

매우 복잡하다.

따라서

- Saddle Point
- Plateau
- Local Minimum

등이 많이 존재한다.

---

# Constraints

Optimization에서는

제약조건(Constraint)이 존재할 수도 있다.

예를 들어

$$
x+y=1
$$

또는

$$
x\ge0
$$

처럼

해가 특정 조건을 만족해야 하는 경우이다.

이를

Constrained Optimization이라고 한다.

반대로

제약이 없는 경우를

Unconstrained Optimization이라고 한다.

딥러닝의 대부분은

Unconstrained Optimization으로 볼 수 있다.

---

# Convex와 Non-Convex 비교

| Convex | Non-Convex |
|---------|------------|
| 하나의 최솟값 | 여러 개의 최솟값 |
| 최적해 찾기 쉬움 | 최적화 어려움 |
| Global Minimum 보장 | 보장 불가 |
| 이론적 분석 용이 | 분석 어려움 |

---

# 장점

- 최적화 이론의 기초를 제공한다.
- Gradient Descent의 수렴성을 설명할 수 있다.
- Optimization 알고리즘 분석이 쉽다.

---

# 한계

실제 딥러닝 모델은 대부분 Non-Convex이다.

따라서 Convex Optimization 이론만으로는

현대 딥러닝을 완전히 설명할 수 없다.

하지만 Optimization 알고리즘을 이해하기 위한 중요한 기초 개념이다.

---

# 후속 연구에 미친 영향

Convex Optimization은 머신러닝 이론의 기반이 되었으며,

Gradient Descent, SGD, Momentum, Adam 등의 수렴 분석도 대부분 Convex 가정에서 시작되었다.

비록 현대 딥러닝은 Non-Convex 문제이지만, Convex Optimization 이론은 Optimizer 설계와 성능 분석의 중요한 기준으로 활용된다.

---

# 내가 이해한 내용

Convexity는 Optimization 문제의 난이도를 결정하는 중요한 성질이다.

Convex Function에서는 Local Minimum이 Global Minimum과 같기 때문에 Gradient Descent만으로도 최적해를 찾을 수 있다.

반면 딥러닝의 Loss Function은 대부분 Non-Convex이므로 Local Minimum, Saddle Point, Plateau 등이 존재하여 최적화가 훨씬 어렵다.

즉, Convex Optimization은 딥러닝의 직접적인 문제는 아니지만 **Optimization 알고리즘의 원리를 이해하기 위한 수학적 기초**라고 이해할 수 있다.
