# 12.4 Stochastic Gradient Descent (SGD)

---

# 왜 SGD가 등장했는가?

기본 Gradient Descent는 **전체 학습 데이터(Full Batch)** 를 모두 사용하여 Gradient를 계산한다.

데이터가 적을 때는 문제가 없지만,

딥러닝에서는 수백만 개의 데이터를 사용하기 때문에 매번 전체 데이터를 이용하여 Gradient를 계산하는 것은 매우 비효율적이다.

Stochastic Gradient Descent(SGD)는 **한 번에 하나의 샘플 또는 매우 적은 수의 샘플을 이용하여 Parameter를 업데이트하는 방법**으로 계산 속도를 크게 향상시켰다.

---

# Gradient Descent의 한계

Gradient Descent는

```
전체 데이터

↓

Gradient 계산

↓

Parameter Update
```

를 수행한다.

예를 들어

```
1,000,000개의 데이터
```

가 있다면

Parameter를 한 번 업데이트하기 위해

100만 개의 데이터를 모두 사용해야 한다.

---

# SGD의 핵심 아이디어

SGD의 핵심은

> **전체 데이터를 사용하지 말고 하나의 데이터만 이용하여 Parameter를 업데이트하자.**

이다.

즉,

```
Data 1

↓

Gradient

↓

Update

↓

Data 2

↓

Gradient

↓

Update
```

처럼

매 샘플마다 Parameter를 업데이트한다.

---

# SGD Update

Gradient Descent는

$$
\theta_{t+1}
=
\theta_t
-
\eta
\nabla J(\theta_t)
$$

를 사용한다.

SGD는

하나의 샘플

\((x_i,y_i)\)

에 대해서만 Gradient를 계산한다.

$$
\theta_{t+1}
=
\theta_t
-
\eta
\nabla J_i(\theta_t)
$$

여기서

\(J_i\)는

하나의 샘플에 대한 Loss이다.

---

# Gradient Descent와 SGD 비교

### Gradient Descent

```text
전체 데이터

↓

Gradient 계산

↓

Update
```

Parameter Update가

느리지만 안정적이다.

---

### SGD

```text
Data 1

↓

Update

↓

Data 2

↓

Update

↓

Data 3

↓

Update
```

매 샘플마다

즉시 Update를 수행한다.

---

# 왜 Stochastic인가?

Stochastic은

**무작위(Random)** 를 의미한다.

SGD는

매번

무작위로 선택된 데이터 하나를 사용하여

Gradient를 계산한다.

따라서

Gradient가 조금씩 달라진다.

---

# SGD의 특징

Gradient가

조금씩 흔들리면서

최솟값을 향해 이동한다.

```text
Gradient Descent

──────────────▶

SGD

/\/\/\/\/\/\/▶
```

즉,

직선으로 가지 않고

조금 흔들리며 이동한다.

---

# Dynamic Learning Rate

Learning Rate는

학습 과정에서

변경할 수도 있다.

예를 들어

초기에는

```
η = 0.1
```

으로 크게 이동하고

후반에는

```
η = 0.001
```

처럼

작게 이동한다.

이를

Learning Rate Decay라고 한다.

---

# SGD의 장점

### 1. 계산 속도가 빠르다.

전체 데이터를 사용할 필요가 없다.

---

### 2. 메모리 사용량이 적다.

한 개의 데이터만 사용한다.

---

### 3. Local Minimum 탈출 가능

Gradient가

조금씩 흔들리기 때문에

Local Minimum에서

빠져나올 수도 있다.

---

### 4. 큰 데이터셋에 적합

ImageNet처럼

수백만 개의 데이터도

효율적으로 학습할 수 있다.

---

# SGD의 한계

### 1. Gradient의 분산이 크다.

매번 다른 데이터를 사용하기 때문에

Gradient가 흔들린다.

---

### 2. 수렴이 불안정하다.

Loss가

계속 진동할 수 있다.

---

### 3. Learning Rate 선택이 어렵다.

Learning Rate가 크면

발산할 수 있고,

작으면

학습이 매우 느려진다.

---

# Convergence

SGD는

Learning Rate를

점차 감소시키면

이론적으로

Convex Function에서

최적해에 수렴한다.

하지만

딥러닝처럼

Non-Convex 문제에서는

Global Minimum을 보장하지 않는다.

---

# Finite Sample

실제 딥러닝에서는

전체 데이터를 모두 사용하는 것이 아니라

유한한 데이터(Finite Samples)를 이용하여 학습한다.

SGD는

제한된 데이터에서도

효율적으로 Parameter를 업데이트할 수 있다.

---

# Gradient Descent와 SGD 비교

| Gradient Descent | SGD |
|------------------|-----|
| 전체 데이터 사용 | 하나의 샘플 사용 |
| 계산량 큼 | 계산량 작음 |
| 안정적인 Gradient | 노이즈가 있는 Gradient |
| 느린 Update | 빠른 Update |

---

# 장점

- 계산 속도가 빠르다.
- 메모리 사용량이 적다.
- 대규모 데이터셋에 적합하다.
- Local Minimum 탈출 가능성이 있다.

---

# 한계

- Gradient의 분산이 크다.
- Loss가 진동한다.
- Learning Rate 설정이 중요하다.

이러한 문제를 해결하기 위해

다음 절에서 **Mini-batch SGD**가 제안된다.

---

# 후속 연구에 미친 영향

SGD는 현대 딥러닝에서 가장 널리 사용되는 Optimizer 중 하나이다.

이후

- Mini-batch SGD
- Momentum
- Nesterov Momentum

등은 SGD의 단점을 개선하기 위해 제안되었다.

특히 Computer Vision 분야에서는 현재도 **SGD + Momentum** 조합이 널리 사용된다.

---

# 내가 이해한 내용

Stochastic Gradient Descent(SGD)는 **전체 데이터 대신 하나의 샘플을 이용하여 Gradient를 계산하고 Parameter를 업데이트하는 최적화 알고리즘**이다.

Gradient Descent보다 계산량이 훨씬 적고 빠르게 학습할 수 있지만, 매번 다른 샘플을 사용하기 때문에 Gradient에 노이즈가 발생하여 학습 경로가 흔들릴 수 있다.

즉, **SGD는 계산 효율을 높이기 위해 정확한 Gradient 대신 근사적인 Gradient를 사용하는 방법**이라고 이해할 수 있다.
