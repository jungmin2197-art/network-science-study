# 12.3 Gradient Descent

---

# 왜 Gradient Descent가 필요한가?

딥러닝의 목표는 Loss Function을 최소화하는 최적의 Parameter를 찾는 것이다.

하지만 대부분의 Loss Function은 복잡하기 때문에 최솟값을 직접 계산하기 어렵다.

Gradient Descent는 **기울기(Gradient)를 이용하여 Loss가 가장 빠르게 감소하는 방향으로 Parameter를 반복적으로 업데이트하는 최적화 알고리즘**이다.

---

# Gradient란?

Gradient는

> **함수가 가장 빠르게 증가하는 방향과 크기**를 나타내는 벡터이다.

반대로

Loss를 줄이기 위해서는

Gradient의 반대 방향으로 이동해야 한다.

즉,

```
Gradient

↑

Loss 증가

-----------------

-Gradient

↓

Loss 감소
```

가 된다.

---

# Gradient Descent의 핵심 아이디어

Gradient Descent의 핵심은

> **Loss가 가장 많이 감소하는 방향으로 조금씩 이동하자.**

이다.

즉,

```
현재 위치

↓

Gradient 계산

↓

반대 방향 이동

↓

새로운 위치

↓

반복
```

를 수행한다.

---

# Parameter Update

Gradient Descent는

다음 식으로 Parameter를 업데이트한다.

$$
\theta_{t+1}
=
\theta_t
-
\eta
\nabla J(\theta_t)
$$

여기서

- \(\theta\) : Parameter
- \(\eta\) : Learning Rate
- \(\nabla J(\theta)\) : Gradient

이다.

---

# Learning Rate

Learning Rate는

한 번에 얼마나 이동할지를 결정한다.

### 너무 작은 경우

```
●

↓

↓

↓

↓

```

조금씩 이동하므로

학습이 매우 느리다.

---

### 너무 큰 경우

```
●

↓↓↓↓↓↓

반대편

↓↓↓↓↓↓

다시 반대편
```

최솟값을 지나쳐

발산할 수도 있다.

---

### 적절한 경우

```
●

↓

↓

↓

★

```

빠르고 안정적으로

최솟값에 도달한다.

---

# One-Dimensional Gradient Descent

1차원 함수에서는

기울기의 부호만 확인하면 된다.

예를 들어

$$
f(x)=x^2
$$

이면

Gradient는

$$
f'(x)=2x
$$

이다.

초기값이

```
x=5
```

이면

```
Gradient = 10

↓

x 감소

↓

0으로 이동
```

한다.

---

# Multivariate Gradient Descent

실제 딥러닝에서는

Parameter가 하나가 아니라

수백만 개이다.

따라서

Gradient도 벡터가 된다.

예를 들어

$$
f(x,y)
$$

이면

Gradient는

$$
\nabla f
=
\left(
\frac{\partial f}{\partial x},
\frac{\partial f}{\partial y}
\right)
$$

이다.

즉,

모든 Parameter를 동시에 업데이트한다.

---

# Gradient Descent 과정

```text
Initialize Parameters

↓

Forward Propagation

↓

Loss 계산

↓

Backward Propagation

↓

Gradient 계산

↓

Parameter Update

↓

반복
```

---

# Adaptive Methods

Gradient Descent는

모든 Parameter에 동일한 Learning Rate를 사용한다.

하지만

Parameter마다

필요한 Learning Rate가 다를 수도 있다.

이를 해결하기 위해

Adaptive Learning Rate를 사용하는 방법이 제안되었다.

대표적으로

- AdaGrad
- RMSProp
- Adam

등이 있다.

---

# Gradient Descent의 장점

- 구현이 간단하다.
- 대부분의 최적화 문제에 적용 가능하다.
- 딥러닝 Optimizer의 기본이 된다.

---

# Gradient Descent의 한계

### 1. Learning Rate 선택이 어렵다.

Learning Rate가 너무 크면

발산하고,

너무 작으면

학습이 매우 느리다.

---

### 2. Local Minimum

Non-Convex 문제에서는

Local Minimum에

머무를 수 있다.

---

### 3. Saddle Point

Gradient가 거의 0이지만

최솟값이 아닌 지점에서

학습이 느려질 수 있다.

---

### 4. Zig-zag 문제

경사가 매우 다른 방향에서는

Gradient가

지그재그로 이동한다.

```text
＼

 ＼

  ＼

   ＼

```

수렴 속도가 느려진다.

---

# 후속 연구에 미친 영향

Gradient Descent는 현대 Optimizer의 출발점이다.

이후

- SGD
- Mini-batch SGD
- Momentum
- AdaGrad
- RMSProp
- Adam

등은 모두 Gradient Descent의 단점을 개선하기 위해 제안되었다.

---

# 내가 이해한 내용

Gradient Descent는 **Loss Function의 Gradient를 계산하여 Loss가 가장 빠르게 감소하는 방향으로 Parameter를 반복적으로 업데이트하는 최적화 알고리즘**이다.

Gradient는 함수가 가장 빠르게 증가하는 방향을 나타내므로, 학습에서는 Gradient의 반대 방향으로 이동하여 Loss를 줄인다.

또한 Learning Rate는 한 번의 이동 크기를 결정하며, 너무 크면 발산하고 너무 작으면 학습 속도가 느려진다.

Gradient Descent는 모든 Optimizer의 기본이 되는 알고리즘이며, 이후 등장한 SGD, Momentum, Adam 등은 이를 더욱 빠르고 안정적으로 개선한 방법들이다.
