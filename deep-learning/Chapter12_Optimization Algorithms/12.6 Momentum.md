# 12.6 Momentum

---

# 왜 Momentum이 등장했는가?

SGD는 Gradient를 이용하여 Parameter를 업데이트하지만, 매 Mini-batch마다 Gradient가 달라지기 때문에 업데이트 방향이 계속 흔들리는 문제가 있다.

특히 Loss Surface가 좁고 긴 골짜기 형태인 경우 Parameter가 좌우로 진동(Zig-zag)하면서 수렴 속도가 매우 느려진다.

Momentum은 **이전 Gradient의 방향을 함께 고려하여 Parameter를 업데이트함으로써 진동을 줄이고 더 빠르게 수렴하도록 하는 방법**이다.

---

# SGD의 문제점

SGD는

현재 Gradient만 이용한다.

```
Gradient

↓

Update
```

따라서

Gradient가 계속 바뀌면

```
↙

↗

↙

↗
```

처럼

계속 흔들리게 된다.

이를

**Zig-zag 문제**라고 한다.

---

# 핵심 아이디어

Momentum의 핵심은

> **이전 방향을 기억하면서 이동하자.**

이다.

자동차를 생각하면

```
자동차

↓

가속

↓

관성

↓

계속 앞으로 이동
```

하는 것과 같다.

즉,

현재 Gradient뿐 아니라

이전 이동 방향도 함께 사용한다.

---

# Velocity

Momentum에서는

Gradient 대신

Velocity(속도)를 사용한다.

Velocity는

이전 Gradient를

조금씩 기억한 값이다.

즉,

```
현재 Gradient

+

이전 Velocity

↓

새로운 Velocity
```

를 계산한다.

---

# Momentum Update

Momentum의 식은

$$
v_t
=
\beta v_{t-1}
+
\nabla J(\theta_t)
$$

이다.

여기서

- \(v_t\) : Velocity
- \(\beta\) : Momentum 계수
- \(\nabla J(\theta)\) : Gradient

이다.

Parameter는

$$
\theta_{t+1}
=
\theta_t
-
\eta v_t
$$

로 업데이트된다.

---

# Momentum 과정

```text
Gradient 계산

↓

이전 Velocity 저장

↓

새로운 Velocity 계산

↓

Parameter Update

↓

반복
```

---

# Momentum의 효과

SGD는

```
↙

↗

↙

↗
```

처럼

계속 흔들린다.

Momentum은

```
↓

↓

↓

↓

```

처럼

평균적인 방향으로

빠르게 이동한다.

---

# Momentum 계수 β

β는

이전 정보를

얼마나 기억할지를 결정한다.

보통

```
β = 0.9
```

를 가장 많이 사용한다.

### β가 작은 경우

```
현재 Gradient 위주
```

가 된다.

---

### β가 큰 경우

```
이전 방향을 오래 기억
```

한다.

---

# 공 굴리기 비유

Loss Surface를

언덕이라고 생각하면

SGD는

```
한 걸음

멈춤

한 걸음

멈춤
```

처럼 이동한다.

Momentum은

```
공이 굴러감

↓

관성

↓

계속 굴러감
```

처럼

속도를 유지하며 이동한다.

# SGD와 Momentum 비교

```text
SGD

↙

↗

↙

↗

↓

↓
```

Momentum은

---

# Gradient Descent, SGD, Momentum 비교

| 방법 | 특징 |
|------|------|
| Gradient Descent | 전체 데이터 사용 |
| SGD | 빠르지만 흔들림 |
| Momentum | 이전 방향까지 고려 |

---

# 장점

- 수렴 속도가 빨라진다.
- Zig-zag 현상이 감소한다.
- Local Minimum을 벗어날 가능성이 높다.
- 실제 딥러닝에서 매우 많이 사용된다.

---

# 한계

- β 값을 적절히 선택해야 한다.
- 너무 큰 β는 최적점을 지나칠 수 있다.
- Learning Rate도 함께 조절해야 한다.

---

# 후속 연구에 미친 영향

Momentum은 이후 다양한 Optimizer의 기반이 되었다.

대표적으로

- Nesterov Momentum
- Adam
- Nadam

등은 Momentum 개념을 포함하고 있다.

특히 Adam은 Momentum과 RMSProp을 결합한 Optimizer이다.

---

# 내가 이해한 내용

Momentum은 **현재 Gradient뿐 아니라 이전 Gradient의 방향도 함께 이용하여 Parameter를 업데이트하는 최적화 알고리즘**이다.

SGD는 Gradient가 자주 바뀌어 업데이트 방향이 흔들릴 수 있지만, Momentum은 이전 이동 방향을 기억하는 Velocity를 사용하여 이러한 진동을 줄이고 더 빠르게 최적점으로 수렴한다.

즉, Momentum의 핵심은 **관성(Inertia)을 이용하여 학습을 더 빠르고 안정적으로 만드는 것**이다.
