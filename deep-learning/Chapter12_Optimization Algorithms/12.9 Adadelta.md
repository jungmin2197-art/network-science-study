# 12.9 Adadelta

---

# 왜 Adadelta가 등장했는가?

AdaGrad는 Gradient를 계속 누적하기 때문에 Learning Rate가 지나치게 감소하는 문제가 있었다.

RMSProp은 Gradient의 지수이동평균(EMA)을 사용하여 이 문제를 해결했지만, 여전히 Learning Rate를 사람이 직접 설정해야 했다.

Adadelta는 **Gradient뿐 아니라 Parameter Update의 이동평균도 함께 이용하여 Learning Rate를 자동으로 조절하는 Optimizer**이다.

---

# RMSProp의 한계

RMSProp은

```
Gradient²

↓

EMA

↓

Learning Rate 조절
```

을 수행한다.

하지만

Learning Rate

```
η
```

는

여전히 사람이 직접 정해야 한다.

---

# 핵심 아이디어

Adadelta의 핵심은

> **Learning Rate를 직접 정하지 말고, 이전 Update 크기를 이용하여 자동으로 계산하자.**

이다.

즉,

```
Gradient

↓

Gradient EMA

↓

Update EMA

↓

Adaptive Update
```

를 수행한다.

---

# Gradient Moving Average

먼저

Gradient의 제곱에 대해

EMA를 계산한다.

$$
E[g^2]_t
=
\rho E[g^2]_{t-1}
+
(1-\rho)g_t^2
$$

여기서

- \(g_t\) : Gradient
- \(\rho\) : 감쇠 계수(보통 0.9)

이다.

---

# Update Moving Average

Adadelta는

Gradient뿐 아니라

Parameter Update도 저장한다.

$$
E[\Delta\theta^2]_t
=
\rho E[\Delta\theta^2]_{t-1}
+
(1-\rho)(\Delta\theta_t)^2
$$

즉,

이전 Update 크기를

계속 기억한다.

---

# Parameter Update

Adadelta의 업데이트 식은

$$
\Delta\theta_t
=
-
\frac{\sqrt{E[\Delta\theta^2]_{t-1}+\epsilon}}
{\sqrt{E[g^2]_t+\epsilon}}
g_t
$$

그리고

$$
\theta_{t+1}
=
\theta_t
+
\Delta\theta_t
$$

로 Parameter를 업데이트한다.

---

# 왜 Learning Rate가 필요 없을까?

RMSProp은

```
η × Gradient
```

를 사용한다.

Adadelta는

```
과거 Update 크기

↓

현재 Gradient 크기

↓

자동 비율 계산
```

을 수행한다.

즉,

Learning Rate 역할을

자동으로 수행한다.

---

# RMSProp과 Adadelta 비교

| RMSProp | Adadelta |
|----------|-----------|
| Gradient EMA | Gradient EMA + Update EMA |
| Learning Rate 필요 | Learning Rate 거의 불필요 |
| Adaptive Learning Rate | Adaptive Update |

---

# Gradient Descent와 비교

| Gradient Descent | Adadelta |
|------------------|-----------|
| Learning Rate 고정 | 자동 조절 |
| Parameter마다 동일 | Parameter마다 다름 |
| 사람이 직접 설정 | Update 기반 자동 계산 |

---

# 장점

- Learning Rate 설정 부담이 적다.
- Adaptive Learning Rate를 제공한다.
- RMSProp보다 안정적인 업데이트가 가능하다.
- 장기 학습에서도 안정적으로 동작한다.

---

# 한계

- Adam보다 널리 사용되지는 않는다.
- Update 계산이 조금 더 복잡하다.
- 최근 딥러닝에서는 Adam 계열 Optimizer가 더 많이 사용된다.

---

# 후속 연구에 미친 영향

Adadelta는 RMSProp을 발전시켜 Learning Rate를 자동으로 조절하는 아이디어를 제시하였다.

이후 Adam은 Momentum과 RMSProp을 결합하면서 더 빠른 수렴과 안정적인 학습을 제공하였고, 현재는 Adadelta보다 Adam이 훨씬 널리 사용된다.

---

# 내가 이해한 내용

Adadelta는 **Gradient의 이동평균뿐 아니라 Parameter Update의 이동평균도 함께 사용하여 Learning Rate를 자동으로 조절하는 Adaptive Optimizer**이다.

RMSProp과 달리 Learning Rate를 직접 설정하지 않아도 되며, 이전 업데이트 크기를 이용하여 현재 업데이트 크기를 결정한다.

즉, **Adadelta는 RMSProp의 Adaptive Learning Rate 개념을 확장하여 Learning Rate 의존성을 더욱 줄인 Optimizer**라고 이해할 수 있다.
