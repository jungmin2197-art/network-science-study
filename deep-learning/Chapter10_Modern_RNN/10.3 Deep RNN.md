# 10.3 Deep Recurrent Neural Networks

---

# 왜 Deep RNN이 등장했는가?

기본 RNN과 LSTM, GRU는 Sequence 데이터를 효과적으로 처리할 수 있었지만, Hidden Layer가 하나인 경우 표현력이 제한되는 문제가 있었다.

복잡한 언어나 긴 문장을 이해하기 위해서는 더 높은 수준의 특징(Feature)을 학습할 필요가 있다.

Deep RNN은 이러한 문제를 해결하기 위해 **여러 개의 RNN Layer를 쌓아 더욱 풍부한 표현을 학습하는 구조**를 제안하였다.

---

# 기존 RNN의 한계

기본 RNN은 하나의 Hidden Layer만 사용한다.

```text
Input

↓

RNN

↓

Output
```

Hidden State 하나만으로 모든 정보를 학습해야 하기 때문에

- 표현력 부족
- 복잡한 문장 이해 어려움
- 계층적인 특징 학습 어려움

이라는 문제가 있다.

---

# 핵심 아이디어

Deep RNN의 핵심은 매우 단순하다.

> **RNN Layer를 여러 층(Stack)으로 쌓아 더 높은 수준의 특징을 학습하자.**

CNN이 Layer를 깊게 쌓아 더 복잡한 특징을 학습하는 것처럼,

RNN도 여러 Layer를 쌓아 Sequence를 더욱 효과적으로 표현한다.

---

# Deep RNN 구조

기본 RNN은

```text
Input

↓

RNN

↓

Output
```

이다.

Deep RNN은

```text
Input

↓

RNN Layer 1

↓

RNN Layer 2

↓

RNN Layer 3

↓

Output
```

처럼 여러 개의 RNN Layer를 연속적으로 사용한다.

---

# Hidden State 전달

각 Layer는 자신의 Hidden State를

다음 Layer의 입력으로 전달한다.

```text
Time t

Input

↓

Layer1 Hidden

↓

Layer2 Hidden

↓

Layer3 Hidden

↓

Output
```

즉,

시간(Time) 방향뿐 아니라

깊이(Depth) 방향으로도 정보가 전달된다.

---

# Time과 Depth

Deep RNN은

두 방향으로 정보가 전달된다.

### 시간(Time)

```text
x1

↓

x2

↓

x3
```

Sequence를 따라 전달된다.

---

### 깊이(Depth)

```text
Layer1

↓

Layer2

↓

Layer3
```

Layer를 따라 전달된다.

즉,

Deep RNN은

시간과 깊이를 동시에 학습한다.

---

# 특징 학습

각 Layer는 서로 다른 수준의 특징을 학습한다.

예를 들어

```text
Layer1

↓

단어 정보

↓

Layer2

↓

문법 정보

↓

Layer3

↓

문장 의미
```

처럼

점점 더 추상적인 정보를 학습한다.

---

# Deep RNN의 장점

- 표현력 증가
- 복잡한 Sequence 학습 가능
- 계층적인 Feature 학습
- 긴 문맥 이해 향상

---

# 한계

Layer가 많아질수록

- 학습 시간이 증가한다.
- Gradient Vanishing이 발생할 수 있다.
- 계산량이 증가한다.

따라서 실제로는 LSTM이나 GRU를 여러 층 쌓아 사용하는 경우가 많다.

---

# PyTorch 구현

PyTorch에서는

```python
nn.RNN(
    input_size,
    hidden_size,
    num_layers=3
)
```

처럼

`num_layers`를 증가시키면

Deep RNN을 쉽게 만들 수 있다.

LSTM과 GRU도 동일하게

```python
nn.LSTM(..., num_layers=3)

nn.GRU(..., num_layers=3)
```

를 사용한다.

---

# Deep RNN과 기본 RNN 비교

| 기본 RNN | Deep RNN |
|----------|----------|
| Hidden Layer 1개 | Hidden Layer 여러 개 |
| 표현력 낮음 | 표현력 높음 |
| 단순한 Sequence | 복잡한 Sequence |
| 계산량 적음 | 계산량 증가 |

---

# 후속 연구에 미친 영향

Deep RNN은 여러 개의 RNN Layer를 쌓아 표현력을 높이는 방법을 제시하였다.

이후

- Deep LSTM
- Deep GRU
- Seq2Seq
- Encoder-Decoder

등 대부분의 Sequence 모델에서 여러 Layer를 사용하는 방식이 기본 구조가 되었다.

또한 Transformer에서도 Encoder와 Decoder를 여러 층으로 쌓는 아이디어로 이어졌다.

---

# 내가 이해한 내용

Deep RNN은 새로운 종류의 RNN이 아니라 **기존 RNN을 여러 층으로 쌓아 표현력을 높인 구조**이다.

CNN에서 Layer를 깊게 쌓을수록 더 복잡한 특징을 학습하는 것처럼, Deep RNN도 여러 개의 RNN Layer를 통해 단어 수준의 정보부터 문장 수준의 의미까지 계층적으로 학습할 수 있다.

즉, Deep RNN의 핵심은 **시간(Time) 방향뿐 아니라 깊이(Depth) 방향으로도 정보를 전달하여 더욱 풍부한 Sequence 표현을 학습하는 것**이다.
