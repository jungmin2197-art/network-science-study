# 10.2 Gated Recurrent Unit (GRU)

## 논문

**Learning Phrase Representations using RNN Encoder–Decoder for Statistical Machine Translation**

- Kyunghyun Cho
- Bart van Merriënboer
- Çaglar Gülçehre
- Yoshua Bengio et al.

EMNLP 2014

---

# 왜 등장했는가?

LSTM은 Gradient Vanishing 문제를 해결하고 긴 Sequence를 효과적으로 처리할 수 있었지만, 구조가 복잡하고 Parameter 수가 많아 학습 속도가 느리다는 단점이 있었다.

GRU(Gated Recurrent Unit)는 **LSTM의 성능은 유지하면서 구조를 단순화하여 계산량을 줄이기 위해** 제안되었다.

---

# LSTM의 한계

LSTM은

- Forget Gate
- Input Gate
- Output Gate
- Cell State

를 모두 사용한다.

덕분에 성능은 뛰어나지만

- Parameter 수 증가
- 계산량 증가
- 학습 속도 감소

라는 문제가 있다.

---

# 핵심 아이디어

GRU의 핵심은 매우 단순하다.

> **Forget Gate와 Input Gate를 하나의 Update Gate로 합치자.**

또한

Cell State를 제거하여

Hidden State 하나만 사용한다.

즉,

- 구조 단순화
- Parameter 감소
- 학습 속도 향상

을 동시에 달성하였다.

---

# GRU 구조

GRU는

- Update Gate
- Reset Gate
- Candidate Hidden State

세 가지 요소로 구성된다.

```text
Input
   │
   ▼
Reset Gate
   │
   ▼
Candidate Hidden State
   │
   ▼
Update Gate
   │
   ▼
Hidden State
```

LSTM과 달리 Cell State는 존재하지 않는다.

---

# Hidden State

GRU에서는

Hidden State 하나가

장기 기억과 단기 기억을 모두 담당한다.

즉,

```
Hidden State

↓

Memory
```

역할을 수행한다.

---

# Reset Gate

Reset Gate는

과거 정보를 얼마나 사용할지를 결정한다.

수식은

$$
r_t=\sigma(W_r[h_{t-1},x_t]+b_r)
$$

이다.

- 0에 가까움 → 과거 기억 거의 사용하지 않음
- 1에 가까움 → 과거 기억 적극 사용

즉,

**이전 Hidden State를 얼마나 참고할지 결정하는 Gate**이다.

---

# Candidate Hidden State

Reset Gate를 이용하여

새로운 Hidden State 후보를 생성한다.

$$
\tilde{h}_t=
\tanh(W_h[r_t\odot h_{t-1},x_t]+b_h)
$$

Reset Gate가 작을수록

과거 정보를 거의 무시하고

새로운 정보를 중심으로 Hidden State를 만든다.

---

# Update Gate

Update Gate는

이전 Hidden State와

새로운 Hidden State 중

어느 쪽을 더 사용할지 결정한다.

수식은

$$
z_t=\sigma(W_z[h_{t-1},x_t]+b_z)
$$

이다.

LSTM의

- Forget Gate
- Input Gate

역할을 동시에 수행한다.

---

# Hidden State Update

최종 Hidden State는

$$
h_t
=
z_t\odot h_{t-1}
+
(1-z_t)\odot\tilde{h}_t
$$

로 계산된다.

즉,

```
이전 기억 유지

+

새로운 기억 추가
```

를 Update Gate 하나로 조절한다.

---

# Gate의 역할

| Gate | 역할 |
|------|------|
| Reset Gate | 과거 정보를 얼마나 사용할지 결정 |
| Update Gate | 이전 기억과 새로운 기억의 비율 결정 |

---

# GRU와 LSTM 비교

| LSTM | GRU |
|-------|------|
| Cell State 사용 | Cell State 없음 |
| Hidden State + Cell State | Hidden State만 사용 |
| Forget/Input/Output Gate | Reset/Update Gate |
| Parameter 많음 | Parameter 적음 |
| 구조 복잡 | 구조 단순 |
| 계산량 큼 | 계산량 작음 |

---

# 장점

- 구조가 단순하다.
- Parameter 수가 적다.
- 학습 속도가 빠르다.
- Gradient Vanishing을 완화한다.
- LSTM과 비슷한 성능을 보인다.

---

# 한계

- Cell State가 없어 매우 긴 Sequence에서는 LSTM보다 성능이 떨어질 수 있다.
- 모든 문제에서 LSTM보다 우수한 것은 아니다.

실제 성능은 데이터와 문제에 따라 달라진다.

---

# 후속 연구에 미친 영향

GRU는 LSTM보다 단순한 구조 덕분에 다양한 Sequence Modeling 문제에서 널리 사용되었다.

특히

- 음성 인식
- 시계열 예측
- 기계 번역
- 이상 탐지

등 계산 효율이 중요한 분야에서 많이 활용된다.

현재도 PyTorch와 TensorFlow에서 기본 RNN Layer로 제공된다.

---

# 내가 이해한 내용

GRU는 **LSTM을 단순화한 RNN 구조**이다.

가장 큰 특징은 Forget Gate와 Input Gate를 하나의 Update Gate로 통합하고, Cell State를 제거하여 Hidden State 하나만으로 정보를 관리한다는 점이다.

즉, LSTM보다 구조는 단순하지만 중요한 정보는 유지하고 불필요한 정보는 제거하는 기능은 그대로 유지하여 더 빠른 학습과 효율적인 Sequence Modeling을 가능하게 한다.
