# 10.5 Machine Translation and the Dataset

---

# 왜 Machine Translation Dataset이 필요한가?

기계 번역(Machine Translation)은 한 언어의 문장을 다른 언어의 문장으로 변환하는 작업이다.

예를 들어

```
English

↓

French
```

또는

```
English

↓

Korean
```

처럼 입력 문장과 출력 문장이 서로 다른 언어로 구성된다.

따라서 일반적인 Language Model과 달리 **입력 문장(Source Sentence)과 정답 문장(Target Sentence)을 함께 포함하는 데이터셋**이 필요하다.

---

# Machine Translation이란?

Machine Translation(MT)은

> **한 언어(Source Language)의 문장을 다른 언어(Target Language)의 문장으로 자동 변환하는 기술**이다.

예를 들어

| Source | Target |
|---------|--------|
| I love AI | 나는 AI를 좋아한다. |
| Thank you | 감사합니다. |
| Good morning | 좋은 아침입니다. |

입력과 출력이 서로 다른 Sequence라는 점이 Language Model과 가장 큰 차이이다.

---

# Parallel Corpus

기계 번역에서는

입력 문장과 정답 문장이 쌍(Pair)으로 존재하는 데이터셋을 사용한다.

이를

**Parallel Corpus**

라고 한다.

예를 들어

| English | French |
|----------|---------|
| I love AI | J'aime l'IA |
| Thank you | Merci |
| Good night | Bonne nuit |

처럼

각 문장이 정확하게 대응된다.

---

# Source Language와 Target Language

Machine Translation에서는

두 가지 언어가 존재한다.

- Source Language : 입력 언어
- Target Language : 출력 언어

예를 들어

```
I love AI

↓

나는 AI를 좋아한다.
```

에서는

- Source : English
- Target : Korean

이다.

---

# Tokenization

문장을 그대로 사용할 수 없기 때문에

Tokenization을 수행한다.

예를 들어

```
I love AI
```

↓

```
["I","love","AI"]
```

또는

```
나는 AI를 좋아한다
```

↓

```
["나는","AI를","좋아한다"]
```

처럼 Token으로 분리한다.

---

# Vocabulary 생성

각 언어마다

Vocabulary를 따로 만든다.

예를 들어

English Vocabulary

```
I

love

AI

thank
```

French Vocabulary

```
Je

aime

IA

merci
```

처럼

Source와 Target은

각각 별도의 Vocabulary를 가진다.

---

# Index Encoding

Neural Network는

숫자만 처리할 수 있다.

따라서

각 Token에 번호를 부여한다.

예를 들어

```
I love AI

↓

[4,15,9]
```

처럼

Index Sequence로 변환한다.

---

# Padding

문장의 길이는 모두 다르다.

예를 들어

```
I love AI
```

와

```
I really love deep learning
```

은 길이가 다르다.

Batch 학습을 위해

Padding을 사용한다.

```
I love AI

↓

I love AI <pad> <pad>
```

처럼

길이를 맞춘다.

---

# Sequence Length

너무 긴 문장은

계산량이 매우 커진다.

따라서

최대 길이를 정한다.

예를 들어

```
Maximum Length

=

10
```

이라면

10개보다 긴 문장은

잘라내거나(Truncation)

Padding을 이용하여 길이를 맞춘다.

---

# Mini-batch 생성

최종적으로

여러 문장을 하나의 Batch로 묶는다.

```text
Source Sentence

↓

Tokenization

↓

Vocabulary

↓

Index Encoding

↓

Padding

↓

Mini-batch
```

이 Batch가

Encoder의 입력으로 사용된다.

---

# Machine Translation Dataset의 특징

Language Model과 달리

입력과 출력이 모두 존재한다.

```text
Source Sentence

↓

Encoder

↓

Decoder

↓

Target Sentence
```

즉,

입력 Sequence와

출력 Sequence를 함께 학습한다.

---

# 장점

- 다양한 언어 번역 가능
- Encoder-Decoder 학습 가능
- Seq2Seq 학습 가능
- 대규모 번역 모델 구축 가능

---

# 한계

- Parallel Corpus 구축 비용이 매우 크다.
- 저자원 언어(Low-resource Language)는 데이터가 부족하다.
- 문장의 길이가 길어질수록 학습이 어려워진다.

---

# 후속 연구에 미친 영향

Machine Translation은 Seq2Seq 모델이 가장 크게 발전한 분야이다.

이후

- Encoder-Decoder
- Attention
- Transformer
- BERT
- GPT

등 현대 자연어 처리 모델의 발전에 중요한 역할을 하였다.

특히 Transformer는 기계 번역 문제를 해결하기 위해 제안된 모델이다.

---

# 내가 이해한 내용

Machine Translation은 입력 문장과 출력 문장이 서로 다른 언어로 이루어진 Sequence Prediction 문제이다.

이를 학습하기 위해서는 입력과 정답 문장이 쌍으로 존재하는 **Parallel Corpus**가 필요하며, 각 문장은 Tokenization, Vocabulary 생성, Index Encoding, Padding 과정을 거쳐 Mini-batch 형태로 변환된다.

즉, 10.5의 핵심은 **기계 번역 모델을 학습하기 위한 데이터셋을 어떻게 구성하고 전처리하는지 이해하는 것**이다.
