# 10.4 Bidirectional Recurrent Neural Networks

---

# 왜 Bidirectional RNN이 등장했는가?

기본 RNN, LSTM, GRU는 Sequence를 앞에서 뒤로만 처리한다.

즉,

현재 단어를 이해할 때 이전 단어(Past)만 사용할 수 있다.

하지만 자연어에서는 **이전 문맥뿐 아니라 이후 문맥(Future)도 함께 알아야 의미를 정확하게 이해할 수 있는 경우가 많다.**

Bidirectional RNN(BiRNN)은 이러한 문제를 해결하기 위해 **정방향(Forward)과 역방향(Backward) RNN을 동시에 사용하는 구조**를 제안하였다.

---

# 기존 RNN의 한계

기본 RNN은

```text
I

↓

love

↓

deep

↓

learning
```

처럼

앞에서 뒤로만 정보를 전달한다.

즉,

현재 단어는

이전 단어만 참고할 수 있다.

예를 들어

```
The bank is near the river.
```

에서

"bank"가

은행인지

강둑인지

뒤에 나오는

```
river
```

를 보기 전에는

정확히 알기 어렵다.

---

# 핵심 아이디어

Bidirectional RNN의 핵심은 매우 단순하다.

> **문장을 앞에서도 읽고 뒤에서도 읽자.**

즉,

- Forward RNN
- Backward RNN

을 동시에 수행한다.

---

# Bidirectional RNN 구조

기본 RNN은

```text
x1

↓

x2

↓

x3

↓

x4
```

순서로만 처리한다.

Bidirectional RNN은

```text
Forward

x1 → x2 → x3 → x4

Backward

x1 ← x2 ← x3 ← x4
```

두 개의 RNN을 동시에 사용한다.

---

# Hidden State

Forward Hidden State는

과거 정보를 기억한다.

$$
\overrightarrow{h_t}
$$

Backward Hidden State는

미래 정보를 기억한다.

$$
\overleftarrow{h_t}
$$

최종 Hidden State는

두 Hidden State를 결합하여 만든다.

$$
h_t=
[\overrightarrow{h_t};
\overleftarrow{h_t}]
$$

즉,

Concatenation을 수행한다.

---

# 정보 전달 과정

```text
Forward

x1 → x2 → x3 → x4

Backward

x1 ← x2 ← x3 ← x4

↓

Concatenate

↓

Output
```

현재 단어는

앞과 뒤 문맥을 모두 사용할 수 있다.

---

# Forward RNN

Forward RNN은

기존 RNN과 동일하다.

```text
Past

↓

Present
```

즉,

이전 정보를 이용하여

현재를 이해한다.

---

# Backward RNN

Backward RNN은

반대로

```text
Future

↓

Present
```

를 계산한다.

즉,

미래 정보를 이용하여

현재를 이해한다.

---

# 왜 성능이 좋아질까?

예를 들어

```
He sat on the bank.
```

에서는

bank의 의미를 알기 어렵다.

하지만

```
He sat on the bank of the river.
```

처럼

뒤에

```
river
```

가 나오면

bank가

강둑이라는 것을 쉽게 알 수 있다.

즉,

미래 문맥까지 함께 사용하면

단어의 의미를 더 정확하게 이해할 수 있다.

---

# BiRNN 구조

```text
Input

↓

Forward RNN

↓

Backward RNN

↓

Concatenate

↓

Output
```

---

# 장점

- 과거와 미래 정보를 모두 활용
- 문맥(Context) 이해 향상
- 자연어 처리 성능 향상
- 단어 의미를 더 정확하게 표현

---

# 한계

Bidirectional RNN은

미래 입력까지 모두 알아야 동작한다.

따라서

- 실시간 번역
- 실시간 음성 인식
- 다음 단어 생성(Language Generation)

에는 사용할 수 없다.

즉,

전체 Sequence가 미리 존재해야 한다.

---

# RNN과 비교

| RNN | Bidirectional RNN |
|------|-------------------|
| 과거 정보만 사용 | 과거 + 미래 정보 사용 |
| Hidden State 1개 | Hidden State 2개 |
| 실시간 처리 가능 | 실시간 처리 어려움 |
| 문맥 정보 제한 | 문맥 정보 풍부 |

---

# 후속 연구에 미친 영향

Bidirectional RNN은 자연어 이해(NLU) 분야에서 큰 성능 향상을 가져왔다.

이후

- BiLSTM
- BiGRU
- ELMo
- BERT

등 대부분의 자연어 이해 모델에서 양방향 문맥을 사용하는 아이디어로 발전하였다.

특히 BERT는 Transformer 기반이지만 **양방향 문맥을 동시에 활용한다는 점에서 Bidirectional RNN의 아이디어를 계승한 모델**이라고 볼 수 있다.

---

# 내가 이해한 내용

Bidirectional RNN은 **하나의 문장을 앞에서만 읽는 것이 아니라 앞과 뒤에서 동시에 읽는 RNN**이다.

기본 RNN은 과거 정보만 이용하기 때문에 현재 단어의 의미를 정확하게 이해하지 못하는 경우가 있지만, Bidirectional RNN은 미래 문맥까지 함께 고려하여 더 풍부한 표현을 학습할 수 있다.

다만 미래 입력이 모두 존재해야 하기 때문에 실시간 예측이나 문장 생성에는 적합하지 않고, 문장 분류나 개체명 인식(NER)과 같은 자연어 이해 작업에서 주로 사용된다.
