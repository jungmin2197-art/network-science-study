# 왜 Transformer가 등장했는가?

기존 Seq2Seq 모델은 RNN 기반으로 동작하였다.

하지만 RNN은

- 순차적 계산
- 병렬 처리 불가능
- 긴 문장에서 Long-range Dependency 문제
- 학습 속도 저하

등의 한계를 가지고 있었다.

Transformer는 이러한 문제를 해결하기 위해 **RNN을 완전히 제거하고 Self-Attention만으로 Sequence를 처리하는 모델**을 제안하였다.

---

# 핵심 아이디어

Transformer의 핵심은

> **"Attention Is All You Need"**

즉,

Sequence를 처리하기 위해

RNN이나 CNN 없이

Self-Attention만 사용한다.

---

# Transformer 전체 구조

Transformer는

두 부분으로 구성된다.

```text
Input

↓

Encoder

↓

Context Representation

↓

Decoder

↓

Output
```

Encoder는 입력 문장을 이해하고,

Decoder는 출력 문장을 생성한다.

---

# Transformer Encoder

Encoder는

동일한 Encoder Block을 여러 번 반복한다.

원 논문에서는

```
Encoder × 6
```

을 사용하였다.

각 Encoder Block은

```
Multi-Head Attention

↓

Add & LayerNorm

↓

Feed Forward Network

↓

Add & LayerNorm
```

으로 구성된다.

---

# Multi-Head Attention

Encoder의 첫 번째 단계는

Multi-Head Self-Attention이다.

각 단어는

모든 단어를 참고하여

새로운 표현을 생성한다.

$$
Attention(Q,K,V)
=
Softmax
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
$$

---

# Feed Forward Network (FFN)

Attention 다음에는

각 Token마다

독립적으로 작은 신경망을 통과한다.

수식은

$$
FFN(x)
=
W_2
ReLU(W_1x+b_1)
+b_2
$$

이다.

즉,

Attention으로 관계를 학습한 뒤

FFN이 각 Token의 표현을 더욱 풍부하게 만든다.

---

# Residual Connection

Transformer는

Residual Connection을 사용한다.

즉,

입력을

출력에 더한다.

$$
Output
=
F(x)+x
$$

Residual Connection은

Gradient Vanishing을 완화하고

깊은 모델의 학습을 쉽게 만든다.

---

# Layer Normalization

Residual Connection 뒤에는

LayerNorm을 적용한다.

```text
Input

↓

Attention

↓

Add

↓

LayerNorm
```

LayerNorm은

Feature의 분포를 안정화하여

학습을 빠르게 만든다.

---

# Transformer Decoder

Decoder 역시

여러 개의 Decoder Block으로 구성된다.

각 Decoder Block은

```
Masked Multi-Head Attention

↓

Add & LayerNorm

↓

Encoder-Decoder Attention

↓

Add & LayerNorm

↓

Feed Forward Network

↓

Add & LayerNorm
```

순으로 수행된다.

---

# Masked Multi-Head Attention

Decoder에서는

미래 단어를

미리 볼 수 없다.

예를 들어

```
I love AI
```

를 생성할 때

```
AI
```

를 예측하기 전에는

그 이후 단어를 사용할 수 없다.

따라서

미래 Token을 가리는

**Mask**를 사용한다.

---

# Encoder-Decoder Attention

Decoder는

Encoder의 출력을 참고하여

번역을 수행한다.

즉,

- Query : Decoder
- Key : Encoder
- Value : Encoder

이다.

이를

Cross Attention이라고도 한다.

---

# Transformer 전체 과정

```text
Input Embedding

↓

Positional Encoding

↓

Encoder

↓

Encoder Output

↓

Decoder

↓

Linear

↓

Softmax

↓

Prediction
```

---

# Transformer의 특징

기존 Seq2Seq와 비교하면

| Seq2Seq | Transformer |
|----------|-------------|
| RNN 사용 | RNN 없음 |
| 순차 계산 | 병렬 계산 |
| Context Vector | Self-Attention |
| Long Dependency 어려움 | Long Dependency 우수 |

---

# 장점

- 병렬 연산 가능
- 긴 문장 처리 우수
- Long-range Dependency 학습
- 높은 성능
- 다양한 분야에 적용 가능

---

# 한계

Self-Attention은

모든 Token 쌍의 관계를 계산한다.

따라서

계산 복잡도가

$$
O(N^2)
$$

이다.

긴 Sequence에서는

메모리 사용량이 매우 커진다.

이를 해결하기 위해

- Performer
- Linformer
- BigBird
- Longformer

등 다양한 효율적인 Transformer가 제안되었다.

---

# 후속 연구에 미친 영향

Transformer는 현대 AI의 표준 모델이 되었다.

이를 기반으로

- BERT
- GPT
- T5
- Vision Transformer
- Graph Transformer
- LLaMA
- PaLM

등 수많은 모델이 등장하였다.

현재 자연어 처리와 컴퓨터 비전 분야 대부분의 최신 모델은 Transformer 구조를 기반으로 한다.

---

# 내가 이해한 내용

Transformer는 **RNN을 제거하고 Self-Attention만으로 Sequence를 처리하는 모델**이다.

Encoder는 Multi-Head Self-Attention과 Feed Forward Network를 반복하여 입력 문장의 표현을 학습하고, Decoder는 Masked Self-Attention과 Encoder-Decoder Attention을 이용하여 출력 문장을 생성한다.

또한 Residual Connection과 Layer Normalization을 통해 깊은 네트워크도 안정적으로 학습할 수 있으며, 병렬 연산이 가능하기 때문에 기존 RNN 기반 Seq2Seq보다 훨씬 빠르고 성능이 뛰어나다.
