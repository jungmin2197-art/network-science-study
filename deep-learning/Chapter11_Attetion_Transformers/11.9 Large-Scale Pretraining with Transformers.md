# 11.9 Large-Scale Pretraining with Transformers

---

# 왜 Large-Scale Pretraining이 등장했는가?

Transformer는 뛰어난 구조를 가지고 있었지만, 특정 Task마다 처음부터 모델을 학습시키는 것은 많은 데이터와 시간이 필요했다.

이를 해결하기 위해 **대규모 텍스트 데이터로 먼저 일반적인 언어 지식을 학습(Pretraining)한 뒤, 특정 Task에 맞게 추가 학습(Fine-tuning)하는 방법**이 제안되었다.

이러한 학습 방식은 자연어 처리의 성능을 크게 향상시켰으며, 현대의 BERT, GPT, T5, LLaMA와 같은 대규모 언어 모델의 기반이 되었다.

---

# Pretraining이란?

Pretraining은

> **대량의 데이터로 먼저 일반적인 지식을 학습하는 과정**이다.

예를 들어

```
Wikipedia

Books

Web Documents
```

등 수십억 개의 문장을 이용하여

언어 자체를 먼저 학습한다.

---

# Fine-tuning이란?

Pretraining이 끝난 모델을

특정 Task에 맞게 다시 학습한다.

예를 들어

```
Pretrained Model

↓

Sentiment Analysis

↓

Fine-tuning
```

또는

```
Pretrained Model

↓

Question Answering

↓

Fine-tuning
```

처럼 사용한다.

---

# 왜 Pretraining이 중요한가?

처음부터 학습하면

```
Task Dataset

↓

학습
```

만 수행한다.

하지만

Pretraining을 이용하면

```
Huge Corpus

↓

Pretraining

↓

Fine-tuning

↓

Task
```

순으로 학습한다.

이미 언어를 이해한 상태에서

Task를 학습하므로

성능이 크게 향상된다.

---

# Transformer의 세 가지 구조

Transformer는

사용하는 부분에 따라

세 가지 구조로 나뉜다.

```
Encoder Only

Encoder-Decoder

Decoder Only
```

이다.

---

# Encoder-Only

대표 모델은

**BERT**이다.

구조는

```text
Input

↓

Transformer Encoder

↓

Task
```

이다.

문장을 이해하는 데 특화되어 있다.

대표적인 활용 분야는

- 문장 분류
- 감정 분석
- 개체명 인식(NER)
- 질의응답(QA)

등이다.

---

# BERT의 학습 방식

BERT는

**Masked Language Modeling (MLM)** 을 사용한다.

예를 들어

```
I love [MASK]
```

를 입력하면

```
AI
```

를 예측한다.

즉,

가려진 단어를 맞추는 방식으로

양방향 문맥(Bidirectional Context)을 학습한다.

---

# Encoder-Decoder

대표 모델은

**T5(Text-to-Text Transfer Transformer)** 이다.

구조는

```text
Input

↓

Encoder

↓

Decoder

↓

Output
```

이다.

입력 문장을 다른 문장으로 변환하는 작업에 적합하다.

대표적인 활용 분야는

- 번역
- 문장 요약
- 질의응답
- 문장 생성

등이다.

---

# T5의 특징

T5는

모든 NLP 문제를

```
Text

↓

Text
```

형태로 변환하여 해결한다.

예를 들어

```
Translate English to Korean:

Hello
```

↓

```
안녕하세요
```

처럼

모든 문제를 Text Generation으로 처리한다.

---

# Decoder-Only

대표 모델은

**GPT(Generative Pre-trained Transformer)** 이다.

구조는

```text
Input

↓

Transformer Decoder

↓

Next Token Prediction
```

이다.

GPT는

이전 단어만 보고

다음 단어를 예측한다.

---

# GPT의 학습 방식

GPT는

**Causal Language Modeling (CLM)** 을 사용한다.

예를 들어

```
I love
```

↓

```
AI
```

를 예측한다.

즉,

현재까지의 단어만 이용하여

다음 단어를 생성한다.

---

# Encoder vs Decoder

| Encoder (BERT) | Decoder (GPT) |
|---------------|---------------|
| 양방향(Bidirectional) | 단방향(Causal) |
| 문장 이해 | 문장 생성 |
| MLM | Next Token Prediction |

---

# 세 가지 구조 비교

| 모델 | 구조 | 대표 모델 | 주요 목적 |
|------|------|-----------|-----------|
| Encoder Only | Encoder | BERT | 문장 이해 |
| Encoder-Decoder | Encoder + Decoder | T5 | 문장 변환 |
| Decoder Only | Decoder | GPT | 문장 생성 |

---

# Scalability

Transformer는

모델 크기를 크게 만들수록

성능이 향상되는 특징이 있다.

대표적으로

- 더 많은 Parameter
- 더 많은 데이터
- 더 긴 학습 시간

을 사용할수록

성능이 꾸준히 향상된다.

이를

**Scaling Law**라고 한다.

---

# Large Language Model (LLM)

LLM은

수십억~수천억 개의 Parameter를 가진

대규모 Transformer 모델이다.

대표적인 모델은

- GPT
- LLaMA
- Gemini
- Claude

등이 있다.

이들은

Pretraining을 통해

광범위한 언어 지식을 학습한 후

다양한 자연어 처리 작업을 수행한다.

---

# 장점

- 다양한 Task에 활용 가능
- 적은 데이터로 Fine-tuning 가능
- 뛰어난 일반화 성능
- 높은 확장성(Scalability)

---

# 한계

- 막대한 학습 비용
- 많은 GPU와 메모리 필요
- 대규모 데이터 필요
- 추론 비용 증가

---

# 후속 연구에 미친 영향

Large-Scale Pretraining은 현대 AI의 표준 학습 방식이 되었다.

이후

- BERT
- GPT 시리즈
- T5
- PaLM
- LLaMA
- Gemini

등 대부분의 최신 AI 모델이 대규모 사전학습을 기반으로 개발되었다.

또한 Instruction Tuning, Reinforcement Learning from Human Feedback(RLHF), Retrieval-Augmented Generation(RAG) 등 다양한 기술로 발전하였다.

---

# 내가 이해한 내용

Large-Scale Pretraining은 **대규모 데이터로 일반적인 언어 지식을 먼저 학습한 뒤, 특정 작업에 맞게 추가 학습하는 방식**이다.

Transformer는 사용하는 구조에 따라 Encoder-Only(BERT), Encoder-Decoder(T5), Decoder-Only(GPT)로 나뉘며, 각각 문장 이해, 문장 변환, 문장 생성에 특화되어 있다.

현재의 대규모 언어 모델(LLM)은 이러한 Transformer 구조를 기반으로 방대한 데이터에서 사전학습을 수행하여 다양한 자연어 처리 작업을 하나의 모델로 해결한다.
