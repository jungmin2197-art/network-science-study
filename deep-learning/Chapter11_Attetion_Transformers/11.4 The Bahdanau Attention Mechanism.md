# 11.4 The Bahdanau Attention Mechanism

## 논문

**Neural Machine Translation by Jointly Learning to Align and Translate**

- Dzmitry Bahdanau
- Kyunghyun Cho
- Yoshua Bengio

ICLR 2015

---

# 왜 Bahdanau Attention이 등장했는가?

기존 Seq2Seq 모델은 입력 문장을 하나의 Context Vector로 압축한 뒤 Decoder가 이를 이용하여 번역을 수행하였다.

하지만 문장이 길어질수록 하나의 Context Vector에 모든 정보를 저장해야 하기 때문에 중요한 정보가 손실되는 **Information Bottleneck** 문제가 발생하였다.

Bahdanau Attention은 이러한 문제를 해결하기 위해 **Decoder가 매 시점마다 Encoder의 모든 Hidden State를 참고하도록 하는 Attention Mechanism**을 제안하였다.

---

# 기존 Seq2Seq의 한계

기존 Encoder-Decoder 구조는

```text
Input Sentence

↓

Encoder

↓

Context Vector

↓

Decoder

↓

Output Sentence
```

처럼

모든 입력 정보를

하나의 Context Vector에 저장한다.

문장이 길어질수록

- 정보 손실
- 번역 성능 저하
- Long Sentence 처리 어려움

문제가 발생한다.

---

# 핵심 아이디어

Bahdanau Attention의 핵심은

> **하나의 Context Vector만 사용하지 말고, Decoder가 필요할 때마다 Encoder의 모든 Hidden State를 참고하자.**

즉,

Decoder는

매 Time Step마다

다시 Encoder를 바라본다.

---

# Encoder

Encoder는

입력 문장을 순차적으로 처리하며

모든 Hidden State를 저장한다.

예를 들어

```text
I

↓

love

↓

AI
```

라면

```text
h1

h2

h3
```

를 모두 보존한다.

기존 Seq2Seq처럼

마지막 Hidden State만 사용하는 것이 아니다.

---

# Decoder

Decoder는

출력 단어를 생성할 때마다

Encoder의 모든 Hidden State를 확인한다.

예를 들어

```text
Decoder State

↓

Attention

↓

h1

h2

h3
```

를 모두 비교한다.

가장 중요한 Hidden State에

더 큰 Weight를 부여한다.

---

# Alignment Score

현재 Decoder Hidden State와

Encoder Hidden State의

유사도를 계산한다.

$$
e_{t,i}
=
score(s_{t-1},h_i)
$$

여기서

- \(s_{t-1}\) : Decoder Hidden State
- \(h_i\) : Encoder Hidden State

이다.

Alignment Score가 높을수록

더 중요한 입력 단어이다.

---

# Attention Weight

Alignment Score를

Softmax에 통과시켜

Attention Weight를 만든다.

$$
\alpha_{t,i}
=
\frac{\exp(e_{t,i})}
{\sum_j\exp(e_{t,j})}
$$

Attention Weight의 합은

항상 1이다.

---

# Dynamic Context Vector

기존 Seq2Seq는

Context Vector가 하나였다.

Bahdanau Attention에서는

매 Decoder Step마다

새로운 Context Vector를 계산한다.

$$
c_t
=
\sum_i
\alpha_{t,i}h_i
$$

즉,

Context Vector가

시간마다 계속 바뀐다.

이를

**Dynamic Context Vector**라고 한다.

---

# Decoder Update

최종적으로

Decoder는

- 이전 Hidden State
- 현재 입력
- Dynamic Context Vector

를 이용하여

새로운 Hidden State를 생성한다.

즉,

```text
Current Input

+

Previous Hidden State

+

Attention Context

↓

Decoder
```

가 된다.

---

# Bahdanau Attention 과정

```text
Encoder Hidden States

↓

Alignment Score 계산

↓

Softmax

↓

Attention Weight

↓

Dynamic Context Vector

↓

Decoder

↓

Output
```

---

# 기존 Seq2Seq와 비교

| Seq2Seq | Bahdanau Attention |
|----------|--------------------|
| Context Vector 1개 | Context Vector 매 시점 계산 |
| 마지막 Hidden State만 사용 | 모든 Hidden State 사용 |
| 긴 문장 성능 저하 | 긴 문장 성능 향상 |

---

# 장점

- 긴 문장을 더 잘 처리한다.
- Information Bottleneck을 완화한다.
- 중요한 단어에 집중할 수 있다.
- 번역 성능이 크게 향상된다.

---

# 한계

매 Decoder Step마다

모든 Encoder Hidden State를 확인해야 하므로

계산량이 증가한다.

또한

여전히 RNN 기반이므로

병렬 처리가 어렵다.

---

# 후속 연구에 미친 영향

Bahdanau Attention은 현대 Attention Mechanism의 출발점이 되었다.

이후

- Luong Attention
- Self-Attention
- Multi-Head Attention
- Transformer

등 다양한 Attention 모델로 발전하였다.

특히 Transformer는

Encoder Hidden State뿐 아니라

모든 Token이 서로 Attention을 수행하도록 확장하였다.

---

# 내가 이해한 내용

Bahdanau Attention은 **기존 Seq2Seq의 Information Bottleneck 문제를 해결하기 위해 제안된 Attention Mechanism**이다.

기존 모델은 입력 문장을 하나의 Context Vector로 압축했지만, Bahdanau Attention은 Decoder가 출력 단어를 생성할 때마다 Encoder의 모든 Hidden State를 다시 참고하여 새로운 Context Vector를 계산한다.

즉, **입력 문장을 한 번만 기억하는 것이 아니라 필요한 순간마다 다시 참고하는 방식**으로 번역 성능을 크게 향상시켰다.
