# 왜 Multi-Head Attention이 등장했는가?

기존 Attention은 하나의 Attention만 수행하였다.

즉,

하나의 Query, Key, Value를 이용하여

하나의 관계만 학습할 수 있었다.

하지만 하나의 문장 안에는

- 문법 관계
- 의미 관계
- 위치 관계
- 장거리 의존성

등 다양한 관계가 동시에 존재한다.

Multi-Head Attention은

**여러 개의 Attention을 동시에 수행하여 서로 다른 관계를 병렬로 학습하기 위해** 제안되었다.

---

# 기존 Attention의 한계

기존 Attention은

```text
Query

↓

Attention

↓

Output
```

구조이다.

즉,

한 번의 Attention으로

모든 정보를 학습해야 한다.

따라서

복잡한 문장에서는

여러 종류의 관계를 동시에 표현하기 어렵다.

---

# 핵심 아이디어

Multi-Head Attention의 핵심은

> **Attention을 여러 번 병렬로 수행한 뒤 결과를 합치자.**

이다.

즉,

```text
Query

↓

Head1

Head2

Head3

...

Headh

↓

Concatenate

↓

Linear

↓

Output
```

를 수행한다.

---

# Head란?

Head는

하나의 독립적인 Attention을 의미한다.

각 Head는

자신만의

- Query Weight
- Key Weight
- Value Weight

를 가진다.

즉,

각 Head는

서로 다른 정보를 학습할 수 있다.

---

# Query, Key, Value 생성

입력 벡터 X에서

각 Head마다

서로 다른 Weight를 이용하여

Q, K, V를 생성한다.

$$
Q=XW_Q
$$

$$
K=XW_K
$$

$$
V=XW_V
$$

여기서

각 Head는

독립적인 Weight를 가진다.

---

# 각 Head의 Attention

각 Head는

Scaled Dot Product Attention을 수행한다.

$$
head_i
=
Attention(Q_i,K_i,V_i)
$$

즉,

모든 Head가

독립적으로 Attention을 계산한다.

---

# Concatenation

각 Head의 출력을

하나로 연결한다.

$$
Concat(head_1,\cdots,head_h)
$$

즉,

```text
Head1 Output

Head2 Output

Head3 Output

↓

Concatenate
```

를 수행한다.

---

# 최종 Linear Layer

Concatenate한 결과를

Linear Layer에 통과시켜

최종 출력을 생성한다.

$$
MultiHead(Q,K,V)
=
Concat(head_1,\cdots,head_h)W_O
$$

여기서

\(W_O\)는

출력 Weight Matrix이다.

---

# Multi-Head Attention 과정

```text
Input

↓

Q, K, V 생성

↓

Head1 Attention

Head2 Attention

...

Headh Attention

↓

Concatenate

↓

Linear

↓

Output
```

---

# 왜 여러 개의 Head를 사용할까?

각 Head는

서로 다른 특징을 학습한다.

예를 들어

Head 1

→ 문법 관계

Head 2

→ 의미 관계

Head 3

→ 장거리 의존성

Head 4

→ 위치 관계

처럼

각기 다른 정보를 학습할 수 있다.

---

# Single Head와 비교

| Single Head | Multi-Head |
|-------------|------------|
| Attention 1번 | 여러 번 수행 |
| 하나의 관계 학습 | 다양한 관계 학습 |
| 표현력 제한 | 표현력 증가 |
| 병렬 표현 부족 | 병렬 표현 가능 |

---

# 장점

- 다양한 관계를 동시에 학습한다.
- 표현력이 크게 증가한다.
- 장거리 의존성을 효과적으로 학습한다.
- Transformer의 성능을 크게 향상시킨다.

---

# 한계

- Parameter 수가 증가한다.
- 계산량이 증가한다.
- 메모리 사용량이 커진다.

하지만 GPU를 이용한 병렬 연산 덕분에

실제로는 매우 효율적으로 학습할 수 있다.

---

# 후속 연구에 미친 영향

Multi-Head Attention은 Transformer의 핵심 연산이다.

이후

- BERT
- GPT
- Vision Transformer (ViT)
- Graph Transformer
- LLaMA

등 대부분의 Transformer 기반 모델에서 동일한 구조를 사용한다.

---

# 내가 이해한 내용

Multi-Head Attention은 하나의 Attention만 사용하는 것이 아니라 여러 개의 Attention을 동시에 수행하는 구조이다.

각 Head는 서로 다른 Query, Key, Value Projection을 사용하여 서로 다른 관계를 학습하며, 마지막에는 모든 Head의 출력을 하나로 결합하여 최종 표현을 만든다.

즉, **여러 사람이 하나의 문장을 서로 다른 관점에서 동시에 분석한 뒤 결과를 종합하는 것**과 같은 방식이라고 이해할 수 있다.
