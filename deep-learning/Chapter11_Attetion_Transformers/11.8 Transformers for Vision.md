**An Image is Worth 16×16 Words: Transformers for Image Recognition at Scale**

- Alexey Dosovitskiy

ICLR 2021

# 왜 Vision Transformer가 등장했는가?

Transformer는 자연어 처리(NLP) 분야에서 뛰어난 성능을 보였지만, 이미지는 문장처럼 Token으로 구성되어 있지 않다.

기존 컴퓨터 비전에서는 CNN이 지역적인 특징(Local Feature)을 추출하는 데 매우 효과적이었다.

Vision Transformer(ViT)는 **이미지를 작은 Patch들의 Sequence로 변환하여 Transformer를 그대로 적용하는 방법**을 제안하였다.

---

# 기존 CNN의 특징

CNN은

```text
Image

↓

Convolution

↓

Pooling

↓

Classification
```

구조를 사용한다.

Convolution을 이용하여

지역적인 특징(Local Feature)을 학습한다.

---

# CNN의 한계

CNN은

- Convolution Kernel 크기에 의존한다.
- 먼 거리의 관계(Long-range Dependency)를 학습하기 어렵다.
- 매우 깊은 Network가 필요하다.

Transformer의 Self-Attention은

모든 Patch의 관계를 동시에 학습할 수 있다.

---

# 핵심 아이디어

Vision Transformer의 핵심은

> **이미지를 작은 Patch로 나누어 각각을 하나의 Token처럼 처리하자.**

즉,

```text
Image

↓

Patch

↓

Patch Embedding

↓

Transformer

↓

Classification
```

를 수행한다.

---

# Patch Embedding

이미지를

작은 Patch로 나눈다.

예를 들어

```
224 × 224 Image
```

를

```
16 × 16 Patch
```

로 나누면

```
14 × 14

=

196개의 Patch
```

가 생성된다.

각 Patch는

Transformer의 Token 역할을 한다.

---

# Patch Flatten

각 Patch는

2차원 이미지이다.

Transformer는

벡터를 입력으로 사용하므로

Patch를 1차원 벡터로 펼친다(Flatten).

```text
16×16×3

↓

768차원 Vector
```

이 된다.

---

# Linear Projection

Flatten된 Patch를

Linear Layer에 통과시켜

Embedding을 생성한다.

$$
z_0=[x_{class};x_p^1E;\cdots;x_p^NE]+E_{pos}
$$

여기서

- \(x_p^i\) : i번째 Patch
- \(E\) : Embedding Matrix
- \(E_{pos}\) : Position Embedding

이다.

---

# Position Embedding

Transformer는

Patch의 위치를 알 수 없다.

따라서

Patch마다

위치 정보를 추가한다.

```text
Patch Embedding

+

Position Embedding

↓

Transformer Input
```

이 된다.

---

# Class Token ([CLS])

ViT는

입력 앞에

특별한 Token인

```
[CLS]
```

를 추가한다.

```text
[CLS]

Patch1

Patch2

...

Patch196
```

Transformer를 통과한 후

최종

```
[CLS]
```

Embedding을 이용하여

이미지를 분류한다.

---

# Transformer Encoder

ViT는

Transformer의

Encoder만 사용한다.

Encoder Block은

```
Multi-Head Self-Attention

↓

Add & LayerNorm

↓

Feed Forward Network

↓

Add & LayerNorm
```

으로 구성된다.

즉,

NLP에서 사용한 Transformer Encoder와

거의 동일하다.

---

# Vision Transformer 전체 과정

```text
Image

↓

Patch 분할

↓

Flatten

↓

Linear Embedding

↓

Position Embedding

↓

Transformer Encoder

↓

[CLS]

↓

MLP Head

↓

Classification
```

---

# CNN과 ViT 비교

| CNN | Vision Transformer |
|------|--------------------|
| Convolution 사용 | Self-Attention 사용 |
| 지역 특징 학습 | 전역 관계 학습 |
| Kernel 필요 | Patch 사용 |
| Translation Equivariance | Position Embedding 필요 |

---

# 장점

- Long-range Dependency 학습
- 전역(Global) 정보를 효과적으로 활용
- 다양한 Vision Task에 적용 가능
- Transformer 구조를 그대로 활용 가능

---

# 한계

- 많은 학습 데이터가 필요하다.
- 계산량이 크다.
- Patch 크기에 따라 성능이 달라질 수 있다.
- 작은 데이터셋에서는 CNN보다 성능이 떨어질 수 있다.

---

# 후속 연구에 미친 영향

Vision Transformer는 컴퓨터 비전 분야에 Transformer를 성공적으로 적용한 대표적인 모델이다.

이후

- DeiT
- Swin Transformer
- BEiT
- MAE
- Segment Anything (SAM)

등 다양한 Vision Transformer 기반 모델이 등장하였다.

또한 의료 영상, 객체 탐지(Object Detection), 영상 분할(Segmentation) 등 다양한 컴퓨터 비전 분야로 확장되었다.

---

# 내가 이해한 내용

Vision Transformer는 **이미지를 작은 Patch들의 Sequence로 변환하여 Transformer Encoder에 입력하는 모델**이다.

기존 CNN처럼 Convolution을 사용하는 대신, 각 Patch를 하나의 Token으로 취급하여 Self-Attention으로 Patch 간의 관계를 학습한다.

또한 Patch의 순서를 알 수 있도록 Position Embedding을 추가하고, 최종적으로 **[CLS] Token**의 출력을 이용하여 이미지를 분류한다.

즉, Vision Transformer의 핵심은 **"이미지를 문장처럼 생각하고 Transformer로 처리하는 것"**이다.
