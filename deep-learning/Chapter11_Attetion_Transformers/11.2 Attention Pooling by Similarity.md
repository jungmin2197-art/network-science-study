# 11.2 Attention Pooling by Similarity

---

# 왜 Attention Pooling이 필요한가?

기존의 Average Pooling이나 Max Pooling은 모든 입력을 동일하게 처리하거나 가장 큰 값만 선택한다.

하지만 실제 문제에서는 모든 정보가 동일하게 중요한 것은 아니다.

예를 들어 문장을 읽을 때도 모든 단어를 똑같이 중요하게 생각하지 않는다.

Attention Pooling은

**입력과 얼마나 비슷한지(Similarity)에 따라 중요한 정보에 더 큰 가중치를 부여하는 Pooling 방법**이다.

---

# 기존 Pooling의 한계

CNN에서 많이 사용하는 Pooling에는

- Average Pooling
- Max Pooling

이 있다.

### Average Pooling

모든 값을 동일한 비중으로 평균낸다.

```
2 4 6

↓

(2+4+6)/3

↓

4
```

모든 정보의 중요도를 동일하게 취급한다.

---

### Max Pooling

가장 큰 값만 선택한다.

```
2 4 6

↓

6
```

가장 큰 특징만 남기지만

나머지 정보는 모두 버리게 된다.

---

# 핵심 아이디어

Attention Pooling의 핵심은

> **중요한 정보일수록 더 큰 가중치를 주어 평균을 계산하자.**

즉,

```
Similarity

↓

Attention Weight

↓

Weighted Average

↓

Output
```

라는 과정이다.

---

# Similarity란?

Similarity는

**두 벡터가 얼마나 비슷한지 나타내는 값**이다.

예를 들어

```
Query

↓

Key
```

의 유사도를 계산한다.

유사도가 높을수록

더 중요한 정보라고 판단한다.

---

# Attention Weight

Similarity를 계산한 후

Softmax를 적용하여

Attention Weight를 만든다.

예를 들어

```
Similarity

2

1

0
```

이면

Softmax 이후

```
0.66

0.24

0.10
```

처럼

확률 형태의 Weight가 생성된다.

Weight의 합은 항상 1이다.

---

# Attention Pooling

최종 출력은

Value들의 가중 평균이다.

$$
Output=\sum_i\alpha_iV_i
$$

여기서

- \(V_i\) : Value
- \(\alpha_i\) : Attention Weight

이다.

즉,

중요한 Value일수록

출력에 더 크게 반영된다.

---

# Nadaraya-Watson Regression

Attention Pooling은

사실 오래전부터 사용되던

**Nadaraya-Watson Kernel Regression**과 매우 비슷한 아이디어이다.

핵심은

> **입력과 가까운 데이터일수록 더 크게 반영하자.**

이다.

예를 들어

```
현재 온도 예측

↓

비슷한 날씨 데이터

↓

더 큰 Weight

↓

예측
```

처럼

가까운 데이터에 더 높은 가중치를 부여한다.

Attention도

Query와 비슷한 Key에

더 큰 Weight를 주는 방식이다.

---

# Kernel Function

Kernel은

두 데이터의 유사도를 계산하는 함수이다.

대표적으로

- Gaussian Kernel
- Epanechnikov Kernel
- Boxcar Kernel

등이 있다.

Attention에서는

Kernel 대신

Dot Product나 Additive Score를 사용한다.

---

# Attention Pooling 과정

```text
Query

↓

Similarity 계산

↓

Attention Weight

↓

Weighted Sum(Value)

↓

Output
```

---

# Average Pooling과 비교

| Average Pooling | Attention Pooling |
|-----------------|-------------------|
| 동일한 Weight | 서로 다른 Weight |
| 중요도 고려 X | 중요도 고려 O |
| 단순 평균 | Weighted Average |

---

# Max Pooling과 비교

| Max Pooling | Attention Pooling |
|-------------|-------------------|
| 하나만 선택 | 여러 정보를 함께 사용 |
| 정보 손실 발생 | 정보 손실 감소 |

---

# 장점

- 중요한 정보에 집중할 수 있다.
- 입력마다 다른 Weight를 사용할 수 있다.
- 긴 Sequence에서도 중요한 정보를 유지할 수 있다.
- 다양한 Attention 모델의 기반이 된다.

---

# 한계

Attention Pooling은

Similarity를 어떻게 계산하느냐에 따라 성능이 달라진다.

따라서

좋은 Attention Score Function이 필요하다.

이를 해결하기 위해

다음 절에서

- Dot Product Attention
- Scaled Dot Product Attention
- Additive Attention

을 학습한다.

---

# 후속 연구에 미친 영향

Attention Pooling은

Transformer의 핵심 아이디어인

Weighted Sum의 기반이 되었다.

이후

- Bahdanau Attention
- Multi-Head Attention
- Self-Attention
- Transformer

모두

Attention Pooling을 사용한다.

---

# 내가 이해한 내용

Attention Pooling은 기존 Average Pooling처럼 모든 정보를 동일하게 평균내는 것이 아니라 **입력과의 유사도(Similarity)를 이용하여 중요한 정보에 더 큰 가중치를 부여하는 Pooling 방법**이다.

즉, Query와 Key의 유사도를 계산하여 Attention Weight를 만들고, 이를 이용해 Value들의 가중 평균을 계산한다.

Transformer의 Attention도 결국 이러한 **Weighted Average**를 수행하는 과정이라고 이해할 수 있다.
