# 왜 Self-Attention이 등장했는가?

기존 RNN과 LSTM은 문장을 순차적으로 처리하였다.

```
A

↓

B

↓

C

↓

D
```

따라서

- 병렬 연산이 어렵고
- 긴 문장에서 Long-range Dependency 학습이 어려우며
- 학습 속도가 느리다는 문제가 있었다.

Self-Attention은 이러한 문제를 해결하기 위해 **문장 전체를 한 번에 바라보면서 각 단어가 다른 모든 단어와의 관계를 동시에 학습하는 방법**을 제안하였다.

---

# 기존 Attention과 Self-Attention의 차이

기존 Bahdanau Attention에서는

```
Decoder

↓

Encoder Hidden States
```

를 참고하였다.

즉,

Decoder와 Encoder 사이에서만 Attention을 수행하였다.

반면 Self-Attention은

```
Input Sentence

↓

Input Sentence
```

자기 자신에 대해 Attention을 수행한다.

즉,

모든 Token이

다른 모든 Token을 참고한다.

---

# 핵심 아이디어

Self-Attention의 핵심은

> **모든 단어가 문장 안의 모든 단어를 동시에 참고하여 새로운 표현을 만든다.**

이다.

예를 들어

```
The animal didn't cross the street because it was tired.
```

에서

```
it
```

은

```
animal
```

을 강하게 참고한다.

Self-Attention은

이러한 관계를 자동으로 학습한다.

---

# Self-Attention 구조

각 Token은

동시에

- Query
- Key
- Value

를 생성한다.

```
Input

↓

Q

K

V
```

그리고

모든 Query가

모든 Key와 Similarity를 계산한다.

---

# Self-Attention 과정

```text
Input

↓

Linear Projection

↓

Q K V 생성

↓

Scaled Dot Product

↓

Softmax

↓

Attention Weight

↓

Weighted Sum

↓

Output
```

즉,

Transformer의 핵심 연산이 수행된다.

---

# Self-Attention 수식

Transformer에서 사용하는 Self-Attention은

$$
Attention(Q,K,V)
=
Softmax
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
$$

이다.

여기서

- Q : Query
- K : Key
- V : Value

이다.

---

# 왜 Self-Attention이 좋은가?

모든 단어가

모든 단어를 동시에 볼 수 있다.

예를 들어

```
I

love

deep

learning
```

이라면

```
I

↓

love

↓

deep

↓

learning
```

순차적으로 보는 것이 아니라

```
I ↔ love

I ↔ deep

I ↔ learning

love ↔ deep

love ↔ learning

deep ↔ learning
```

모든 관계를 동시에 학습한다.

---

# CNN, RNN, Self-Attention 비교

| CNN | RNN | Self-Attention |
|------|------|----------------|
| 지역 정보(Local) | 순차 정보 | 전체 정보(Global) |
| 병렬 가능 | 병렬 어려움 | 병렬 가능 |
| 장거리 관계 어려움 | Long Dependency 문제 | Long Dependency 해결 |

---

# Positional Encoding이 필요한 이유

Self-Attention은

모든 단어를 동시에 처리한다.

즉,

```
I

love

AI
```

와

```
AI

love

I
```

를

동일하게 볼 수도 있다.

왜냐하면

순서를 모르기 때문이다.

따라서

위치 정보를 추가해야 한다.

---

# Positional Encoding

Positional Encoding은

각 Token에

위치 정보를 더하는 방법이다.

즉,

```
Word Embedding

+

Position Information

↓

Transformer Input
```

를 만든다.

---

# Sinusoidal Positional Encoding

Transformer는

사인(Sine)과 코사인(Cosine) 함수를 이용하여

위치를 표현한다.

수식은

$$
PE(pos,2i)
=
\sin
\left(
\frac{pos}{10000^{2i/d}}
\right)
$$

$$
PE(pos,2i+1)
=
\cos
\left(
\frac{pos}{10000^{2i/d}}
\right)
$$

이다.

---

# 왜 Sin과 Cos를 사용할까?

Sin과 Cos는

위치마다

서로 다른 값을 가진다.

또한

가까운 위치는

비슷한 Encoding을 갖는다.

즉,

```
Word Embedding

+

Sin/Cos Position

↓

최종 Embedding
```

이 된다.

---

# Self-Attention 전체 과정

```text
Input Embedding

+

Positional Encoding

↓

Q K V 생성

↓

Multi-Head Attention

↓

Output
```

이것이

Transformer Encoder의 핵심 구조이다.

---

# 장점

- 모든 Token을 동시에 처리
- 병렬 연산 가능
- Long-range Dependency 학습
- 높은 표현력
- Transformer의 핵심 구조

---

# 한계

Self-Attention은

모든 Token 쌍의 관계를 계산해야 한다.

따라서

계산량이

$$
O(N^2)
$$

으로 증가한다.

긴 Sequence에서는

메모리 사용량이 매우 커진다.

이를 해결하기 위해

Performer, Linformer, BigBird 등

Linear Attention 모델이 제안되었다.

---

# 후속 연구에 미친 영향

Self-Attention은 현대 AI 모델의 핵심 연산이 되었다.

이후

- BERT
- GPT
- Vision Transformer
- Graph Transformer
- LLaMA
- PaLM

등 대부분의 모델이

Self-Attention을 기반으로 한다.

---

# 내가 이해한 내용

Self-Attention은 **각 단어가 문장 안의 모든 단어를 동시에 참고하여 새로운 표현을 학습하는 메커니즘**이다.

기존 RNN처럼 순차적으로 정보를 전달하는 것이 아니라 모든 Token 간 관계를 한 번에 계산하므로 장거리 의존성을 효과적으로 학습할 수 있고 병렬 연산도 가능하다.

하지만 Self-Attention은 단어의 순서를 알 수 없기 때문에 Positional Encoding을 추가하여 위치 정보를 함께 입력한다.

즉, Transformer의 핵심은 **Self-Attention으로 단어 간 관계를 학습하고, Positional Encoding으로 단어의 위치 정보를 제공하는 것**이라고 이해할 수 있다.
