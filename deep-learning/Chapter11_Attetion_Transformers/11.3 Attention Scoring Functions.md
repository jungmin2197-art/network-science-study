# 11.3 Attention Scoring Functions

---

# 왜 Attention Score가 필요한가?

Attention Mechanism에서는

Query와 Key의 유사도(Similarity)를 계산하여

어떤 정보를 얼마나 참고할지를 결정한다.

이때 계산되는 값이

**Attention Score**이다.

Attention Score가 클수록

해당 Value를 더 많이 반영하게 된다.

---

# Attention의 전체 과정

Attention은 다음과 같은 순서로 수행된다.

```text
Query

↓

Key와 Similarity 계산

↓

Attention Score

↓

Softmax

↓

Attention Weight

↓

Value의 Weighted Sum

↓

Output
```

Attention Score는

Attention에서 가장 중요한 단계이다.

---

# Attention Score란?

Attention Score는

> **Query와 Key가 얼마나 비슷한지를 나타내는 값**이다.

예를 들어

```
Query

↓

AI
```

와

```
Key

↓

AI

↓

Machine

↓

Love
```

가 있다면

AI와 가장 비슷한 Key가

가장 높은 Score를 가진다.

---

# Dot Product Attention

가장 간단한 방법은

두 벡터의 내적(Dot Product)을 계산하는 것이다.

수식은

$$
score(Q,K)=QK^T
$$

이다.

즉,

벡터가 비슷할수록

내적 값이 커진다.

---

# Dot Product의 의미

예를 들어

```
Q

=

[1,2]
```

```
K

=

[1,3]
```

이라면

내적은

```
1×1

+

2×3

=

7
```

이 된다.

값이 클수록

두 벡터가 더 비슷하다고 판단한다.

---

# Dot Product Attention 과정

```text
Query

↓

Dot Product

↓

Attention Score

↓

Softmax

↓

Attention Weight

↓

Weighted Sum
```

계산이 매우 간단하여

Transformer에서도 기본적으로 사용된다.

---

# Dot Product의 문제점

Embedding Dimension이 커질수록

Dot Product 값도 커진다.

예를 들어

```
Dimension = 32

↓

Score = 5
```

일 수도 있지만

```
Dimension = 1024

↓

Score = 150
```

처럼

값이 지나치게 커질 수 있다.

그러면

Softmax가 거의

```
1

0

0
```

처럼 되어

Gradient가 매우 작아지는 문제가 발생한다.

---

# Scaled Dot Product Attention

이 문제를 해결하기 위해

Dot Product를

Embedding Dimension의 제곱근으로 나누어 준다.

수식은

$$
score(Q,K)
=
\frac{QK^T}{\sqrt{d_k}}
$$

이다.

여기서

- \(d_k\) : Key Vector의 차원

이다.

---

# 왜 √dk로 나눌까?

Embedding Dimension이 커질수록

Dot Product 값도 커진다.

이를 그대로 Softmax에 넣으면

확률이 한쪽으로 치우치게 된다.

따라서

```
Dot Product

↓

√dk로 Scaling

↓

Softmax
```

를 수행하여

Score의 크기를 적절하게 조절한다.

이것이

Transformer에서 사용하는

**Scaled Dot Product Attention**이다.

---

# Additive Attention

Bahdanau Attention에서는

내적 대신

작은 신경망을 이용하여

Similarity를 계산한다.

수식은

$$
score(Q,K)
=
v^T
\tanh(W_qQ+W_kK)
$$

이다.

즉,

Query와 Key를

Linear Layer에 통과시킨 뒤

유사도를 계산한다.

---

# Dot Product와 Additive 비교

| Dot Product | Additive |
|-------------|----------|
| 내적 계산 | 작은 신경망 사용 |
| 계산 속도 빠름 | 계산량 큼 |
| Transformer 사용 | Bahdanau Attention 사용 |

---

# Attention Weight

Attention Score를

바로 사용할 수는 없다.

Softmax를 적용하여

확률 형태로 변환한다.

$$
\alpha_i
=
\frac{\exp(score_i)}
{\sum_j\exp(score_j)}
$$

Attention Weight의 합은

항상 1이 된다.

---

# 최종 Attention

최종 출력은

Value의 가중합이다.

$$
Attention(Q,K,V)
=
Softmax(score(Q,K))
V
$$

Transformer에서는

이를

$$
Attention(Q,K,V)
=
Softmax
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
$$

로 사용한다.

---

# Dot Product vs Scaled Dot Product

| Dot Product | Scaled Dot Product |
|-------------|-------------------|
| QKᵀ | QKᵀ / √dk |
| 큰 차원에서 불안정 | 안정적인 학습 |
| Softmax Saturation 발생 | Gradient 유지 |
| 초기 Attention | Transformer |

---

# 장점

- Query와 Key의 중요도를 계산할 수 있다.
- 필요한 정보에 집중할 수 있다.
- 긴 Sequence도 효과적으로 처리한다.
- Transformer의 핵심 연산이다.

---

# 한계

Attention Score를 계산하더라도

한 번의 Attention으로는

다양한 관계를 모두 학습하기 어렵다.

이를 해결하기 위해

다음 절에서는

**Bahdanau Attention**을,

이후에는

**Multi-Head Attention**을 학습한다.

---

# 후속 연구에 미친 영향

Attention Score는 현대 Transformer의 핵심 연산이다.

특히

- Transformer
- BERT
- GPT
- Vision Transformer
- Graph Transformer

등 대부분의 Attention 기반 모델은

Scaled Dot Product Attention을 사용한다.

---

# 내가 이해한 내용

Attention Score는 Query와 Key가 얼마나 비슷한지를 계산하는 값이다.

가장 단순한 방법은 Dot Product를 이용하는 것이지만, Embedding 차원이 커질수록 Score가 너무 커져 Softmax가 불안정해지는 문제가 발생한다.

Transformer는 이를 해결하기 위해 Dot Product를 √dk로 나누는 **Scaled Dot Product Attention**을 사용하며, 이를 통해 안정적인 학습과 더 좋은 성능을 얻을 수 있다.
