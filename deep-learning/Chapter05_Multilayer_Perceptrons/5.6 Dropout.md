# 5.6 Dropout

> **핵심 키워드:** Dropout · Regularization · Overfitting · Ensemble Learning · Random Mask

---

## 등장 배경

앞 절에서는 딥러닝 모델의 일반화(Generalization)를 향상시키기 위한 다양한 방법을 학습하였다.

하지만 모델의 크기가 커질수록 Parameter의 수도 증가하며, Training Data에 과도하게 적합되는 Overfitting이 발생하기 쉽다.

이를 해결하기 위해 제안된 대표적인 방법이 **Dropout**이다.

Dropout은 학습 과정에서 일부 뉴런을 무작위(Random)로 비활성화하여 모델이 특정 뉴런에 지나치게 의존하는 것을 방지하고, 더 일반화된 특징을 학습하도록 만든다.

---

## 핵심 아이디어

> **학습 중 일부 뉴런을 무작위로 제거하여 여러 개의 서로 다른 모델을 학습하는 효과를 만든다.**

일반적인 MLP는

```
Input
   │
Hidden Layer
   │
Output
```

구조를 가진다.

Dropout을 적용하면

```
Input
   │
Hidden Layer
(X)   (O)   (X)   (O)
   │
Output
```

처럼 일부 뉴런이 임시로 비활성화된다.

중요한 점은

**매 학습마다 제거되는 뉴런이 계속 바뀐다는 것이다.**

---

## 주요 개념

### 1. Dropout

Dropout은 학습 과정에서 일정 비율의 뉴런을 무작위로 제거하는 Regularization 기법이다.

예를 들어

Dropout Rate가 0.5라면

매 Iteration마다 Hidden Layer 뉴런의 절반 정도가 랜덤하게 비활성화된다.

#### 왜 사용하는가?

- Overfitting을 줄이기 위해
- 특정 뉴런에 대한 의존성을 낮추기 위해
- 더욱 일반화된 Feature를 학습하기 위해

---

### 2. Dropout in Practice

Dropout은 **Training 과정에서만 적용**된다.

```
Training

Dropout 적용

↓

Prediction

Dropout 사용 안 함
```

즉,

Inference(Test) 단계에서는 모든 뉴런을 사용한다.

#### 왜 Test에서는 사용하지 않는가?

학습이 끝난 후에는 모든 Feature를 활용하여 가장 정확한 예측을 수행해야 하기 때문이다.

---

### 3. Ensemble Learning 효과

Dropout은 하나의 모델을 학습하는 것처럼 보이지만,

실제로는

```
Model A

Model B

Model C

...

```

처럼 수많은 서로 다른 모델을 동시에 학습하는 것과 비슷한 효과를 만든다.

이를 **Ensemble Learning 효과**라고 한다.

#### 왜 성능이 좋아지는가?

- 특정 뉴런 하나에 의존하지 않는다.
- 다양한 Feature 조합을 학습한다.
- 새로운 데이터에서도 더욱 안정적으로 동작한다.

---

### 4. Dropout Rate

Dropout Rate는 제거할 뉴런의 비율을 의미한다.

예를 들어

- 0.2 → 20% 제거
- 0.5 → 50% 제거

일반적으로 Hidden Layer에서는

```
0.2 ~ 0.5
```

사이를 많이 사용한다.

#### 너무 크게 설정하면?

- 학습이 어려워진다.
- 중요한 정보까지 제거될 수 있다.

#### 너무 작게 설정하면?

- Regularization 효과가 거의 없다.
- Overfitting이 발생할 가능성이 높다.

---

### 5. Implementation

Dropout은 두 가지 방법으로 구현할 수 있다.

#### From Scratch

- Random Mask 생성
- 일부 뉴런을 0으로 변경
- 남은 값은 비율에 맞게 Scaling

이를 통해 Dropout의 내부 동작 원리를 이해할 수 있다.

---

#### PyTorch

PyTorch에서는

```python
nn.Dropout(p=0.5)
```

만으로 쉽게 사용할 수 있다.

Training과 Evaluation 모드를 자동으로 구분하여 처리하므로 실제 프로젝트에서는 대부분 이 방식을 사용한다.

---

## 장점

- Overfitting을 효과적으로 줄일 수 있다.
- Ensemble Learning과 유사한 효과를 얻을 수 있다.
- 구현이 매우 간단하다.
- 대부분의 딥러닝 프레임워크에서 기본적으로 지원한다.
- 새로운 데이터에 대한 일반화 성능을 향상시킬 수 있다.

---

## 한계

- 학습 속도가 다소 느려질 수 있다.
- Dropout Rate를 적절히 설정해야 한다.
- CNN에서는 Fully Connected Layer보다 효과가 작을 수 있다.
- Batch Normalization이 널리 사용되면서 일부 최신 모델에서는 사용 빈도가 감소하였다.

---

## Dropout 동작 과정

```
Training

Input
   │
Hidden Layer
   │
Randomly Drop Neurons
   │
Output
```

```
Inference

Input
   │
Hidden Layer
   │
(All Neurons)
   │
Output
```

Training에서는 일부 뉴런을 제거하지만,

Inference에서는 모든 뉴런을 사용한다.

---

## Dropout vs Weight Decay

| Dropout | Weight Decay |
|----------|--------------|
| 일부 뉴런을 무작위 제거 | Weight 크기를 제한 |
| 모델 의존성 감소 | Parameter 크기 감소 |
| Ensemble 효과 | Model Complexity 감소 |
| Hidden Layer 중심 | 모든 Weight에 적용 |
