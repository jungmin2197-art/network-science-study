# 5.3 Forward Propagation, Backward Propagation, and Computational Graphs

> **핵심 키워드:** Forward Propagation · Backpropagation · Computational Graph · Gradient · Chain Rule · Automatic Differentiation

---

## 등장 배경

앞 절에서는 Multilayer Perceptron(MLP)을 구현하는 방법을 학습하였다.

하지만 모델를 구현했다고 해서 학습 과정까지 이해한 것은 아니다. 실제 딥러닝 모델은 **출력을 계산하는 과정(Forward Propagation)** 과 **오차를 이용해 가중치를 업데이트하는 과정(Backpropagation)** 을 반복하면서 학습된다.

이러한 계산 과정을 체계적으로 표현하기 위해 **Computational Graph(계산 그래프)** 를 사용하며, 이는 현대 딥러닝 프레임워크(PyTorch, TensorFlow 등)의 핵심 원리이다.

---

## 핵심 아이디어

> **딥러닝은 순전파(Forward Propagation)로 예측을 수행하고, 역전파(Backpropagation)로 오차를 전달하여 가중치를 학습한다.**

전체 학습 과정은 다음과 같다.

```
Input
   │
Forward Propagation
   │
Prediction
   │
Loss
   │
Backpropagation
   │
Gradient
   │
Parameter Update
```

즉,

- **Forward Propagation** : 예측값 계산
- **Backpropagation** : Gradient 계산
- **Optimizer** : Weight 업데이트

를 반복하면서 모델이 학습된다.

---

## 주요 개념

### 1. Forward Propagation

Forward Propagation(순전파)은 입력 데이터를 모델에 전달하여 최종 출력값을 계산하는 과정이다.

MLP에서는 각 Layer를 순서대로 통과하면서 Feature를 변환하고, 마지막 Layer에서 Prediction을 생성한다.

```
Input
   │
Linear
   │
ReLU
   │
Linear
   │
Output
```

이 과정에서 모든 Layer의 출력값은 이후 Backpropagation을 위해 저장된다.

#### 왜 사용하는가?

- 입력 데이터로부터 예측값을 계산하기 위해
- Loss를 계산하기 위한 출력을 생성하기 위해
- Backpropagation에 필요한 중간 결과를 저장하기 위해

---

### 2. Computational Graph

Computational Graph는 모델의 모든 연산을 그래프 형태로 표현한 것이다.

각 노드는 연산(Operation)을 의미하고,

각 엣지는 데이터의 흐름을 의미한다.

예를 들어

```
Input
   │
Linear
   │
ReLU
   │
Loss
```

처럼 하나의 연산 과정이 그래프로 연결된다.

PyTorch는 이러한 그래프를 자동으로 생성하여 Gradient를 계산한다.

#### 왜 사용하는가?

- 연산 순서를 체계적으로 관리할 수 있다.
- Gradient를 자동으로 계산할 수 있다.
- 복잡한 신경망도 동일한 방식으로 학습할 수 있다.

---

### 3. Backpropagation

Backpropagation(역전파)은 Loss를 이용하여 각 Parameter의 Gradient를 계산하는 과정이다.

Gradient는 **Loss가 Weight에 얼마나 민감한지**를 나타내는 값이며,

이를 이용해 Weight를 업데이트한다.

계산은 출력층부터 입력층 방향으로 진행된다.

```
Loss
   │
Output Layer
   │
Hidden Layer
   │
Input Layer
```

#### 왜 사용하는가?

- Weight를 올바른 방향으로 업데이트하기 위해
- Loss를 최소화하는 방향을 찾기 위해
- 신경망 전체를 효율적으로 학습하기 위해

---

### 4. Chain Rule

Backpropagation은 미분의 **연쇄법칙(Chain Rule)** 을 이용하여 Gradient를 계산한다.

즉,

각 Layer의 Gradient를 순차적으로 연결하여 전체 Gradient를 계산한다.

$$
\frac{\partial L}{\partial w}
=
\frac{\partial L}{\partial y}
\cdot
\frac{\partial y}{\partial w}
$$

Layer가 여러 개 존재하는 경우에도 동일한 원리를 반복적으로 적용한다.

#### 왜 중요한가?

- 깊은 신경망에서도 Gradient를 효율적으로 계산할 수 있다.
- Backpropagation의 핵심 수학적 원리이다.

---

### 5. Training Neural Networks

신경망 학습은 다음 과정을 반복하는 것이다.

```
Forward Propagation
        │
Prediction
        │
Loss Calculation
        │
Backpropagation
        │
Gradient
        │
Optimizer
        │
Weight Update
        │
Repeat
```

Epoch가 반복될수록 Loss는 감소하고 모델의 성능은 향상된다.

#### 왜 중요한가?

- 모든 딥러닝 모델이 동일한 학습 과정을 사용한다.
- CNN, RNN, Transformer도 동일한 Training Pipeline을 따른다.

---

## 장점

- 복잡한 신경망에서도 Gradient를 효율적으로 계산할 수 있다.
- 자동 미분(Automatic Differentiation)을 통해 구현이 간단해진다.
- 모든 딥러닝 모델에 공통적으로 적용되는 학습 방식이다.
- 대규모 신경망도 안정적으로 학습할 수 있다.

---

## 한계

- 신경망이 깊어질수록 Gradient Vanishing 또는 Exploding 문제가 발생할 수 있다.
- Computational Graph를 저장해야 하므로 메모리 사용량이 증가한다.
- 매우 큰 모델에서는 계산 비용이 커질 수 있다.

---

## 핵심 흐름

```
Input
   │
Forward Propagation
   │
Prediction
   │
Loss
   │
Backpropagation
   │
Gradient
   │
Optimizer
   │
Updated Parameters
```

딥러닝 모델은 이 과정을 반복하면서 점차 더 좋은 가중치를 학습한다.

---

## 다음 절과의 연결

5.3에서는 Forward Propagation과 Backpropagation을 통해 신경망이 학습되는 원리를 이해하고, Computational Graph를 이용해 Gradient가 계산되는 과정을 학습하였다.

하지만 신경망의 깊이가 깊어질수록 Gradient가 너무 작아지거나 커지는 문제가 발생할 수 있다.

다음 절에서는 **Numerical Stability and Initialization**을 통해 **Gradient Vanishing**, **Gradient Exploding**, 그리고 적절한 **Parameter Initialization** 방법을 학습한다.
