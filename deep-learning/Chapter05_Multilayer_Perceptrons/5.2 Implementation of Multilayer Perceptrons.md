# 5.2 Implementation of Multilayer Perceptrons

> **핵심 키워드:** MLP · From Scratch · PyTorch · ReLU · Hidden Layer · High-level API

---

## 등장 배경

앞 절에서는 Multilayer Perceptron(MLP)의 구조와 Hidden Layer, Activation Function의 역할을 학습하였다.

하지만 MLP의 개념을 이해하는 것과 실제로 구현하는 것은 다른 문제이다. 따라서 이번 절에서는 **MLP를 처음부터 직접 구현(From Scratch)** 하여 내부 동작을 이해하고, 이후 **PyTorch의 High-level API**를 이용하여 동일한 모델을 더욱 간결하게 구현하는 방법을 학습한다.

이를 통해 딥러닝 프레임워크가 어떤 과정을 자동으로 처리하는지 이해할 수 있다.

---

## 핵심 아이디어

> **MLP는 기존 Softmax Regression에 Hidden Layer와 Activation Function을 추가한 구조이며, 학습 과정은 기존과 동일하다.**

전체 구조는 다음과 같다.

```
Input
   │
Linear Layer
   │
ReLU
   │
Hidden Layer
   │
Linear Layer
   │
Output
```

Forward Propagation을 통해 출력을 계산하고,

Loss를 계산한 뒤,

Backpropagation으로 Weight를 업데이트한다.

즉,

학습 과정은 이전 장과 동일하지만,

**모델 구조만 더 깊어진 것이다.**

---

## 주요 개념

### 1. Implementation from Scratch

MLP를 직접 구현하기 위해 다음 요소를 하나씩 정의한다.

- Weight와 Bias 초기화
- Hidden Layer
- ReLU Activation Function
- Output Layer
- Forward Propagation

Hidden Layer에서는 먼저 선형 변환을 수행한 뒤 ReLU를 적용한다.

```
Input
    │
Linear
    │
ReLU
    │
Hidden Layer
```

#### 왜 직접 구현하는가?

- MLP의 내부 동작을 이해하기 위해
- Forward Propagation 과정을 직접 확인하기 위해
- PyTorch API가 수행하는 역할을 이해하기 위해

---

### 2. ReLU 직접 구현

이번 절에서는 PyTorch의 `nn.ReLU()` 대신 ReLU 함수를 직접 구현한다.

```
ReLU(x)=max(0,x)
```

이를 통해 Activation Function이 실제로 어떻게 동작하는지 이해할 수 있다.

#### 왜 직접 구현하는가?

- Activation Function의 원리를 이해하기 위해
- Hidden Layer에서 비선형성이 어떻게 추가되는지 확인하기 위해

---

### 3. Hidden Layer

MLP에서는 Hidden Layer가 추가되면서 Parameter의 수도 증가한다.

기존 Softmax Regression은

```
Input
   │
Output
```

구조였지만,

MLP는

```
Input
   │
Hidden Layer
   │
Output
```

구조를 사용한다.

#### 왜 사용하는가?

- 더 복잡한 Feature를 학습하기 위해
- 비선형 관계를 표현하기 위해
- 모델의 표현력을 높이기 위해

---

### 4. Concise Implementation

PyTorch에서는 `nn.Sequential`과 `nn.Linear`를 이용하여 MLP를 매우 간단하게 구현할 수 있다.

직접 Weight를 생성하거나 Forward 함수를 모두 작성하지 않아도 된다.

#### 왜 사용하는가?

- 코드가 훨씬 간결하다.
- 구현 오류를 줄일 수 있다.
- 실제 프로젝트에서 가장 많이 사용하는 방식이다.

---

## From Scratch vs PyTorch

| From Scratch | PyTorch |
|--------------|----------|
| Weight 직접 생성 | `nn.Linear` 사용 |
| ReLU 직접 구현 | `nn.ReLU()` 사용 |
| Forward 직접 구현 | `nn.Sequential` 사용 |
| 교육 목적에 적합 | 실제 프로젝트에 적합 |

---

## 장점

- MLP의 내부 구조를 이해할 수 있다.
- Hidden Layer와 ReLU의 동작 과정을 직접 확인할 수 있다.
- PyTorch API가 내부적으로 수행하는 기능을 이해할 수 있다.
- 실제 프로젝트에서 사용하는 구현 방식과 연결할 수 있다.

---

## 한계

- 직접 구현은 코드가 길고 복잡하다.
- 구현 과정에서 오류가 발생하기 쉽다.
- 모델가 깊어질수록 직접 구현의 부담이 커진다.
- 실제 프로젝트에서는 대부분 High-level API를 사용한다.
