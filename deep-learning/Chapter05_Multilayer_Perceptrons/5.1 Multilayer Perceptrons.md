# 5.1 Multilayer Perceptrons

> **핵심 키워드:** Multilayer Perceptron (MLP) · Hidden Layer · Nonlinearity · Activation Function · ReLU · Sigmoid · Tanh

---

## 등장 배경

Chapter 3과 Chapter 4에서는 Linear Regression과 Softmax Regression을 이용하여 회귀와 분류 문제를 해결하였다.

하지만 이러한 모델은 모두 **선형 모델(Linear Model)** 이므로 입력과 출력 사이의 복잡한 비선형 관계를 학습하기 어렵다.

예를 들어,

- 이미지 분류
- 음성 인식
- 자연어 처리

와 같은 문제에서는 입력 데이터 사이의 관계가 매우 복잡하기 때문에 하나의 선형 변환만으로는 충분하지 않다.

이를 해결하기 위해 **Hidden Layer**와 **Activation Function**을 추가한 **Multilayer Perceptron(MLP)** 이 등장하였다.

---

## 핵심 아이디어

> **Hidden Layer와 Activation Function을 이용하여 선형 모델이 표현하지 못하는 비선형 관계를 학습한다.**

MLP의 기본 구조는 다음과 같다.

```
Input
   │
Linear
   │
Activation
   │
Hidden Layer
   │
Linear
   │
Output
```

Hidden Layer를 여러 개 쌓으면 더욱 복잡한 함수를 학습할 수 있으며, 이것이 Deep Neural Network의 기본 구조가 된다.

---

## 주요 개념

### 1. Linear Model의 한계

Linear Regression과 Softmax Regression은 모두 하나의 선형 변환만 수행한다.

즉,

$$
y=Wx+b
$$

형태의 함수만 표현할 수 있다.

하지만 실제 데이터는 대부분 비선형 관계를 가지므로 이러한 모델만으로는 충분하지 않다.

예를 들어,

- 고양이와 강아지 분류
- 사람 얼굴 인식
- 자율주행 객체 인식

등은 입력 Feature 사이의 복잡한 상호작용을 고려해야 하므로 선형 모델만으로는 해결하기 어렵다.

#### 왜 한계가 있는가?

- 비선형 관계를 표현할 수 없다.
- Feature 간 복잡한 상호작용을 학습하지 못한다.
- 표현력이 제한적이다.

---

### 2. Hidden Layer

Hidden Layer는 입력층(Input Layer)과 출력층(Output Layer) 사이에 존재하는 중간 계층이다.

Hidden Layer는 입력 데이터로부터 더 추상적인 특징(Feature Representation)을 학습한다.

즉,

```
Input
    │
Hidden Layer
    │
Output
```

구조를 통해 단순한 입력을 점점 더 의미 있는 특징으로 변환한다.

#### 왜 사용하는가?

- 데이터의 복잡한 패턴을 학습하기 위해
- Feature를 자동으로 추출하기 위해
- 모델의 표현력을 높이기 위해

> **하지만 Hidden Layer만 추가한다고 표현력이 증가하는 것은 아니다.**

Hidden Layer가 모두 **Linear Transformation**만 수행한다면,

여러 개를 쌓아도 결국 하나의 Linear Layer와 동일하다.

따라서 **Activation Function이 반드시 필요하다.**

---

### 3. Activation Function

Activation Function은 Hidden Layer에 **비선형성(Nonlinearity)** 을 추가하는 함수이다.

Activation Function이 존재해야 여러 개의 Layer를 쌓는 의미가 생긴다.

#### 왜 사용하는가?

- 비선형 함수를 학습하기 위해
- Deep Neural Network의 표현력을 높이기 위해
- 여러 Layer를 쌓아도 하나의 Linear Model로 합쳐지는 것을 방지하기 위해

Activation Function이 없다면

```
Linear
↓
Linear
↓
Linear
```

은

```
Linear
```

와 완전히 동일하다.

즉,

**딥러닝이 가능한 이유는 Activation Function이 비선형성을 추가하기 때문이다.**

---

### 4. ReLU (Rectified Linear Unit)

ReLU는 현재 가장 많이 사용되는 Activation Function이다.

$$
ReLU(x)=max(0,x)
$$

입력이 0보다 작으면 0을 출력하고,

0보다 크면 그대로 출력한다.

#### 장점

- 계산이 매우 빠르다.
- Gradient Vanishing 문제가 적다.
- 대부분의 딥러닝 모델에서 기본 Activation Function으로 사용된다.

#### 한계

- 음수 영역에서는 Gradient가 0이 된다.
- 일부 뉴런이 영구적으로 학습되지 않는 Dying ReLU 문제가 발생할 수 있다.

---

### 5. Sigmoid

Sigmoid는 출력을 0과 1 사이의 값으로 변환하는 Activation Function이다.

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

#### 장점

- 출력을 확률처럼 해석할 수 있다.
- Binary Classification의 출력층에서 자주 사용된다.

#### 한계

- 입력이 매우 크거나 작으면 Gradient가 거의 0이 된다.
- Gradient Vanishing 문제가 발생하기 쉽다.
- Hidden Layer에서는 현재 거의 사용되지 않는다.

---

### 6. Tanh

Tanh는 출력을 -1과 1 사이로 변환하는 Activation Function이다.

Sigmoid보다 평균이 0에 가까워 학습이 조금 더 안정적이다.

#### 장점

- 출력의 중심이 0이다.
- Sigmoid보다 Gradient 전달이 상대적으로 안정적이다.

#### 한계

- Sigmoid와 마찬가지로 Gradient Vanishing 문제가 발생한다.
- 현재 Hidden Layer에서는 대부분 ReLU가 사용된다.

---

## 장점

- 선형 모델보다 훨씬 높은 표현력을 가진다.
- 복잡한 비선형 함수를 학습할 수 있다.
- Feature를 자동으로 추출할 수 있다.
- 현대 딥러닝 모델(CNN, RNN, Transformer)의 기본 구조가 된다.

---

## 한계

- Hidden Layer가 많아질수록 학습이 어려워질 수 있다.
- Activation Function의 선택에 따라 성능 차이가 발생한다.
- Parameter 수가 증가하여 Overfitting이 발생할 수 있다.
- Gradient Vanishing, Exploding 등의 문제가 발생할 수 있다.

---

## Activation Function 비교

| Function | 출력 범위 | 장점 | 한계 |
|-----------|-----------|------|------|
| ReLU | [0, ∞) | 빠른 학습, Gradient Vanishing 감소 | Dying ReLU |
| Sigmoid | (0, 1) | 확률 표현 가능 | Gradient Vanishing |
| Tanh | (-1, 1) | 평균이 0 | Gradient Vanishing |
