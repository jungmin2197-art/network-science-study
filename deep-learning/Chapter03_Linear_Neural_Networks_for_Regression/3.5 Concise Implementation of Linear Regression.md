# 3.5 Concise Implementation of Linear Regression

> **핵심 키워드:** PyTorch · nn.Linear · nn.MSELoss · SGD · High-level API

---

## 등장 배경

앞 절에서는 Linear Regression을 처음부터 직접 구현(From Scratch)하면서 모델의 학습 과정과 내부 동작 원리를 이해하였다.

하지만 실제 딥러닝 프로젝트에서는 모든 모델을 직접 구현하지 않는다. 모델의 구조가 복잡해질수록 코드의 양이 증가하고, 구현 과정에서 오류가 발생할 가능성도 높아진다.

이를 해결하기 위해 PyTorch와 같은 딥러닝 프레임워크는 **High-level API**를 제공한다.

이번 절에서는 PyTorch에서 제공하는 API를 이용하여 동일한 Linear Regression 모델을 더욱 간결하게 구현하고, 직접 구현과의 차이를 이해하는 것이 목표이다.

---

## 핵심 아이디어

> **직접 구현을 통해 원리를 이해하고, 프레임워크를 이용하여 효율적으로 개발한다.**

PyTorch에서는 대부분의 기능을 이미 제공한다.

| 직접 구현 (3.4) | PyTorch 구현 (3.5) |
|:----------------|:-------------------|
| Model 직접 구현 | `nn.Linear` |
| MSE 직접 구현 | `nn.MSELoss()` |
| SGD 직접 구현 | `optim.SGD()` |
| Training Loop 구현 | 대부분 동일 |

즉, 모델의 학습 과정은 동일하지만 구현 방식이 훨씬 간결해진다.

---

## 주요 개념

### 1. nn.Linear

`nn.Linear`는 Fully Connected Layer를 구현하는 클래스이다.

Linear Regression의

$$
\hat{y}=Xw+b
$$

를 내부적으로 수행한다.

#### 왜 사용하는가?

- Weight와 Bias를 자동으로 생성한다.
- Forward 연산을 직접 작성할 필요가 없다.
- 다양한 Neural Network에서 그대로 사용할 수 있다.

---

### 2. nn.MSELoss()

PyTorch에서 제공하는 Mean Squared Error Loss이다.

예측값과 실제값의 차이를 자동으로 계산하여 Loss를 반환한다.

#### 왜 사용하는가?

- 직접 Loss Function을 구현할 필요가 없다.
- 검증된 구현을 사용할 수 있다.
- 코드의 가독성과 생산성이 향상된다.

---

### 3. optim.SGD()

SGD(Stochastic Gradient Descent)를 구현한 Optimizer이다.

Gradient를 이용하여 Weight와 Bias를 자동으로 업데이트한다.

#### 왜 사용하는가?

- Parameter Update를 자동으로 수행한다.
- 다양한 Optimizer와 쉽게 교체할 수 있다.
- 실제 프로젝트에서 가장 많이 사용하는 방식이다.

---

### 4. Training Process

PyTorch를 사용하더라도 학습 과정 자체는 변하지 않는다.

```
Forward
    ↓
Loss 계산
    ↓
Backward
    ↓
Optimizer Step
    ↓
Repeat
```

즉, **학습 원리는 동일하고 구현만 간단해진 것**이다.

---

## Scratch Implementation vs PyTorch

| From Scratch | PyTorch |
|:-------------|:---------|
| 내부 원리를 이해하기 쉽다. | 개발 속도가 빠르다. |
| 코드의 양이 많다. | 코드가 매우 간결하다. |
| 구현 실수가 발생할 수 있다. | 안정적인 라이브러리를 사용한다. |
| 교육 목적에 적합하다. | 실제 연구 및 산업 환경에 적합하다. |

---

## 장점

- 코드가 매우 간결해진다.
- 개발 속도가 빠르다.
- 검증된 라이브러리를 사용하므로 안정성이 높다.
- 다양한 모델을 쉽게 구현할 수 있다.
- 실제 연구 및 산업 현장에서 가장 많이 사용하는 방식이다.

---

## 한계

- 내부 동작을 이해하지 않고 사용할 위험이 있다.
- 추상화 수준이 높아 처음에는 내부 연산을 파악하기 어렵다.
- 디버깅이 필요한 경우 프레임워크의 구조를 이해해야 한다.

## 다음 절과의 연결

지금까지는 Linear Regression 모델을 구현하고 학습하는 방법을 학습하였다.

하지만 **Training Dataset에서 성능이 좋다고 해서 새로운 데이터에서도 좋은 성능을 보장하는 것은 아니다.**

다음 절에서는 **Generalization**을 통해 모델이 보지 못한 데이터에서도 얼마나 잘 동작하는지, 그리고 **Overfitting**과 **Underfitting**이 왜 발생하는지 학습한다.
