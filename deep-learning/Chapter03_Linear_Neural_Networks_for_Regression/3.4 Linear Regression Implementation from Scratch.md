# 3.4 Linear Regression Implementation from Scratch

> **핵심 키워드:** From Scratch · Forward Propagation · Loss Function · SGD · Training Loop

---

## 등장 배경

앞 절에서는 Synthetic Data를 생성하고 DataLoader를 이용하여 학습 데이터를 준비하였다.

이제 모델을 학습시킬 준비는 모두 끝났지만, 아직 PyTorch가 내부에서 어떻게 동작하는지는 알지 못한다.

대부분의 딥러닝 프레임워크는 `nn.Linear`, `optim.SGD`와 같은 API를 제공하지만, 이를 바로 사용하면 내부 동작 원리를 이해하기 어렵다.

따라서 이번 절에서는 **PyTorch의 고수준 API를 사용하지 않고 Linear Regression을 처음부터 직접 구현(From Scratch)** 하여 딥러닝 모델이 실제로 어떻게 학습되는지를 이해하는 것이 목표이다.

---

## 핵심 아이디어

> **딥러닝 프레임워크에 의존하지 않고, 모델의 학습 과정을 직접 구현하여 내부 동작 원리를 이해한다.**

Linear Regression의 학습 과정은 다음과 같은 순서로 이루어진다.

```
Parameter 초기화
        │
        ▼
Forward Propagation
        │
        ▼
Loss 계산
        │
        ▼
Gradient 계산
        │
        ▼
SGD를 이용한 Parameter Update
        │
        ▼
반복(Epoch)
```

이 과정은 Linear Regression뿐만 아니라 이후 배우게 될 CNN, RNN, Transformer에서도 동일하게 반복된다.

---

## 주요 개념

### 1. Defining the Model

모델은 입력 Feature와 Weight를 이용하여 예측값을 계산하는 함수이다.

Linear Regression에서는

$$
\hat{y}=Xw+b
$$

를 그대로 구현한다.

#### 왜 직접 구현하는가?

- Linear Layer가 실제로 수행하는 연산을 이해할 수 있다.
- Forward Propagation의 원리를 직접 확인할 수 있다.
- 이후 `nn.Linear`가 내부에서 어떤 역할을 하는지 이해하기 쉽다.

---

### 2. Defining the Loss Function

Loss Function은 모델의 예측값과 실제값의 차이를 계산하는 함수이다.

Linear Regression에서는 **Mean Squared Error(MSE)** 를 직접 구현한다.

#### 왜 직접 구현하는가?

- Loss가 단순한 숫자가 아니라 학습 방향을 결정하는 기준임을 이해할 수 있다.
- Loss가 작아질수록 모델의 성능이 향상된다는 것을 확인할 수 있다.

---

### 3. Defining the Optimization Algorithm

Optimization은 Loss를 최소화하도록 Weight와 Bias를 업데이트하는 과정이다.

Linear Regression에서는 **Stochastic Gradient Descent(SGD)** 를 직접 구현한다.

Parameter는 다음과 같이 업데이트된다.

$$
w=w-\eta\frac{\partial L}{\partial w}
$$

여기서

- **η(Learning Rate)** : 한 번에 이동하는 크기
- **∂L/∂w** : Loss를 가장 빠르게 증가시키는 방향

Gradient Descent는 이 반대 방향으로 이동하여 Loss를 감소시킨다.

#### 왜 직접 구현하는가?

- Weight가 어떻게 업데이트되는지 이해할 수 있다.
- Learning Rate가 모델 성능에 어떤 영향을 주는지 확인할 수 있다.
- Optimizer의 동작 원리를 이해할 수 있다.

---

### 4. Training

Training은 앞에서 정의한 모든 과정을 반복하는 단계이다.

하나의 Training 과정은

1. Forward Propagation
2. Loss 계산
3. Gradient 계산(Backpropagation)
4. Parameter Update

순으로 진행된다.

이 과정을 여러 Epoch 동안 반복하면서 모델은 점점 더 정확한 Weight를 학습하게 된다.

#### 왜 중요한가?

- 딥러닝 모델은 반복적인 학습을 통해 성능이 향상된다.
- 대부분의 Neural Network는 동일한 Training Pipeline을 사용한다.

---

## 장점

- 딥러닝 프레임워크 내부 동작을 이해할 수 있다.
- Forward, Loss, Optimizer의 관계를 명확하게 이해할 수 있다.
- 모델이 어떻게 학습되는지 전체 과정을 직접 확인할 수 있다.
- 이후 PyTorch API를 사용할 때 내부 원리를 이해하며 사용할 수 있다.

---

## 한계

- 직접 구현해야 하므로 코드의 양이 많아진다.
- 최적화와 예외 처리를 모두 개발자가 직접 수행해야 한다.
- 실제 프로젝트에서는 유지보수성과 생산성이 떨어진다.
- 복잡한 모델에서는 직접 구현하기 어렵다.

---

## 다음 절과의 연결

3.4에서는 Linear Regression을 처음부터 직접 구현하여 딥러닝 모델의 학습 과정을 이해하였다.

하지만 실제 연구나 산업에서는 모든 모델을 직접 구현하지 않는다.

다음 절에서는 **PyTorch에서 제공하는 `nn.Linear`, `nn.MSELoss`, `optim.SGD`** 를 이용하여 동일한 모델을 훨씬 간결하게 구현하고, 직접 구현과 프레임워크 구현의 차이를 비교한다.
