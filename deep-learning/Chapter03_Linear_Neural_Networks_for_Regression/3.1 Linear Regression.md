# 3.1 Linear Regression

## 등장 배경

머신러닝의 목표는 입력 데이터로부터 원하는 출력을 예측하는 모델을 학습하는 것이다. 이때 가장 기본적인 문제는 **연속적인 값을 예측하는 Regression 문제**이며, 대표적인 예로는 집값 예측, 주가 예측, 판매량 예측 등이 있다.

복잡한 신경망을 배우기 전에 가장 단순한 모델인 **Linear Regression**을 먼저 학습하는 이유는, 딥러닝의 핵심 요소인 **Model, Loss Function, Optimization, Training** 과정을 가장 직관적으로 이해할 수 있기 때문이다. 또한 Linear Regression은 이후 등장하는 대부분의 신경망의 기본 구조가 된다.

---

## 핵심 아이디어

Linear Regression은 입력(Feature)과 출력(Label) 사이에 **선형 관계(Linear Relationship)** 가 존재한다고 가정한다.

즉, 입력 Feature들의 가중합(Weighted Sum)으로 출력값을 예측한다.

\[
\hat{y}=w^Tx+b
\]

여기서 모델은 임의의 Weight와 Bias로 시작한 뒤, 예측값과 실제값의 차이를 최소화하도록 반복적으로 파라미터를 업데이트한다.

또한 데이터에는 항상 예측할 수 없는 오차(Noise)가 존재한다고 가정하며, 이러한 오차를 최소화하는 방향으로 모델을 학습한다.

---

## 주요 개념

### 1. Weight와 Bias

- **Weight(w)** : 각 Feature가 결과에 얼마나 영향을 미치는지를 나타내는 학습 파라미터이다.
- **Bias(b)** : 입력이 모두 0일 때의 기본 출력을 의미하며, 모델이 더욱 유연하게 데이터를 표현할 수 있도록 도와준다.

### 2. Vectorization

딥러닝에서는 데이터를 하나씩 반복문으로 계산하지 않고 벡터와 행렬 연산을 이용하여 한 번에 처리한다.

**왜 사용하는가?**

- Python 반복문보다 연산 속도가 훨씬 빠르다.
- GPU의 병렬 연산을 효율적으로 활용할 수 있다.
- 코드가 간결해지고 계산 과정에서 발생할 수 있는 오류를 줄일 수 있다.

### 3. MSE (Mean Squared Error)

Linear Regression에서는 예측값과 실제값의 차이를 계산하기 위해 **MSE Loss**를 사용한다.

**왜 사용하는가?**

- 큰 오차에 더 큰 패널티를 부여하여 정확한 학습을 유도한다.
- 미분이 가능하여 Gradient Descent를 이용한 최적화에 적합하다.
- Gaussian Distribution을 가정한 Maximum Likelihood Estimation(MLE)과 동일한 목적함수를 갖는다.

### 4. Gaussian Distribution

Linear Regression은 데이터의 오차(Noise)가 평균이 0인 **Gaussian Distribution(정규분포)** 을 따른다고 가정한다.

이 가정을 적용하면 Maximum Likelihood Estimation(MLE)의 목적함수가 자연스럽게 **MSE를 최소화하는 문제**와 동일해진다.

즉, MSE는 단순히 계산이 쉬워서 사용하는 것이 아니라 통계적인 근거를 가진 Loss Function이다.

### 5. Linear Regression as a Neural Network

Linear Regression은 입력층(Input Layer)과 출력층(Output Layer)만 존재하는 **가장 단순한 Fully Connected Neural Network**로 표현할 수 있다.

모든 입력 노드가 하나의 출력 노드와 연결되어 있으며 Activation Function이 존재하지 않기 때문에 선형 변환만 수행한다.

이 구조는 이후 배우게 될 **Dense Layer(Fully Connected Layer)** 의 기본 원리와 동일하다.

---

## 장점

- 구조가 단순하여 이해하기 쉽고 계산량이 적다.
- 딥러닝의 핵심 요소(Model, Loss, Optimization, Training)를 가장 직관적으로 학습할 수 있다.
- Weight의 의미를 해석할 수 있어 모델의 설명 가능성(Interpretability)이 높다.
- Fully Connected Layer의 기본 원리를 이해하는 데 도움이 된다.
- 복잡한 모델의 성능을 비교하기 위한 Baseline 모델로 널리 사용된다.

---

## 한계

- 입력과 출력의 선형 관계만 표현할 수 있어 복잡한 비선형 데이터를 학습하지 못한다.
- 이미지, 음성, 자연어와 같은 실제 딥러닝 문제에서는 표현력이 부족하다.
- 이상치(Outlier)에 민감하며, MSE는 큰 오차를 더욱 크게 반영한다.
- 여러 개의 Linear Layer를 단순히 쌓아도 결국 하나의 선형 변환과 동일하기 때문에 표현력이 증가하지 않는다.

## 다음 절과의 연결

3.1에서는 Linear Regression의 이론적 배경과 신경망으로의 해석을 학습하였다.

하지만 실제 딥러닝 모델은 단순히 수식을 정의하는 것만으로는 충분하지 않다. 모델(Model), 데이터(Data), 학습 과정(Training)을 체계적으로 관리할 수 있는 구조가 필요하다.

따라서 다음 절에서는 **Object-Oriented Design**을 통해 딥러닝 프로젝트를 효율적으로 구현하고 관리하는 방법을 학습한다.
