# 9.4 Recurrent Neural Networks

---

# 왜 RNN이 등장했는가?

기존 Feedforward Neural Network와 CNN은 입력들이 서로 독립적이라고 가정한다.

즉,

```
Input

↓

Output
```

만 계산하며,

이전 입력의 정보를 기억하지 못한다.

하지만 자연어, 음성, 시계열 데이터는 이전 정보가 현재 결과에 큰 영향을 준다.

예를 들어

```
I

love

deep

learning
```

이라는 문장에서

"learning"을 이해하기 위해서는

"I", "love", "deep"

모두 알아야 한다.

즉,

**이전 정보를 기억할 수 있는 신경망**이 필요하게 되었고,

이를 위해 Recurrent Neural Network(RNN)가 등장하였다.

---

# 기존 Neural Network의 한계

기존 Neural Network는

```
x1

↓

y1

x2

↓

y2
```

처럼

각 입력을 독립적으로 처리한다.

따라서

```
오늘

↓

비가

↓

온다
```

라는 문장에서

"오늘"이라는 정보를

"온다"를 예측할 때 사용할 수 없다.

---

# 핵심 아이디어

RNN의 핵심은 매우 단순하다.

> **이전 시점의 정보를 Hidden State에 저장하여 다음 시점에서도 사용하자.**

즉,

현재 입력뿐 아니라

이전까지의 정보를 함께 이용한다.

---

# Hidden State

Hidden State는

RNN이 과거 정보를 저장하는 메모리 역할을 한다.

각 Time Step에서는

- 현재 입력
- 이전 Hidden State

를 이용하여

새로운 Hidden State를 생성한다.

즉,

```
현재 입력

+

과거 정보

↓

Hidden State
```

가 만들어진다.

---

# RNN 구조

Feedforward Network는

```
Input

↓

Hidden

↓

Output
```

구조이다.

반면 RNN은

```
x(t)

↓

Hidden State

↓

Output

↑

h(t−1)
```

처럼

이전 Hidden State가

현재 Hidden State 계산에 사용된다.

---

# Time Step

RNN은 데이터를

한 번에 처리하지 않고

시간(Time) 순서대로 처리한다.

예를 들어

```
I

↓

love

↓

AI
```

는

```
t=1

↓

t=2

↓

t=3
```

순서대로 입력된다.

각 시점을

**Time Step**이라고 한다.

---

# Hidden State Update

각 Time Step에서

Hidden State는

다음과 같이 업데이트된다.

$$
h_t=\phi(W_{xh}x_t+W_{hh}h_{t-1}+b)
$$

여기서

- \(x_t\) : 현재 입력
- \(h_{t-1}\) : 이전 Hidden State
- \(h_t\) : 새로운 Hidden State
- \(\phi\) : 활성화 함수(Tanh)

를 의미한다.

즉,

현재 입력과 이전 기억을 이용하여

새로운 기억을 만든다.

---

# Output

Output은

현재 Hidden State를 이용하여 계산된다.

$$
y_t=W_{hy}h_t+b
$$

즉,

```
Hidden State

↓

Output
```

이 된다.

---

# RNN 전체 구조

```
x1

↓

h1

↓

y1

↓

x2

↓

h2

↓

y2

↓

x3

↓

h3

↓

y3
```

실제로는

```
x1 → h1 → h2 → h3

       ↑

      x2

       ↑

      x3
```

처럼

Hidden State가

시간축을 따라 계속 전달된다.

---

# Parameter Sharing

RNN의 가장 큰 특징 중 하나는

모든 Time Step에서

동일한 Weight를 사용한다는 것이다.

즉,

```
t=1

↓

W

t=2

↓

W

t=3

↓

W
```

모두 같은 Parameter를 공유한다.

이를

**Parameter Sharing**

이라고 한다.

덕분에

- Parameter 수 감소
- Sequence 길이와 무관하게 학습 가능

이라는 장점을 얻는다.

---

# Character-Level Language Model

RNN은

문자(Character) 단위로도 Language Model을 만들 수 있다.

예를 들어

```
H

↓

e

↓

l

↓

l

↓

o
```

를 순차적으로 입력하면

다음 문자를 예측할 수 있다.

즉,

```
Hell

↓

o
```

를 생성하는 모델을 만들 수 있다.

---

# 장점

- Sequence 데이터 처리 가능
- 이전 정보 기억 가능
- Language Model 구현 가능
- Parameter Sharing
- 다양한 길이의 입력 처리 가능

---

# 한계

기본 RNN은

긴 Sequence를 처리할 때

- Gradient Vanishing
- Gradient Exploding
- Long-term Dependency 문제

가 발생한다.

이러한 문제를 해결하기 위해

LSTM과 GRU가 등장하였다.

---

# 후속 연구에 미친 영향

RNN은 Sequence Modeling의 시작점이 된 모델이다.

이후

- LSTM
- GRU
- Seq2Seq
- Attention
- Transformer

모두 RNN의 한계를 해결하기 위해 발전하였다.

---

# 내가 이해한 내용

RNN은 이전 입력을 기억하기 위해 **Hidden State**를 사용하는 신경망이다.

기존 Neural Network는 입력을 독립적으로 처리하지만, RNN은 이전 Hidden State와 현재 입력을 함께 이용하여 새로운 Hidden State를 생성한다.

또한 모든 Time Step에서 동일한 Weight를 사용하는 **Parameter Sharing** 덕분에 다양한 길이의 Sequence를 효율적으로 처리할 수 있다.

하지만 Sequence가 길어질수록 Gradient Vanishing과 Long-term Dependency 문제가 발생하며, 이러한 한계를 해결하기 위해 이후 LSTM과 GRU가 등장하게 되었다.
