# 9.7 Backpropagation Through Time (BPTT)

---

# 왜 BPTT가 필요한가?

일반적인 Feedforward Neural Network는 Forward Propagation 이후 Backpropagation을 수행하여 Weight를 업데이트한다.

하지만 RNN은 Hidden State가 이전 시점과 연결되어 있기 때문에 일반적인 Backpropagation을 그대로 사용할 수 없다.

즉,

현재 출력은

- 현재 입력
- 이전 Hidden State
- 더 이전 Hidden State

모두의 영향을 받는다.

따라서 시간(Time) 방향까지 고려한 Backpropagation이 필요하며,

이를 **Backpropagation Through Time(BPTT)** 라고 한다.

---

# Feedforward Network와의 차이

일반 Neural Network는

```
Input

↓

Hidden

↓

Output
```

만 계산한다.

Gradient도

```
Output

↓

Hidden

↓

Input
```

으로 한 번만 전달된다.

반면 RNN은

```
x1

↓

h1

↓

x2

↓

h2

↓

x3

↓

h3

↓

Output
```

처럼

시간축(Time Step)을 따라 연결되어 있다.

즉,

Gradient 역시

시간을 거슬러 전달된다.

---

# Time Unrolling

RNN은 하나의 Cell을 반복 사용하는 구조이다.

이를 이해하기 쉽게 펼치면(Unrolling)

```
x1 → h1 → y1

↓

x2 → h2 → y2

↓

x3 → h3 → y3

↓

x4 → h4 → y4
```

처럼 보인다.

실제로는 하나의 RNN Cell이

시간축을 따라 반복 사용되는 것이다.

---

# BPTT

Forward 과정에서는

```
x1

↓

x2

↓

x3

↓

Output
```

순서로 계산한다.

Backward에서는

```
Output

↓

h3

↓

h2

↓

h1
```

순으로 Gradient가 전달된다.

즉,

시간을 거꾸로 따라가며

Gradient를 계산한다.

이것이

Backpropagation Through Time(BPTT)이다.

---

# Parameter Sharing

RNN은

모든 Time Step에서

같은 Weight를 사용한다.

```
t=1

↓

W

t=2

↓

W

t=3

↓

W
```

따라서

Gradient는

각 Time Step에서 계산된 값을 모두 더하여

Weight를 업데이트한다.

즉,

$$
\frac{\partial L}{\partial W}
=
\sum_t
\frac{\partial L_t}{\partial W}
$$

가 된다.

---

# Gradient Vanishing

BPTT에서는

Gradient가

Hidden State를 계속 거쳐 전달된다.

즉,

```
h5

↓

h4

↓

h3

↓

h2

↓

h1
```

을 반복한다.

Gradient는

매 단계마다 Weight와 Activation Function의 미분값을 계속 곱하게 된다.

예를 들어

```
0.5

×

0.5

×

0.5

×

0.5
```

처럼 계속 곱하면

```
0.0625
```

처럼 매우 작은 값이 된다.

이를

**Gradient Vanishing**이라고 한다.

---

# Long-term Dependency

Gradient가 너무 작아지면

초기 입력까지

정보가 전달되지 않는다.

예를 들어

```
The movie that I watched yesterday was

...

amazing
```

에서

"movie" 정보를

"amazing"까지 전달하기 어렵다.

즉,

멀리 떨어진 정보를 기억하지 못한다.

이를

**Long-term Dependency Problem**이라고 한다.

---

# Gradient Exploding

반대로

Gradient가

```
2

×

2

×

2

×

2
```

처럼 계속 커질 수도 있다.

그러면

Weight가

한 번에 크게 업데이트되어

학습이 불안정해진다.

이를

**Gradient Exploding**이라고 한다.

---

# Gradient Clipping

Gradient Exploding을 방지하기 위해

Gradient Clipping을 사용한다.

즉,

Gradient가 일정 Threshold보다 크면

크기만 줄인다.

Gradient의 방향은 유지하면서

크기만 제한한다.

현재 대부분의 RNN에서도 사용되는 기법이다.

---

# Truncated BPTT

Sequence가 매우 길면

모든 Time Step에 대해

BPTT를 수행하는 것은 계산량이 매우 크다.

따라서

일정 길이까지만

Backpropagation을 수행한다.

예를 들어

```
1000 Step

↓

20 Step만

Gradient 계산
```

하는 방식이다.

이를

**Truncated BPTT**라고 한다.

---

# 장점

- RNN 학습 가능
- Sequence 정보 학습
- Hidden State 업데이트 가능
- Language Model 학습 가능

---

# 한계

- Gradient Vanishing
- Gradient Exploding
- Long-term Dependency
- 긴 Sequence에서 계산량 증가

이러한 문제를 해결하기 위해

LSTM과 GRU가 등장하였다.

---

# 후속 연구에 미친 영향

BPTT는 RNN 계열 모델의 기본 학습 알고리즘이다.

이후

- LSTM
- GRU
- Seq2Seq

에서도 동일하게 사용된다.

하지만 긴 Sequence에서 발생하는 Gradient Vanishing 문제를 해결하기 위해

Attention과 Transformer는

순환 구조(Recurrent Structure)를 제거하는 새로운 접근을 제안하였다.

---

# 내가 이해한 내용

BPTT는 RNN을 학습하기 위한 Backpropagation 알고리즘으로, 일반적인 신경망과 달리 시간축(Time Step)을 따라 Gradient를 전달한다.

모든 Time Step이 동일한 Weight를 공유하기 때문에 각 시점에서 계산된 Gradient를 모두 합하여 Parameter를 업데이트한다.

하지만 Sequence가 길어질수록 Gradient Vanishing과 Long-term Dependency 문제가 발생하며, 이러한 한계가 LSTM과 GRU의 등장 배경이 되었다.
