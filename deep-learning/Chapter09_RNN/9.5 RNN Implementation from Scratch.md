# 9.5 Recurrent Neural Network Implementation from Scratch

---

# 왜 직접 구현할까?

앞 절에서는 RNN의 구조와 동작 원리를 살펴보았다.

하지만 실제로 RNN이 어떻게 동작하는지 이해하기 위해서는 라이브러리를 사용하기보다 직접 구현해 보는 것이 중요하다.

직접 구현을 통해

- Hidden State가 어떻게 업데이트되는지
- Sequence가 어떻게 처리되는지
- Language Model이 어떻게 학습되는지

를 이해할 수 있다.

---

# RNN 구현 과정

RNN을 구현하는 과정은 다음과 같다.

```text
Input Sequence

↓

Embedding (또는 One-hot Encoding)

↓

RNN Cell

↓

Hidden State Update

↓

Output

↓

Softmax

↓

Loss 계산
```

이 과정을 모든 Time Step에서 반복한다.

---

# RNN Cell

RNN Cell은 하나의 Time Step에서 수행되는 연산을 의미한다.

입력은

- 현재 입력 \(x_t\)
- 이전 Hidden State \(h_{t-1}\)

이다.

새로운 Hidden State는

$$
h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b)
$$

로 계산된다.

출력은

$$
y_t=W_{hy}h_t+b
$$

를 이용하여 계산된다.

---

# Language Model

RNN은 대부분 Language Model 학습에 사용된다.

예를 들어

```
I love deep learning
```

이라는 문장이 있다면

입력과 정답은 다음과 같이 구성된다.

| Input | Target |
|--------|---------|
| I | love |
| love | deep |
| deep | learning |

즉,

현재 단어를 입력하면

다음 단어를 예측하도록 학습한다.

---

# Loss Function

각 Time Step마다

예측한 단어와 실제 단어를 비교한다.

일반적으로

**Cross Entropy Loss**를 사용한다.

```
Prediction

↓

Softmax

↓

Cross Entropy Loss
```

전체 Loss는

모든 Time Step의 Loss를 합하여 계산한다.

---

# Training

학습 과정은 다음과 같다.

```text
Forward

↓

Loss 계산

↓

BPTT

↓

Gradient 계산

↓

Parameter Update
```

RNN은 일반적인 Backpropagation이 아니라

시간축으로 확장된 **Backpropagation Through Time(BPTT)** 를 사용한다.

---

# Gradient Clipping

RNN은 Sequence가 길어질수록

Gradient가 매우 커지는

**Gradient Exploding** 문제가 발생할 수 있다.

이를 해결하기 위해

Gradient Clipping을 사용한다.

---

# Gradient Exploding

예를 들어

Gradient가

```
0.8

↓

3.5

↓

28

↓

420

↓

5300
```

처럼 계속 커질 수 있다.

그러면

Weight가 한 번에 크게 업데이트되어

학습이 불안정해진다.

---

# Gradient Clipping의 원리

Gradient가 일정 크기 이상이면

강제로 줄여준다.

예를 들어

Threshold를

```
5
```

라고 하면

```
Gradient

=

20
```

인 경우

이를

```
5
```

정도로 줄여 사용한다.

수식으로는

$$
g
\leftarrow
\min\left(1,\frac{\theta}{\|g\|}\right)g
$$

로 표현된다.

여기서

- \(g\) : Gradient
- \(\theta\) : Clipping Threshold

이다.

즉,

Gradient의 방향은 유지하면서

크기만 줄인다.

---

# Gradient Clipping의 장점

- 학습 안정화
- Gradient Exploding 방지
- Weight Update 안정화
- 긴 Sequence 학습 가능

현재 대부분의 RNN, LSTM, GRU에서도 사용된다.

---

# Text Generation (Decoding)

학습이 끝나면

RNN은 새로운 문장을 생성할 수 있다.

예를 들어

```
Input

↓

I

↓

love

↓

deep

↓

learning
```

처럼

이전 출력이

다음 입력이 된다.

이를

**Autoregressive Generation**이라고 한다.

---

# 장점

- RNN의 동작 원리를 이해할 수 있다.
- Hidden State의 흐름을 확인할 수 있다.
- Language Model 구현 가능
- Gradient Clipping 적용 가능

---

# 한계

- 직접 구현이 복잡하다.
- 학습 속도가 느리다.
- 긴 Sequence에서는 Gradient Vanishing 문제가 여전히 존재한다.

실제 프로젝트에서는 대부분 PyTorch나 TensorFlow의 RNN Layer를 사용한다.

---

# 후속 연구에 미친 영향

RNN 구현 방식은 이후

- LSTM
- GRU
- Seq2Seq
- Attention

에서도 거의 동일하게 사용된다.

또한 Gradient Clipping은 현재 대부분의 Sequence Model에서 기본적으로 사용하는 학습 기법이다.

---

# 내가 이해한 내용

RNN 구현의 핵심은 **현재 입력과 이전 Hidden State를 이용하여 새로운 Hidden State를 계산하는 과정**이다.

학습은 BPTT를 이용하여 모든 Time Step의 Gradient를 계산하며, 이 과정에서 Gradient Exploding이 발생할 수 있기 때문에 Gradient Clipping을 적용하여 학습을 안정화한다.

즉, 9.5의 핵심은 **RNN의 구현보다 Hidden State의 업데이트 과정과 Gradient Clipping의 필요성을 이해하는 것**이라고 생각한다.
