# 9.1 Working with Sequences

---

# 왜 Sequence를 학습해야 하는가?

지금까지 다루었던 MLP와 CNN은 입력 데이터가 서로 독립(Independent)이라고 가정하였다.

예를 들어 이미지 분류에서는 한 장의 이미지가 다른 이미지에 영향을 주지 않는다.

하지만 현실에는 이전 데이터가 이후 데이터에 영향을 주는 **순차 데이터(Sequence Data)** 가 매우 많다.

대표적인 예시는 다음과 같다.

- 자연어 처리(NLP)
- 음성 인식
- 주가 예측
- 날씨 예측
- 센서 데이터
- 시계열(Time Series) 데이터

이러한 데이터는 **순서(Order)** 와 **시간(Time)** 정보가 매우 중요하다.

---

# Sequence Data란?

Sequence Data는 데이터의 순서가 의미를 가지는 데이터를 의미한다.

예를 들어

```
I

love

AI
```

와

```
AI

love

I
```

는 같은 단어를 사용하지만 의미가 완전히 다르다.

즉,

```
Input

↓

순서(Order)

↓

Output
```

이 결정된다.

---

# 기존 Neural Network의 한계

기존 Feedforward Neural Network는

```
Input

↓

Output
```

만 계산한다.

이전 입력을 기억하지 못한다.

예를 들어

```
오늘

↓

비가

↓

온다
```

라는 문장을 처리할 때

"오늘"이라는 정보를

"온다"를 예측할 때 사용할 수 없다.

즉,

순차 정보를 저장하지 못한다.

---

# 핵심 아이디어

Sequence Model의 핵심은

> **이전 정보를 이용하여 다음 정보를 예측하는 것이다.**

즉,

```
Past

↓

Present

↓

Future
```

의 관계를 학습한다.

이러한 아이디어가 이후 RNN으로 발전한다.

---

# Autoregressive Model

Autoregressive(AR) Model은

현재 값을 이전 값들의 함수로 표현하는 모델이다.

즉,

```
x(t)

↓

x(t+1)
```

을 예측하는 것이 아니라

```
x(t−3)

x(t−2)

x(t−1)

↓

x(t)
```

를 예측한다.

수식으로는

$$
x_t=f(x_{t-1},x_{t-2},...,x_{t-\tau})
$$

로 표현된다.

여기서

- \(x_t\) : 현재 값
- \(\tau\) : 사용하는 과거 데이터의 개수(Window Size)

를 의미한다.

---

# Sequence Model

Sequence Model은

입력 전체를 이용하여 다음 값을 예측한다.

예를 들어

```
오늘

날씨가

↓

좋다
```

라는 문장에서

앞의 단어들을 모두 이용하여

다음 단어를 예측한다.

즉,

입력의 순서를 고려하여 학습한다.

---

# Training

학습 과정에서는

입력 Sequence와 정답 Sequence를 함께 사용한다.

예를 들어

```
입력

I

love

↓

정답

love

AI
```

처럼

현재 입력으로 다음 데이터를 예측하도록 학습한다.

이를 **Teacher Forcing**의 기본 개념으로 볼 수 있다.

---

# Prediction

예측 단계에서는

정답을 사용할 수 없다.

따라서

모델이 예측한 결과를

다음 입력으로 다시 사용한다.

예를 들어

```
I

↓

love (예측)

↓

AI (예측)

↓

very (예측)
```

처럼

출력이 다음 입력이 된다.

이를 **Autoregressive Generation**이라고 한다.

---

# Sequence Prediction 과정

```text
Input Sequence

↓

Model

↓

Next Output

↓

다음 입력으로 사용

↓

다음 Output
```

이 과정을 반복하여 긴 Sequence를 생성한다.

---

# 장점

- 시간 정보를 학습할 수 있다.
- Sequence 데이터를 처리할 수 있다.
- 미래 값을 예측할 수 있다.
- 자연어 생성이 가능하다.
- 시계열 예측에 활용된다.

---

# 한계

- 긴 Sequence를 처리하기 어렵다.
- 이전 정보를 오래 기억하기 어렵다.
- Gradient Vanishing 문제가 발생한다.

이러한 문제를 해결하기 위해 이후 **Recurrent Neural Network(RNN)** 가 등장한다.

---

# 활용 분야

Sequence Model은 다양한 분야에서 사용된다.

- 자연어 처리(NLP)
- 기계 번역
- 음성 인식
- 문장 생성
- 시계열 예측
- 이상 탐지
- 주가 예측

---

# 내가 이해한 내용

Sequence Model은 일반적인 신경망과 달리 **데이터의 순서와 시간 정보를 함께 학습하는 모델**이다.

가장 중요한 아이디어는 **과거 정보를 이용하여 현재 또는 미래를 예측하는 것**이며, 이러한 개념이 발전하여 Hidden State를 사용하는 RNN이 등장하게 되었다.

또한 학습 과정에서는 실제 정답을 이용해 다음 값을 예측하고, 추론 과정에서는 이전에 예측한 결과를 다시 입력으로 사용하는 방식으로 Sequence를 생성한다.
