# 9.2 Converting Raw Text into Sequence Data

---

# 왜 Text Preprocessing이 필요한가?

컴퓨터는 사람처럼 문장을 그대로 이해하지 못한다.

예를 들어

```
I love deep learning.
```

이라는 문장은 사람은 쉽게 이해하지만,

컴퓨터는 문자열(String) 자체를 학습할 수 없다.

따라서 자연어를 숫자로 변환하는 전처리 과정(Text Preprocessing)이 필요하다.

---

# Text Preprocessing이란?

Text Preprocessing은

> **Raw Text를 Neural Network가 학습할 수 있는 Sequence 데이터로 변환하는 과정**이다.

대표적인 과정은 다음과 같다.

```
Raw Text

↓

Tokenization

↓

Vocabulary 생성

↓

Token을 Index로 변환

↓

Sequence Data
```

---

# Corpus

Corpus는 모델을 학습하기 위해 사용하는 **문장들의 집합**을 의미한다.

예를 들어

```
I love AI.

Deep learning is powerful.

Graph Neural Networks are interesting.
```

이 전체가 하나의 Corpus가 된다.

Language Model은 Corpus를 이용하여 다음 단어를 예측하도록 학습한다.

---

# Tokenization

Tokenization은 문장을 작은 단위(Token)로 나누는 과정이다.

예를 들어

```
I love AI.
```

를

```
["I", "love", "AI"]
```

처럼 단어 단위로 분리할 수 있다.

또는

```
["I"," ","l","o","v","e"]
```

처럼 문자(Character) 단위로 나눌 수도 있다.

---

# Token 종류

대표적인 Tokenization 방법은 다음과 같다.

### Word Token

```
I love AI

↓

["I","love","AI"]
```

가장 많이 사용하는 방법이다.

---

### Character Token

```
AI

↓

["A","I"]
```

문자 하나씩 분리한다.

Vocabulary가 작다는 장점이 있다.

---

### Subword Token

긴 단어를 더 작은 단위로 나눈다.

예를 들어

```
Playing

↓

Play

ing
```

최근 Transformer(BERT, GPT)에서 가장 많이 사용하는 방식이다.

---

# Vocabulary

Vocabulary는

> **Corpus에 존재하는 모든 Token의 집합**

이다.

예를 들어

Corpus가

```
I love AI

I study AI
```

라면

Vocabulary는

```
I

love

AI

study
```

이다.

중복은 제거된다.

---

# Token을 Index로 변환

Neural Network는 숫자만 입력받을 수 있다.

따라서

Vocabulary에 번호를 부여한다.

예를 들어

| Token | Index |
|--------|------:|
| I | 0 |
| love | 1 |
| AI | 2 |
| study | 3 |

그러면

```
I love AI
```

는

```
[0,1,2]
```

로 변환된다.

---

# Unknown Token (<unk>)

테스트 과정에서는 학습 중 보지 못한 단어가 등장할 수 있다.

예를 들어

Vocabulary에 없는

```
Transformer
```

라는 단어가 등장하면

```
<unk>
```

(Unknown Token)으로 변환한다.

이를 통해 새로운 단어가 등장해도 모델이 동작할 수 있다.

---

# Padding

문장의 길이는 모두 다르다.

예를 들어

```
I love AI
```

와

```
Deep learning is very powerful
```

는 길이가 다르다.

Batch 학습을 위해서는 길이를 맞춰야 한다.

따라서

```
I love AI

↓

I love AI <pad> <pad>
```

처럼 Padding Token을 추가한다.

---

# Sequence Data 생성

최종적으로

```
Raw Text

↓

Tokenization

↓

Vocabulary

↓

Index 변환

↓

Padding

↓

Sequence Data
```

과정을 거쳐

RNN이 입력받을 수 있는 데이터가 만들어진다.

---

# 장점

- 자연어를 숫자로 변환할 수 있다.
- 다양한 Language Model 학습 가능
- Batch 학습 가능
- RNN, LSTM, Transformer의 입력 생성

---

# 한계

- Word Token은 Vocabulary가 매우 커질 수 있다.
- Unknown Word 문제가 발생한다.
- Character Token은 Sequence가 너무 길어진다.

이러한 문제를 해결하기 위해 이후 **Subword Tokenization(BPE, WordPiece, SentencePiece)** 이 등장하였다.

---

# 후속 연구에 미친 영향

Text Preprocessing은 모든 자연어 처리 모델의 기본 과정이다.

현재

- RNN
- LSTM
- GRU
- BERT
- GPT
- T5

등 대부분의 NLP 모델이 Tokenization과 Vocabulary를 기반으로 학습된다.

최근에는 Word Token보다 **Subword Tokenization**이 표준으로 사용된다.

---

# 내가 이해한 내용

Text Preprocessing은 사람이 사용하는 문장을 컴퓨터가 이해할 수 있는 숫자 형태로 변환하는 과정이다.

가장 중요한 과정은 **Tokenization**, **Vocabulary 생성**, **Token을 Index로 변환하는 것**이며, 이를 통해 자연어는 Sequence Data가 되어 RNN과 같은 신경망의 입력으로 사용된다.

현재의 대규모 언어 모델 역시 이러한 전처리 과정을 거친 뒤 Embedding을 통해 의미를 학습한다.
