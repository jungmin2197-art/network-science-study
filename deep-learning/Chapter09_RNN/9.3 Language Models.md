# 9.3 Language Models

---

# 왜 Language Model이 필요한가?

사람은 문장을 읽을 때 다음 단어를 자연스럽게 예측할 수 있다.

예를 들어

```
I love

↓

deep learning
```

또는

```
The weather is

↓

beautiful
```

처럼 이전 단어를 이용하여 다음 단어를 예상한다.

Language Model은 이러한 능력을 컴퓨터가 학습하도록 만드는 모델이다.

즉,

> **이전 단어들을 이용하여 다음 단어가 등장할 확률을 예측하는 모델**이다.

---

# Language Model이란?

Language Model(LM)은

문장이 등장할 확률을 학습하는 모델이다.

즉,

```
P(sentence)
```

를 계산하는 것이 목표이다.

예를 들어

```
I love deep learning
```

이라는 문장은

```
P(I,love,deep,learning)
```

이라는 확률로 표현된다.

확률이 높을수록 자연스러운 문장이라고 판단한다.

---

# Chain Rule

문장의 확률은

Chain Rule을 이용하여 다음과 같이 분해할 수 있다.

$$
P(x_1,x_2,\cdots,x_T)
=
P(x_1)
P(x_2|x_1)
P(x_3|x_1,x_2)
\cdots
P(x_T|x_1,\cdots,x_{T-1})
$$

즉,

각 단어는 이전 단어들을 조건으로 하여 계산된다.

예를 들어

```
I

↓

love

↓

deep

↓

learning
```

처럼 이전 단어를 이용하여 다음 단어를 예측한다.

---

# N-gram Model

모든 이전 단어를 사용하는 것은 계산량이 너무 크다.

그래서 N-gram Model은

최근 N개의 단어만 사용한다.

---

## Unigram

현재 단어만 사용한다.

$$
P(x_t)
$$

단어 간 관계를 고려하지 않는다.

---

## Bigram

이전 단어 하나만 사용한다.

$$
P(x_t|x_{t-1})
$$

예를 들어

```
I

↓

love
```

---

## Trigram

이전 두 개의 단어를 사용한다.

$$
P(x_t|x_{t-2},x_{t-1})
$$

예를 들어

```
I

love

↓

deep
```

---

# N-gram의 한계

N-gram은

Window 크기가 고정되어 있다.

예를 들어

```
The food in this restaurant is very

↓

delicious
```

에서

"food"와 "delicious"의 관계는

멀리 떨어져 있기 때문에

Bigram으로는 학습할 수 없다.

즉,

긴 문맥(Long-term Dependency)을 학습하지 못한다.

이러한 문제를 해결하기 위해

RNN이 등장한다.

---

# Perplexity

Language Model의 성능은

Accuracy 대신

Perplexity(PPL)를 사용한다.

Perplexity는

> **모델이 다음 단어를 얼마나 잘 예측하는지 측정하는 지표**이다.

수식은

$$
\mathrm{PPL}
=
\exp\left(
-\frac1T
\sum_{t=1}^{T}
\log P(x_t)
\right)
$$

이다.

---

# Perplexity의 의미

Perplexity가 작을수록

다음 단어를 더 잘 예측한다.

예를 들어

```
Model A

PPL = 15
```

```
Model B

PPL = 8
```

이라면

Model B가 더 좋은 Language Model이다.

즉,

```
Perplexity ↓

↓

Language Model ↑
```

이다.

---

# Sequence Partitioning

Language Model을 학습하기 위해

긴 문장을 일정한 길이의 Sequence로 나눈다.

예를 들어

```
I love deep learning very much
```

를

```
I love deep

↓

love deep learning

↓

deep learning very

↓

learning very much
```

처럼

Sliding Window 방식으로 학습할 수 있다.

또는

랜덤하게 Sequence를 추출하여 학습할 수도 있다.

---

# Random Sampling

긴 문장에서

무작위 위치를 선택하여

Sequence를 생성한다.

장점

- 다양한 데이터 사용
- Overfitting 감소

단점

- Hidden State를 이어 사용할 수 없다.

---

# Sequential Partitioning

문장을 순서대로 잘라 학습한다.

장점

- Hidden State 유지 가능
- 실제 Sequence와 동일

단점

- 데이터 다양성이 감소한다.

---

# 장점

- 문장의 확률을 계산할 수 있다.
- 다음 단어를 예측할 수 있다.
- 문장 생성이 가능하다.
- 번역과 챗봇의 기반이 된다.

---

# 한계

N-gram 기반 Language Model은

- 긴 문맥을 기억하지 못한다.
- Vocabulary가 커질수록 희소성(Sparsity)이 발생한다.
- 계산량이 증가한다.

이러한 문제를 해결하기 위해

RNN이 등장하였다.

---

# 후속 연구에 미친 영향

Language Model은 현대 NLP의 핵심 기술이다.

이후

- RNN
- LSTM
- GRU
- Seq2Seq
- Attention
- Transformer
- GPT

모두 Language Modeling을 기반으로 발전하였다.

특히 GPT는

Autoregressive Language Model의 대표적인 예이다.

---

# 내가 이해한 내용

Language Model은 **이전 단어들을 이용하여 다음 단어를 예측하는 모델**이다.

초기의 N-gram 모델은 계산이 단순하지만 긴 문맥을 학습하지 못하는 한계가 있었다.

이러한 문제를 해결하기 위해 Hidden State를 이용하여 과거 정보를 지속적으로 기억하는 RNN이 등장하였으며, 이후 LSTM, GRU, Transformer와 같은 현대 언어 모델로 발전하게 되었다.
