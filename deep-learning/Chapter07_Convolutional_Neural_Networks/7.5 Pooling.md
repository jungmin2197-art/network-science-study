# 7.5 Pooling

> **핵심 키워드:** Pooling · Max Pooling · Average Pooling · Downsampling · Translation Invariance

---

## 등장 배경

앞 절에서는 Convolution Layer를 이용하여 다양한 Feature Map을 생성하는 방법을 학습하였다.

하지만 CNN이 깊어질수록 Feature Map의 크기가 커지고 계산량도 함께 증가한다. 또한 Feature Map에는 중요한 특징뿐 아니라 불필요한 정보나 작은 노이즈도 함께 포함될 수 있다.

이를 해결하기 위해 **Pooling**을 사용한다.

Pooling은 Feature Map의 크기를 줄이면서도 중요한 특징을 유지하여 계산량을 감소시키고, 모델의 일반화 성능을 향상시키는 역할을 한다.

---

## 핵심 아이디어

> **Pooling은 Feature Map을 Downsampling하여 계산량을 줄이고, 중요한 특징만 유지하는 연산이다.**

전체 과정은 다음과 같다.

```
Input Feature Map
        │
        ▼
Pooling
        │
        ▼
Smaller Feature Map
```

Pooling은 새로운 Feature를 생성하는 것이 아니라,

이미 추출된 Feature를 압축하여 전달하는 과정이다.

---

## 주요 개념

### 1. Pooling

Pooling은 일정한 영역(Window)에서 하나의 대표값만 선택하여 Feature Map의 크기를 줄이는 연산이다.

예를 들어

```
2×2 Window

1 3
5 2
```

이라면

하나의 값만 선택하여 출력한다.

#### 왜 사용하는가?

- 계산량을 줄이기 위해
- 중요한 특징만 유지하기 위해
- Overfitting을 줄이기 위해
- Feature Map 크기를 감소시키기 위해

---

### 2. Max Pooling

Max Pooling은 Pooling 영역에서 가장 큰 값을 선택하는 방법이다.

예를 들어

```
2 5
1 3
```

이라면

```
Output

5
```

가 된다.

즉,

가장 강한 Feature만 다음 Layer로 전달한다.

#### 왜 사용하는가?

- 가장 중요한 특징을 유지하기 위해
- Edge나 Texture와 같은 강한 Feature를 강조하기 위해
- 실제 CNN에서 가장 많이 사용하는 Pooling 방식이다.

---

### 3. Average Pooling

Average Pooling은 Pooling 영역의 평균값을 출력하는 방법이다.

예를 들어

```
2 6
4 8
```

이라면

```
Output

5
```

가 된다.

#### 왜 사용하는가?

- 전체적인 정보를 유지하기 위해
- Feature를 부드럽게(Smoothing) 만들기 위해

현재는 Hidden Layer보다

**마지막 Layer(Global Average Pooling)** 에서 자주 사용된다.

---

### 4. Padding and Stride in Pooling

Pooling도 Convolution과 마찬가지로

- Padding
- Stride

를 사용할 수 있다.

일반적으로

- Pooling Size = 2×2
- Stride = 2

를 가장 많이 사용한다.

이 경우

Feature Map의 크기가 절반으로 감소한다.

#### 왜 사용하는가?

- 일정한 비율로 Feature Map을 축소하기 위해
- 계산량을 효과적으로 감소시키기 위해

---

### 5. Multiple Channels

Pooling은 각 Channel을 **독립적으로 처리**한다.

예를 들어

```
64 Feature Maps

↓

Max Pooling

↓

64 Smaller Feature Maps
```

이 된다.

즉,

Pooling은

- Channel 수는 유지하고
- Feature Map의 크기만 감소시킨다.

#### 왜 중요한가?

- 다양한 Feature를 그대로 유지할 수 있다.
- 공간 크기만 줄여 계산량을 감소시킬 수 있다.

---

## 장점

- Feature Map의 크기를 줄여 계산량을 감소시킨다.
- Overfitting을 완화할 수 있다.
- 중요한 Feature를 유지할 수 있다.
- 작은 위치 변화에 더욱 강인한 모델을 만들 수 있다.
- CNN의 학습 속도를 향상시킬 수 있다.

---

## 한계

- 일부 세부 정보가 손실될 수 있다.
- Pooling 크기가 너무 크면 중요한 특징까지 제거될 수 있다.
- 최근 일부 최신 모델에서는 Pooling 대신 Strided Convolution을 사용하는 경우도 있다.

---

## Max Pooling vs Average Pooling

| Max Pooling | Average Pooling |
|--------------|-----------------|
| 가장 큰 값을 선택 | 평균값을 선택 |
| 중요한 특징 강조 | 전체적인 정보 유지 |
| 가장 많이 사용 | 마지막 Layer에서 자주 사용 |
| Edge, Texture 표현에 유리 | Global Feature 표현에 유리 |

---

## Convolution vs Pooling

| Convolution | Pooling |
|--------------|----------|
| 새로운 Feature 추출 | Feature 압축 |
| 학습 가능한 Parameter 존재 | 학습 Parameter 없음 |
| Kernel 사용 | Max 또는 Average 사용 |
| Feature Map 생성 | Feature Map 축소 |
