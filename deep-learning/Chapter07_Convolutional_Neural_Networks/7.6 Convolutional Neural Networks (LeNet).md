# 7.6 Convolutional Neural Networks (LeNet)

> **핵심 키워드:** LeNet · CNN Architecture · Feature Extraction · Classification · End-to-End Learning

---

## 등장 배경

앞 절에서는 CNN을 구성하는 핵심 요소인 Convolution, Padding, Stride, Multiple Channels, Pooling을 각각 학습하였다.

하지만 실제 이미지 분류 문제에서는 이러한 요소들이 하나의 모델 안에서 함께 동작한다.

LeNet은 **Yann LeCun**이 손글씨 숫자 인식(MNIST)을 위해 제안한 최초의 성공적인 Convolutional Neural Network(CNN)로, 이후 등장한 AlexNet, VGG, ResNet 등 대부분의 CNN 구조의 기반이 되었다.

이번 절에서는 LeNet의 구조를 살펴보며 지금까지 학습한 CNN의 핵심 구성 요소들이 실제 모델에서 어떻게 사용되는지 이해한다.

---

## 핵심 아이디어

> **Convolution Layer와 Pooling Layer를 반복하여 특징을 추출하고, 마지막 Fully Connected Layer를 이용해 이미지를 분류한다.**

LeNet의 전체 구조는 다음과 같다.

```
Input Image
      │
      ▼
Convolution
      │
      ▼
Pooling
      │
      ▼
Convolution
      │
      ▼
Pooling
      │
      ▼
Fully Connected Layer
      │
      ▼
Output
```

초기 Layer에서는 Edge와 Texture 같은 단순한 특징을 학습하고,

깊은 Layer에서는 객체의 형태와 같은 고수준 특징을 학습한다.

---

## 주요 개념

### 1. LeNet Architecture

LeNet은 여러 개의 Convolution Layer와 Pooling Layer를 순차적으로 연결한 구조이다.

초기 Layer에서는 이미지의 기본적인 특징을 추출하고,

마지막 Fully Connected Layer에서는 추출된 특징을 이용하여 최종 클래스를 예측한다.

#### 왜 사용하는가?

- 이미지의 공간 정보를 유지할 수 있다.
- 특징 추출과 분류를 하나의 모델에서 수행할 수 있다.
- CNN의 기본 구조를 이해할 수 있다.

---

### 2. Feature Extraction

LeNet에서 Convolution Layer의 가장 중요한 역할은 Feature Extraction이다.

Layer가 깊어질수록

```
Edge

↓

Corner

↓

Texture

↓

Object Parts

↓

Object
```

처럼 점점 더 추상적인 특징을 학습한다.

#### 왜 중요한가?

- 사람이 직접 Feature를 설계할 필요가 없다.
- 데이터로부터 중요한 특징을 자동으로 학습한다.
- CNN의 가장 큰 장점이다.

---

### 3. Pooling

Pooling Layer는 Feature Map의 크기를 줄여 계산량을 감소시키고,

중요한 Feature만 다음 Layer로 전달한다.

#### 왜 사용하는가?

- 계산량 감소
- Overfitting 완화
- 위치 변화에 더욱 강인한 특징 학습

---

### 4. Fully Connected Layer

Convolution과 Pooling을 거쳐 추출된 Feature를 이용하여 최종 분류를 수행한다.

즉,

```
Feature Maps

↓

Flatten

↓

Fully Connected

↓

Prediction
```

과정을 통해 최종 클래스를 예측한다.

#### 왜 사용하는가?

- 추출된 특징을 종합하여 최종 결정을 내리기 위해
- Classification을 수행하기 위해

---

### 5. Training

LeNet의 학습 과정은 이전 장에서 학습한 MLP와 동일하다.

```
Input
   │
Forward Propagation
   │
Loss
   │
Backpropagation
   │
Optimizer
   │
Parameter Update
```

즉,

모델의 구조는 CNN으로 바뀌었지만,

학습 방법은 동일하다.

#### 왜 중요한가?

- CNN도 결국 하나의 Neural Network이다.
- 모든 딥러닝 모델은 동일한 학습 과정을 따른다.

---

## 장점

- 이미지의 공간 정보를 유지하며 특징을 추출할 수 있다.
- MLP보다 훨씬 적은 Parameter를 사용한다.
- Feature를 자동으로 학습할 수 있다.
- 현대 CNN 구조의 기반이 되었다.
- End-to-End Learning이 가능하다.

---

## 한계

- 구조가 비교적 단순하여 복잡한 이미지에는 성능이 제한적이다.
- 매우 깊은 CNN에 비해 표현력이 낮다.
- 작은 이미지(MNIST)를 대상으로 설계되었다.
- 현대 모델에서는 AlexNet, VGG, ResNet 등이 주로 사용된다.

---

## MLP vs LeNet

| MLP | LeNet |
|------|--------|
| Fully Connected 중심 | Convolution 중심 |
| 이미지를 1차원으로 변환 | 공간 정보를 유지 |
| Parameter 수가 많음 | Parameter 수가 적음 |
| Feature를 직접 학습하기 어려움 | Feature를 자동으로 추출 |
| 이미지 처리에 비효율적 | 이미지 처리에 최적화 |

---

## LeNet 구조 요약

```
Input
   │
Convolution
   │
Pooling
   │
Convolution
   │
Pooling
   │
Flatten
   │
Fully Connected
   │
Output
```

LeNet은 Convolution과 Pooling을 반복하여 Feature를 추출하고,

마지막 Fully Connected Layer에서 분류를 수행하는 가장 기본적인 CNN 구조이다.
