# 7.4 Multiple Input and Multiple Output Channels

> **핵심 키워드:** Input Channel · Output Channel · Feature Map · Convolution Layer · Multi-channel Convolution

---

## 등장 배경

앞 절에서는 Convolution 연산과 Padding, Stride를 이용하여 이미지의 특징을 추출하고 출력 Feature Map의 크기를 조절하는 방법을 학습하였다.

하지만 지금까지는 입력 이미지가 하나의 Channel만 가진다고 가정하였다.

실제 이미지 데이터는 대부분 **RGB(Red, Green, Blue)** 로 구성되어 있으며, 하나의 이미지가 여러 개의 Channel을 가진다. 또한 하나의 특징만 추출하는 것으로는 충분하지 않기 때문에 CNN은 여러 개의 Filter를 사용하여 다양한 Feature Map을 생성한다.

이번 절에서는 **여러 개의 입력 Channel과 여러 개의 출력 Channel을 처리하는 방법**을 학습한다.

---

## 핵심 아이디어

> **CNN은 여러 입력 Channel을 동시에 처리하고, 여러 개의 Filter를 이용하여 다양한 Feature를 추출한다.**

전체 과정은 다음과 같다.

```
Input Image
(RGB)

R
G
B
 │
 ▼
Convolution Filter
 │
 ▼
Feature Map

↓

여러 개의 Filter

↓

Multiple Feature Maps
```

즉,

입력 Channel이 많아질수록 하나의 Filter도 여러 Channel을 동시에 계산하며,

Filter의 개수가 많아질수록 출력 Feature Map도 많아진다.

---

## 주요 개념

### 1. Multiple Input Channels

실제 이미지는 하나 이상의 Channel을 가진다.

예를 들어

- Grayscale Image → 1 Channel
- RGB Image → 3 Channels
- 의료 영상이나 위성 영상 → 그 이상의 Channel

하나의 Convolution Filter는 입력의 모든 Channel을 동시에 처리한다.

예를 들어 RGB 이미지라면

```
R Channel

G Channel

B Channel

↓

3개의 Kernel

↓

Element-wise Sum

↓

Output Feature Map
```

으로 계산된다.

즉,

각 Channel에서 얻은 결과를 모두 더하여 하나의 Feature Map을 만든다.

#### 왜 사용하는가?

- 색상 정보를 모두 활용하기 위해
- 각 Channel의 특징을 함께 학습하기 위해
- 이미지의 다양한 정보를 동시에 반영하기 위해

---

### 2. Multiple Output Channels

하나의 Filter는 하나의 Feature Map만 생성한다.

하지만 하나의 특징만으로는 이미지를 충분히 표현할 수 없기 때문에 CNN은 여러 개의 Filter를 동시에 사용한다.

예를 들어

```
Filter 1

↓

Edge Feature

----------------

Filter 2

↓

Texture Feature

----------------

Filter 3

↓

Shape Feature
```

처럼 서로 다른 특징을 추출한다.

따라서

```
Output Channel 수

=

Filter 개수
```

가 된다.

#### 왜 사용하는가?

- 다양한 특징을 동시에 학습하기 위해
- 모델의 표현력을 높이기 위해
- 더 복잡한 이미지를 이해하기 위해

---

### 3. Convolutional Layer

Convolution Layer는

- 여러 개의 입력 Channel
- 여러 개의 Filter

를 이용하여 여러 개의 Output Channel을 생성한다.

예를 들어

```
Input

3 Channels

↓

64 Filters

↓

Output

64 Feature Maps
```

이 된다.

즉,

입력 Channel 수와 출력 Channel 수는 서로 다를 수 있으며,

출력 Channel의 개수는 설계자가 자유롭게 결정한다.

#### 왜 중요한가?

- Layer가 깊어질수록 더 다양한 특징을 학습할 수 있다.
- CNN의 표현력을 크게 향상시킨다.
- 대부분의 CNN 모델이 이 구조를 사용한다.

---

### 4. Feature Extraction

CNN에서는 Layer가 깊어질수록 더욱 복잡한 특징을 추출한다.

예를 들어

```
초기 Layer

↓

Edge

↓

중간 Layer

↓

Texture

↓

고수준 Layer

↓

Object Parts

↓

마지막 Layer

↓

Object
```

즉,

Output Channel이 많아질수록 더 다양한 특징을 동시에 표현할 수 있다.

---

## 장점

- RGB와 같은 다채널 이미지를 효과적으로 처리할 수 있다.
- 여러 Filter를 통해 다양한 특징을 동시에 추출할 수 있다.
- Layer가 깊어질수록 더욱 풍부한 Feature Representation을 얻을 수 있다.
- 현대 CNN(ResNet, VGG, YOLO 등)의 기본 구조를 이해할 수 있다.

---

## 한계

- Output Channel이 많아질수록 계산량이 증가한다.
- Parameter 수도 함께 증가한다.
- 너무 많은 Channel은 메모리 사용량을 증가시킬 수 있다.

---

## Input Channel vs Output Channel

| Input Channel | Output Channel |
|---------------|----------------|
| 입력 데이터의 Channel 수 | Filter의 개수 |
| RGB는 3 Channels | Filter가 64개면 Output도 64개 |
| 모든 Channel을 함께 계산 | 각각 하나의 Feature Map 생성 |
