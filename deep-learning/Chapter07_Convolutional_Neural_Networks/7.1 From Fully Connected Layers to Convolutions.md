# 7.1 From Fully Connected Layers to Convolutions

> **핵심 키워드:** Fully Connected Layer · Convolution · Invariance · Locality · Weight Sharing · Channel

---

## 등장 배경

앞 장에서는 **Multilayer Perceptron(MLP)** 을 이용하여 복잡한 비선형 문제를 해결하는 방법을 학습하였다.

하지만 이미지 데이터를 처리할 때 MLP는 여러 가지 한계를 가진다.

예를 들어 224×224 크기의 RGB 이미지를 입력으로 사용하면 하나의 이미지는 약 15만 개 이상의 입력값을 가지게 된다. 이를 Fully Connected Layer에 그대로 연결하면 엄청난 수의 Parameter가 필요하며, 학습 속도가 느려지고 Overfitting이 발생하기 쉽다.

또한 이미지를 1차원 벡터로 펼치는 과정에서 **픽셀 간의 위치 정보(Spatial Information)** 가 사라진다. 실제 이미지에서는 가까운 픽셀끼리 의미 있는 특징을 이루지만, MLP는 이러한 공간적인 관계를 고려하지 못한다.

이러한 문제를 해결하기 위해 등장한 모델이 **Convolutional Neural Network(CNN)** 이며, CNN은 이미지의 공간적 특징을 효율적으로 학습하기 위해 **Convolution 연산**을 사용한다.

---

## 핵심 아이디어

> **이미지의 공간적 구조를 유지하면서 필요한 특징만 추출하기 위해 Convolution을 사용한다.**

CNN의 기본 아이디어는 다음과 같다.

```
Image
    │
Local Region
    │
Convolution
    │
Feature Map
    │
Classifier
```

즉,

이미지 전체를 한 번에 연결하는 것이 아니라,

**작은 영역(Local Region)** 을 조금씩 살펴보면서 특징을 추출한다.

---

## 주요 개념

### 1. Invariance

이미지는 객체의 위치가 조금 변해도 같은 객체로 인식할 수 있어야 한다.

예를 들어 고양이가

- 왼쪽에 있든
- 가운데 있든
- 오른쪽에 있든

모두 **고양이**로 인식해야 한다.

이를 **Translation Invariance(평행 이동 불변성)** 이라고 한다.

#### 왜 중요한가?

- 객체 위치에 관계없이 동일한 특징을 추출하기 위해
- 실제 이미지 환경에 더욱 강인한 모델을 만들기 위해

---

### 2. Constraining the MLP

MLP는 모든 입력과 모든 뉴런을 연결한다.

```
Input
██████████

↓

Fully Connected

↓

Output
```

이러한 구조는

- Parameter가 매우 많고
- 공간 정보를 활용하지 못하며
- 이미지 처리에 비효율적이다.

CNN에서는 이러한 문제를 해결하기 위해 두 가지 제약을 적용한다.

- **Local Connectivity(국소 연결)**
- **Weight Sharing(가중치 공유)**

#### 왜 사용하는가?

- Parameter 수를 크게 줄이기 위해
- 이미지의 공간 정보를 유지하기 위해
- 같은 특징을 여러 위치에서 탐지하기 위해

---

### 3. Convolution

Convolution은 작은 **Kernel(Filter)** 을 이용하여 이미지를 순차적으로 탐색하면서 특징을 추출하는 연산이다.

```
Image

□□□□□
□□■□□
□□□□□

↓

Kernel

■■
■■

↓

Feature Map
```

Kernel은 이미지를 조금씩 이동하며

- Edge
- Corner
- Texture

등 다양한 특징을 추출한다.

#### 왜 사용하는가?

- 이미지의 중요한 특징만 추출하기 위해
- Parameter를 크게 줄이기 위해
- 공간 정보를 유지하기 위해

---

### 4. Channels

이미지는 하나 이상의 Channel을 가진다.

예를 들어

- 흑백 이미지 → 1 Channel
- RGB 이미지 → 3 Channels

CNN에서는 각 Channel을 함께 사용하여 Feature를 추출한다.

또한 Layer가 깊어질수록

```
Input Channel

↓

Convolution

↓

Feature Channels
```

처럼 다양한 Feature Map이 생성된다.

#### 왜 사용하는가?

- 다양한 특징을 동시에 학습하기 위해
- 색상, 질감, 모양 등을 함께 표현하기 위해
- 더 풍부한 Feature Representation을 만들기 위해

---

## 장점

- Parameter 수를 크게 줄일 수 있다.
- 이미지의 공간 정보를 유지할 수 있다.
- Translation Invariance를 어느 정도 만족할 수 있다.
- 같은 Filter를 공유하여 효율적으로 특징을 추출할 수 있다.
- 대부분의 이미지 처리 모델의 기반이 된다.

---

## 한계

- 이미지 이외의 데이터에서는 효과가 제한적일 수 있다.
- Kernel 크기와 Channel 수를 적절하게 설정해야 한다.
- 매우 복잡한 특징은 여러 Convolution Layer를 쌓아야 학습할 수 있다.

---

## MLP vs CNN

| MLP | CNN |
|------|-----|
| Fully Connected | Local Connectivity |
| Parameter 수가 많음 | Parameter 수가 적음 |
| 위치 정보 손실 | 공간 정보 유지 |
| 이미지 처리에 비효율적 | 이미지 처리에 최적화 |
| Weight Sharing 없음 | Weight Sharing 사용 |
