# 7.3 Padding and Stride

> **핵심 키워드:** Padding · Stride · Output Size · Zero Padding · Feature Map

---

## 등장 배경

앞 절에서는 Convolution 연산을 통해 이미지의 특징을 추출하는 방법을 학습하였다.

하지만 Convolution을 반복적으로 수행하면 Feature Map의 크기가 계속 감소하게 된다. Feature Map이 너무 작아지면 이미지의 중요한 정보가 손실될 수 있으며, 깊은 CNN을 구성하기도 어려워진다.

또한 Kernel이 이미지를 이동하는 간격에 따라 계산량과 출력 Feature Map의 크기가 달라진다.

이를 해결하기 위해 **Padding**과 **Stride**를 사용한다.

---

## 핵심 아이디어

> **Padding은 출력 크기를 유지하기 위해 사용하고, Stride는 Kernel의 이동 간격을 조절하여 출력 크기와 계산량을 조절한다.**

전체 과정은 다음과 같다.

```
Input Image
      │
      ▼
Padding
      │
      ▼
Convolution
      │
      ▼
Stride
      │
      ▼
Feature Map
```

즉,

Padding과 Stride는 **Convolution 자체를 바꾸는 것이 아니라 출력 Feature Map의 크기를 조절하는 역할**을 한다.

---

## 주요 개념

### 1. Padding

Padding은 입력 이미지의 가장자리에 일정한 값을 추가하는 기법이다.

일반적으로 **0(Zero Padding)** 을 사용한다.

예를 들어

```
Original

1 2 3
4 5 6
7 8 9
```

Padding = 1

```
0 0 0 0 0
0 1 2 3 0
0 4 5 6 0
0 7 8 9 0
0 0 0 0 0
```

처럼 가장자리를 둘러싸게 된다.

#### 왜 사용하는가?

- Feature Map의 크기를 유지하기 위해
- 가장자리 정보 손실을 줄이기 위해
- 깊은 CNN에서도 충분한 공간 정보를 유지하기 위해

---

### 2. Padding의 효과

Padding을 사용하지 않으면

```
Input

5 × 5

↓

3 × 3 Kernel

↓

Output

3 × 3
```

으로 출력 크기가 감소한다.

하지만 Padding을 적용하면

```
Input

5 × 5

↓

Padding

↓

7 × 7

↓

Convolution

↓

5 × 5
```

처럼 입력과 비슷한 크기의 Feature Map을 얻을 수 있다.

---

### 3. Stride

Stride는 Kernel이 한 번 이동하는 거리(간격)를 의미한다.

예를 들어

Stride = 1

```
■■□
□■■
```

처럼 한 칸씩 이동한다.

Stride = 2

```
■■□□
□□■■
```

처럼 두 칸씩 이동한다.

#### 왜 사용하는가?

- Feature Map의 크기를 줄이기 위해
- 계산량을 감소시키기 위해
- 중요한 특징만 효율적으로 추출하기 위해

---

### 4. Stride의 효과

Stride가 커질수록

- 출력 Feature Map은 작아지고
- 계산량도 감소한다.

예를 들어

| Stride | Output Size |
|---------|-------------|
| 1 | 큼 |
| 2 | 작음 |
| 3 | 더욱 작음 |

하지만 Stride가 너무 크면

중간 정보가 많이 생략되어 중요한 특징을 놓칠 수 있다.

---

### 5. Padding과 Stride 함께 사용

실제 CNN에서는 Padding과 Stride를 함께 사용한다.

예를 들어

```
Input

↓

Padding

↓

Convolution

↓

Stride

↓

Feature Map
```

과정을 반복하면서

Feature Map의 크기를 적절하게 조절한다.

대표적으로

- Padding = 1
- Stride = 1

은 Feature Map 크기를 유지하는 데 많이 사용된다.

반면

- Padding = 1
- Stride = 2

는 Feature Map의 크기를 절반 정도로 줄일 때 자주 사용된다.

---

## 장점

- Feature Map의 크기를 자유롭게 조절할 수 있다.
- 중요한 가장자리 정보를 보존할 수 있다.
- 계산량을 효율적으로 조절할 수 있다.
- 깊은 CNN을 안정적으로 구성할 수 있다.

---

## 한계

- Padding이 너무 크면 불필요한 정보가 추가될 수 있다.
- Stride가 너무 크면 중요한 특징을 놓칠 수 있다.
- 적절한 Padding과 Stride 값을 선택해야 최적의 성능을 얻을 수 있다.

---

## Padding vs Stride

| Padding | Stride |
|----------|---------|
| 입력 이미지의 가장자리를 확장 | Kernel의 이동 간격 조절 |
| Feature Map 크기 유지 | Feature Map 크기 감소 |
| 가장자리 정보 보존 | 계산량 감소 |
| 주로 Zero Padding 사용 | 보통 1 또는 2 사용 |
